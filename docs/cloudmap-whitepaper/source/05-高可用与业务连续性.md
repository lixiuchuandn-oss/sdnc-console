# 5. 高可用与业务连续性


## 5.1 多层次高可用机制

- **控制平面 HA**：管理节点采用 3 节点集群部署，分布式一致性存储 数据自动选举与同步，确保大脑永不宕机。

- **数据平面 HA**：分布式存储的多副本机制确保数据在物理磁盘或节点损坏时依然可读可写。

- **业务实例 HA**：当物理节点发生故障（断电、死机）时，系统会自动检测并将受影响的虚拟机在其他健康节点上重启，实现分钟级业务恢复。RPO=0，RTO 为分钟级。


## 5.2 企业级备份与容灾

内置产品化的备份管理服务，支持将虚拟机镜像高效备份至本地或远端存储。

- **多协议支持**：支持备份至 NFS 存储或 S3 兼容对象存储，实现数据异地归档。

- **可用区容灾**：支持跨可用区的数据级与业务级容灾，通过专用低延迟网络实现同城双活。

- **灵活策略**：支持 Cron 表达式级别的定时备份策略，满足 RPO/RTO 的严格要求。

- **多样化恢复模式**：支持原机覆盖恢复、异机重建恢复及文件级细粒度恢复。


## 5.3 混合架构与一云多芯

Cloudmap 具备强大的硬件异构兼容性，支持在单一集群内实现不同架构服务器的混合部署与协同管理。

- **异构资源池化**：支持将 x86、ARM、LoongArch 等不同架构的服务器构建为统一的资源池，上层应用感知不到底层差异。

- **平滑国产化替代**：支持在原有 x86 集群中直接添加国产化节点，通过在线迁移逐步替换老旧硬件，实现业务无感知的国产化平滑演进。

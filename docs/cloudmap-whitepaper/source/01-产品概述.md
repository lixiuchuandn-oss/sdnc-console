# 1. 产品概述


## 1.1 背景与建设动因

当前政企与行业数字化建设普遍面临**架构割裂、运维分散、信创合规压力大、边缘管控难**四大痛点：

- 计算、存储、网络分建分管，资源利用率低、扩容周期长、成本高企；
- 中心机房与边缘站点架构异构、管理不统一，监控分散、运维效率低下；
- 信创替代与等级保护并行推进，亟需一套**兼容多架构、支持国密、满足分权审计**的统一底座；
- 边缘算力分散、数据安全风险高、云边协同难，难以支撑分布式业务与 AI 推理场景。

Cloudmap 超融合平台基于上述行业痛点，以**软件定义基础设施**为核心理念，构建一套**统一架构、统一管控、统一运维、统一安全**的企业级私有云底座，覆盖从边缘单节点到数据中心千级集群的全场景部署，支撑政企数字化转型与信创建设。


## 1.2 产品定位

Cloudmap 是北京瑞和云图自主研发的**企业级全栈超融合基础设施平台**，面向政企、金融、能源、制造等行业，提供**私有化、国产化、安全可控、云边一体**的 IaaS+PaaS+MaaS 一体化解决方案。

平台以 **Cloudmap OS** 为底层统一资源底座，整合计算、存储、网络、安全四大基础设施能力；以 **ComputerTower** 为统一管控入口，提供可视化、多租户、分级权限、统一运维运营能力，**一套架构承载虚拟机、容器、裸金属、云桌面、AI 推理、数据库**等多元业务负载，适配私有云、混合云、边缘计算、智算中心等多样化部署形态，助力客户构建**稳态+敏态**双模 IT 架构，支撑业务长期演进与创新。


## 1.3 核心价值

Cloudmap 紧扣政企数字化转型与信创建设核心诉求，以**轻量化、高可靠、敏捷化、强兼容**为核心设计理念，为客户创造四大核心价值：


### 1.3.1 轻量化起步，弹性演进

支持**单节点边缘部署、三节点集群起步、平滑扩容至千级节点**，大幅降低中小数据中心、分支机房、边缘站点的建设门槛与初始投入。云原生架构控制面资源占用极低，智能调度引擎动态适配负载密度，在同等硬件条件下承载更多业务，**实现小投入、大产出，轻量级起步、规模化演进**。


### 1.3.2 稳定可靠，承载关键业务

构建**控制面集群高可用、数据面多副本冗余、业务面故障自愈**的多层次高可用体系，数据零丢失（RPO=0）、业务分钟级恢复（RTO 分钟级）。可稳定承载**核心数据库、交易系统、ERP、MES** 等高等级稳态业务，**保障业务连续、降低停机风险、减少运营损失**。


### 1.3.3 敏捷交付，双模 IT 融合

一套平台统一纳管**虚拟机、容器、裸金属、云桌面、AI 推理**，实现传统应用与云原生应用**统一调度、统一运维、统一交付**。资源交付从小时级缩短至分钟级，快速响应业务上线、变更、扩容需求，**支撑稳态业务稳定运行、敏态业务快速创新，实现双模 IT 一体化管理**。


### 1.3.4 广泛兼容，平滑国产化

全面适配 **x86、鲲鹏、海光、飞腾、龙芯** 等异构 CPU 架构，支持**国产与非国产服务器混合部署、存量设备利旧纳管、第三方存储与安全设备兼容**。支持业务**平滑迁移、渐进式信创替代**，最大化保护现有投资、降低迁移风险、缩短替代周期，**助力客户安全、高效、低成本完成国产化升级**。

# 1. 产品概述

## 1.1 产品定位

Cloudmap超融合平台由北京瑞和云图科技有限公司独立开发，属于新一代企业级超融合基础设施软件系统，致力于打造全新一代企业级IT基础架构。本平台并非虚拟化与存储的简单叠加，而是依托先进的云原生架构，将计算、存储、网络和安全重新整合，为企业数字化变革提供“开箱即云”的现代化数据中心解决途径。

面对传统IT架构逐渐暴露的固化与分离问题，Cloudmap摒弃传统虚拟化的性能负担，选用极度轻量的容器基础，拥有弹性扩展与快速部署的特点。可消除稳态与敏态业务的界限，既能稳定承载数据库、ERP等核心关键应用，又能为微服务、DevOps等云原生业务提供天然的运行支撑，是企业建立双模IT架构的最佳基础设施。

Cloudmap 通过核心云计算引擎与统一云管理平台深度协同，消除从中心数据中心到边缘节点的运维孤岛。无论是构建企业私有云、行业云，还是统筹管理分布式的边缘云站点，Cloudmap 都能提供一致、流畅的高效体验。

## 1.2 核心价值

Cloudmap 围绕 超轻、极稳、敏捷、兼容 四大核心特质，为客户创造从费效比优化到业务创新的全方位价值：

### 1.2.1 超轻系统 · 极致效能

- **轻量化架构**：基于云原生架构深度瘦身，单节点仅需极低资源即可全功能运行，在同等硬件条件下，为业务释放更多算力。

- **动态超配算法**：内置智能调度引擎，实时感知集群负载水位，在保障 SLA 的前提下动态调整资源超配比，提升硬件资源利用率。

### 1.2.2 极稳可靠 · 业务永续

- **统一分布式存储**：通过内核直通与分布式加速算法，消除 I/O 瓶颈。单节点即可提供数万级 IOPS，满足高性能计算严苛需求。

- **多级容灾**：从数据多副本到跨数据中心双活，全方位保障数据零丢失与业务零中断。

### 1.2.3 敏捷交付 · 云原生底座

底层融合 云原生编排引擎，实现“虚拟机+容器”的统一调度。资源交付从小时级缩短至分钟级，无缝对接公有云生态。

1-1000 节点弹性伸缩：支持从单节点、3 节点边缘轻量化起步，平滑扩展至 1000+ 节点的大规模云数据中心，随需而变。

### 1.2.4 广泛兼容 · 一云多芯

- **全栈异构兼容**：全面打破硬件锁定，支持 Intel/AMD 及鲲鹏、海光、飞腾、龙芯等国产芯片在同一集群内混合部署与统一纳管，助力企业从容应对信创替代挑战。

- **极简智能运维**：所见即所得的 Web 控制台配合 AIOps 智能巡检，实现故障的秒级定位与自愈，将运维人员从繁琐的日常巡检中解放出来。

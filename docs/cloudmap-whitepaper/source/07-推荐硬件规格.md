# 7. 推荐硬件规格

## 7.1 通用计算型 (G9000-X28S)

适用于通用业务负载、Web 应用、轻量级数据库等场景。
CPU：双路处理器，单颗 14 核以上，主频 2.4GHz+
内存：128GB - 512GB DDR4 ECC
系统盘：2 x 480GB SSD (RAID 1)
数据盘：3 x 4TB/8TB SATA HDD (建议配置 RAID5 或分布式副本)
网络：4 x GE 电口，2 x 10GE 光口

## 7.2 高性能计算型 (G9000-F32S)

适用于高并发数据库、高性能计算、核心业务系统等场景。
CPU：双路处理器，单颗 32 核以上，主频 2.4GHz+
内存：256GB - 1TB DDR4 ECC
缓存盘：2 x 1TB NVMe SSD (用于分布式存储缓存层)
数据盘：6 x 4TB SSD (全闪存配置，提供极低延迟)
网络：双路 25GE/100GE 光口，支持 RoCEv2 RDMA 协议

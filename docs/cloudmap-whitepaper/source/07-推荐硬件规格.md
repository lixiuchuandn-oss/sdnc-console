# 7. 推荐硬件规格

硬件规格应根据站点定位、业务负载、数据规模、网络条件和高可用要求选型。中心云通常关注资源规模、存储性能和扩展能力；区域云关注多业务混合承载和区域自治；边缘节点关注轻量化、低功耗、现场空间和远程运维能力。以下规格为典型建议，实际项目需结合厂商型号、兼容性清单和容量测算确定。

## 7.1 通用计算型（G9000-X28S）

适用于通用业务负载、Web 应用、轻量级数据库、园区边缘节点和中小规模资源池。

| 项目   | 建议规格                                           |
| ------ | -------------------------------------------------- |
| CPU    | 双路处理器，单颗 14 核以上，主频 2.4GHz+           |
| 内存   | 128GB–512GB DDR4 ECC                               |
| 系统盘 | 2 × 480GB SSD，建议 RAID 1                         |
| 数据盘 | 3 × 4TB/8TB SATA HDD，按项目选择 RAID 或分布式副本 |
| 网络   | 4 × GE 电口，2 × 10GE 光口                         |

该型号适合边缘站点快速部署。若承载云桌面、数据库或容器密集型负载，应结合并发数、IOPS、网络吞吐和备份窗口重新测算。

## 7.2 高性能计算型（G9000-F32S）

适用于高并发数据库、高性能计算、核心业务系统等场景。

| 项目   | 建议规格                                       |
| ------ | ---------------------------------------------- |
| CPU    | 双路处理器，单颗 32 核以上，主频 2.4GHz+       |
| 内存   | 256GB–1TB DDR4 ECC                             |
| 缓存盘 | 2 × 1TB NVMe SSD，用于分布式存储缓存层         |
| 数据盘 | 6 × 4TB SSD，全闪或混闪配置按业务要求选择      |
| 网络   | 双路 25GE/100GE 光口，可按项目支持 RoCEv2 RDMA |

该型号适合中心云、区域云或对数据库、AI 推理、云桌面图形工作站有较高要求的场景。若启用 RDMA、GPU/vGPU 或跨可用区复制，需要同步规划交换机、线缆、网卡、驱动和运维监控。

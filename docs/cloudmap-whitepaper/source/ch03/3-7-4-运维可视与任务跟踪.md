### 3.7.4 运维可视与任务跟踪

- **概览大屏**：资源池概览页聚合机器状态分布、Region 连接信息、机架/区域控制器运行状态等关键指标，数据定时自动刷新，帮助运维快速掌握裸金属集群健康度。

- **异步任务感知**：纳管、部署、释放等长耗时操作采用异步任务模型，界面持续跟踪任务进度直至成功或失败终态，无需人工轮询控制面。

- **与超融合协同**：裸金属节点可与 Cloudmap 虚拟机、分布式存储、SDN 网络及智算 GPU 节点在同一业务网内协同部署，形成「虚拟化 + 裸金属 + 智算」混合资源池，兼顾弹性与性能；部署完成的裸金属可进一步接入云桌面远程运维（详见 3.11）。

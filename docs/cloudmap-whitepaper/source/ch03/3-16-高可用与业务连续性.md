### 3.16 高可用与业务连续性

平台在控制面、数据面与业务实例三层提供高可用能力；备份操作与远程归档见 **3.9** 各节。


#### 多层次高可用机制

- **控制平面 HA**：管理节点 3 节点集群部署，分布式一致性保障自动选举与同步；
- **数据平面 HA**：分布式存储多副本，磁盘或节点损坏时数据仍可读可写；
- **业务实例 HA**：节点故障时虚拟机可在健康节点重启，RPO=0，RTO 分钟级。


#### 企业级备份与容灾

- **多协议支持**：备份至 NFS 或 S3 兼容对象存储，实现异地归档；
- **可用区容灾**：跨可用区数据级与业务级容灾，同城双活经专用低时延网络实现；
- **灵活策略**：Cron 级定时备份，满足 RPO/RTO 要求；
- **多样化恢复**：原机覆盖、异机重建、文件级细粒度恢复。

部署形态与灾备组网见 **5.3**、**3.3.7**、**3.4.9**。

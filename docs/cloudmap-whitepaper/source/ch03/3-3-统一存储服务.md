## 3.3 统一存储服务

在 **3.1.2** 统一存储架构之上，Cloudmap 在同一平台交付块存储、对象存储与文件访问，覆盖虚拟机云盘、容器持久化卷、数据库、智算高 I/O 及备份归档等场景。以下各节说明部署配置、加速引擎、云盘与快照、QoS 及运维等能力。

![Cloudmap 分布式存储数据面架构](assets/storage-service-data-plane.png)

**图 3-7 Cloudmap 分布式存储数据面架构**

集群各节点由 **统一存储控制面** 统一下发策略，节点侧 **数据服务进程** 对接 NVMe/SSD/HDD 数据盘；数据面采用用户态软硬协同（内核旁路、零拷贝、CPU 卸载）释放闪存性能，**存储专网** 承载副本复制与恢复流量，可选 RDMA/RoCE 加速。存储具备多副本保护、全闪/闪混与池化能力，存储类注册至虚拟机与容器调度链路。

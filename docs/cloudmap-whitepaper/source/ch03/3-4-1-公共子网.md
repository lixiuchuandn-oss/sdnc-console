### 3.4.1 公共子网

**实现目标**：提供南北向互通网段，支撑 EIP、NAT、浮动 IP 等对外发布与公网访问能力。

**部署位置**：由节点侧 **虚拟网络服务** 在 **3.1.3** 业务网上统一供给，与 **图 3-9** 所示公共网络平面对应。

**整体价值**：扁平子网、VPC 网络经边界服务关联公共子网即可对外互通，出口地址与带宽可在界面集中规划。

**功能说明**

- **网段规划**：定义对外互通用的 IP 网段与网关，作为 EIP、NAT 等边界能力的承载网段。
- **边界关联**：扁平子网、VPC 网络内的实例经 EIP、SNAT、DNAT 等与公共子网联动，实现出网或入网发布。
- **带宽控制**：可对关联 EIP 设置上下行带宽上限，避免单业务占满出口。

边界能力细则见 **3.4.5**。

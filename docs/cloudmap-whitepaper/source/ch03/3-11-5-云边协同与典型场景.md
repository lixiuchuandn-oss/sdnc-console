### 3.11.5 云边协同与典型场景

云端集中管控，边缘就近推理：结合Cloudmap原生云边多级架构，中心端负责管控策略下发、全平台模型目录同步、全局监控汇总；边缘节点就地承载推理计算，就近响应本地业务，适配现场带宽受限、数据不能出园区的项目。

- **全量数据本地留存不出域**：模型权重、企业业务资料、推理交互日志全部保存在私有云或边缘本地，数据全程不流出企业内网，适配金融、政务、制造等行业的数据安全与合规监管要求。

- **典型落地应用场景**：依托超融合算力+私有化推理+低代码应用能力，可快速落地园区视频智能分析、产线设备预测性维护、门店智能导购、政务智能问答、医疗辅助研判、研发代码助手等项目。

与训练能力形成AI全链路闭环：联动Cloudmap自研MaaS模型训练模块，训练模块负责数据标注、模型微调迭代，推理模块承接模型服务化部署上线，形成数据标注-模型训练-私有化部署-业务落地完整AI业务闭环；推理侧可独立投产，企业若需自研微调再与MaaS训练模块联动。

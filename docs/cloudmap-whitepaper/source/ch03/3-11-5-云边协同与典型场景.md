### 3.11.5 云边协同与典型场景

深度融入**中心—区域—边缘**三级架构，实现策略统一下发、模型统一管理、边缘就近推理、断网自治运维。

- **中心管控**：统一管理模型目录、权限、策略，全局监控汇总、算力调度（详见 **3.15**）；
- **边缘自治**：边缘节点本地运行推理，断网时独立运维、保障业务连续；
- **数据本地留存**：模型、业务数据、推理日志不出园区，满足金融、政务、制造合规要求（详见 **10.1**）；
- **典型场景**：园区视频分析、产线质检、政务问答、医疗辅助、研发助手、门店导购等。

跨站点网络见 **3.4.9**；与 MaaS 训练模块联动为**选配**，可形成「标注—训练—部署」闭环。

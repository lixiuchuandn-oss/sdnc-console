### 3.1.3 超融合网络架构

![超融合网络架构](assets/hci-network-arch.png)

**图 3-3 超融合网络架构**

超融合集群经核心层设备与 IDC、办公网络互联。节点侧按职能划分 **存储网**、**迁移网**、**管理网**与 **业务网** 四条逻辑网络，分别承载分布式存储 I/O、虚拟机跨节点迁移、平台管控与租户业务流量。

存储网、迁移网与管理网可按项目 **三网合一或三网分离** 部署：合一方案简化布线、降低交换机端口占用，适合中小规模与成本敏感场景；分离方案为各网分配独立网段，隔离性更好。若对 **存储网络 QoS** 有明确要求（如保障副本复制与数据 I/O 不受迁移流量冲击），建议将 **迁移网独立** 出来，与存储专网分网承载。业务网通常与集群内部流量分网规划。VPC、扁平网络、SSLO 等逻辑网络见 **3.4**。

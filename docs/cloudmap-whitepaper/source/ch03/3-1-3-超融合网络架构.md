### 3.1.3 超融合网络架构

![超融合网络架构](assets/hci-network-arch.png)

**图 3-3 超融合网络架构**

超融合集群经核心层设备与 IDC、办公网络、园区网络或边缘现场网络互联。节点侧按职能划分 **存储网**、**迁移网**、**管理网**与 **业务网** 四条逻辑网络，分别承载分布式存储 I/O、虚拟机跨节点迁移、平台管控与租户业务流量。

存储网、迁移网与管理网可按项目 **三网合一或三网分离** 部署：合一方案简化布线、降低交换机端口占用，适合小型边缘节点和成本敏感场景；分离方案为各网分配独立网段，隔离性和可观测性更好，适合中心云、区域云和高负载资源池。若对 **存储网络 QoS** 有明确要求，例如需要保障副本复制与业务 I/O 不受迁移流量影响，建议将迁移网独立规划。

业务网通常与集群内部流量分网规划，用于承载租户 VPC、扁平网络、负载均衡、EIP/NAT、SSLO 和跨站点访问等逻辑网络能力。边缘节点接入中心云时，应结合现场链路质量、地址规划、DNS、证书和安全策略设计南北向访问路径，避免把边缘现场网络暴露为无边界的扁平互联。

### 3.3.1 统一存储部署与配置

平台通过可视化向导完成存储上线、扩容与策略下发，降低分布式存储部署门槛。

- **向导式部署**：按节点分配数据盘，自动识别 NVMe/SSD/HDD，配置副本数、压缩策略与存储类注册。

- **运行态扩容**：支持新增数据盘或存储节点，遵循「仅扩容、不缩容」规范，避免误删已有数据盘。

- **元数据加速**：可为节点选配独立 SSD/NVMe 作为元数据加速盘，并设定每盘元数据区容量。

- **存储专网**：支持为复制与数据 I/O 配置独立 VLAN 与地址段，与管理面流量隔离。

- **云原生集成**：存储类自动注册至虚拟化与容器调度链路，云盘支持在线扩容与存储池联动。

### 3.3.1 统一存储部署与配置

提供**向导式、可视化、全自动化**存储部署与管理能力，大幅降低分布式存储上线、扩容、运维门槛。

- **一键式部署**：可视化向导自动识别 NVMe/SSD/HDD，完成节点磁盘分配、副本策略配置、存储类注册，快速构建分布式存储集群；
- **在线平滑扩容**：支持新增磁盘或节点，遵循「仅扩容、不缩容」原则，扩容过程业务无感知，容量线性增长；
- **元数据加速**：支持独立 SSD/NVMe 作为元数据盘，提升元数据访问性能，适配高并发场景；
- **存储专网隔离**：独立 VLAN 承载存储复制与 I/O 流量，与管理、业务网络隔离，保障存储性能稳定；
- **云原生深度集成**：存储类自动注册至虚拟化与容器调度链路，云盘支持在线扩容、快照联动，无缝对接上层应用。
- **统一存储 Operate（已交付）**：**集群 → 统一存储配置** 提供向导式 Operate 能力，含存储扩容、存储网变更等运维入口；变更存储网等高风险步骤须二次确认（见 **4.1.2**）。

### 3.2.1 资源动态调度

Cloudmap OS 智能调度引擎对集群节点执行「预选 → 优选 → 选定」三步决策，为虚拟机与容器工作负载匹配最优节点；选定结果用于故障重建、节点故障恢复、负载动态均衡与虚拟机热迁移等场景。

![Cloudmap OS 智能调度](assets/intelligent-scheduling.png)

**图 3-6 Cloudmap OS 智能调度**

- **预选过滤**：按节点可调度性、资源余量、标签匹配、污点容忍等硬条件筛除不可用节点。
- **优选打分**：对候选节点按资源均衡、亲和/反亲和、QoS 分级、部署集与故障域等规则评分，取得分最高者。
- **调度底座**：Cloudmap OS Scheduler 提供实时资源感知、自动负载均衡、故障自愈、污点管理与节点动态扩容等能力，支撑上述决策闭环。

### 3.2.1 资源动态调度

构建**智能化、策略化、全局感知**的资源调度体系，采用「预选—优选—选定」三步决策机制，实现资源最优匹配、负载智能均衡、故障自动自愈。

![Cloudmap OS 智能调度](assets/intelligent-scheduling.png)

**图 3-6 Cloudmap OS 智能调度**

- **预选过滤**：基于节点资源余量、硬件兼容性、标签匹配、污点容忍等硬约束，快速筛除不可用节点，确保调度合规；
- **优选打分**：综合资源利用率、负载均衡、亲和/反亲和策略、QoS 等级、故障域分布等维度动态评分，智能选择最优节点；
- **调度能力闭环**：实时感知集群资源状态，支持**负载均衡、故障重建、热迁移、自动扩容**，节点故障时快速重建业务，保障业务连续性。

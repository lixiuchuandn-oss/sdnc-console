### 3.5.4 配置与镜像仓库

**实现目标**：集中管理应用配置、敏感凭证与镜像拉取来源，支撑工作负载安全、可重复部署。

**部署位置**：ConfigMap、Secret 按命名空间存放于容器集群；镜像仓库凭证与平台 Harbor 实例对接。

**整体价值**：配置与镜像来源统一纳管，创建/变配工作负载时可直接引用，降低配置散落与凭证泄露风险。

- **ConfigMap**：键值或文件形式注入应用配置；支持创建、编辑、YAML 查看及与工作负载挂载关联。
- **Secret**：管理密码、TLS 证书、镜像拉取凭证等敏感数据；与工作负载、Ingress 等引用关系可在界面维护。
- **镜像仓库**：对接 Harbor 等兼容仓库，浏览项目、镜像与标签；配置拉取凭证并同步至命名空间，供工作负载与任务选用。
- **命名空间隔离**：配置与凭证按命名空间划分，与租户/项目权限策略一致。

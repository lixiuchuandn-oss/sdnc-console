### 3.11.1 边缘推理一体化架构

- **平台统一管控**：所有边缘推理算力统一划为独立资源池接入Cloudmap，运维人员在超融合管理界面即可完成资源入网对接、连通性校验、接口密钥配置、分级权限分配，无需逐一登录各边缘节点单独配置。

- **资源复用**：智算模块直接复用 Cloudmap 现有底层能力，包含 GPU/vGPU 硬件直通、显卡显存切分、CPU 架构 NUMA 亲和调度、高性能分布式存储等（详见 **3.2**、**3.3.2**），为大模型权重加载、缓存读写、多实例并发推理提供稳定算力与低时延存储支撑，避免硬件资源重复建设。

- **线性扩展**：除单机一体机外，推理集群支持多 Worker 节点横向扩展，调度模块统一感知各节点 GPU 负载并分发模型实例，满足从单点边缘到多节点智算集群的弹性扩容需求。

- **应用集成部署**：边缘推理集群以平台自研推理调度模块作为集群控制核心，应用编排服务通过反向代理同机部署对外提供访问，配套监控组件统一采集GPU及集群运行指标，形成推理调度+应用开发+运行监控三位一体的整机交付模式。

- **标准化接口**：推理服务兼容行业通用大模型API规范，现有业务系统、自研AI应用、第三方智能框架无需改造代码即可快速接入，原生支持流式输出、工具函数调用、图文音视频多模态收发交互。

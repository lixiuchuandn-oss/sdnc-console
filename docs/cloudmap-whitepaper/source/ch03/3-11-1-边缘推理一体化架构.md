### 3.11.1 边缘推理一体化架构

采用**中心管控、边缘自治、算力池化**的一体化架构，实现推理资源统一管理、边缘就近响应、断网自治运行。

- **资源池统一纳管**：GPU/国产 AI 芯片推理节点统一接入管控平台，形成**智算资源池**，全局调度、统一运维；
- **算力复用优化**：复用平台虚拟化、存储、网络、调度能力；以 GPU/PCI 硬件直通（**3.2.5**）、CPU 绑核与隔离（**3.2.2**）、NUMA 亲和与大页内存（**3.2.2**、**3.2.3**）支撑推理负载性能调优；
- **集群弹性扩展**：支持单推理一体机、多 Worker 集群横向扩展，线性提升并发处理能力；
- **三位一体交付**：推理调度、应用网关、监控组件一体化部署，快速上线（具体组件以项目交付清单为准）；
- **标准化 API 兼容**：原生兼容主流大模型 API，支持**流式输出、工具调用、多模态交互**，业务系统无缝对接。

部署形态见 **2.1**；中心—区域—边缘管控见 **3.15**。

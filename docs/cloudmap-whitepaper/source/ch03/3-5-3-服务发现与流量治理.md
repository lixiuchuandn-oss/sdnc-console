### 3.5.3 服务发现与流量治理

**实现目标**：为容器应用提供服务发现、南北向流量入口及可视化拓扑，支撑对外发布与集群内访问。

**部署位置**：Service、Ingress、Gateway 等资源运行于容器集群；对外发布可与 **3.4** 公共子网及边界服务协同。

**整体价值**：从集群内访问到对外暴露的路径在界面可配置、可观测，减少手工维护 Ingress 与网关配置。

- **Service**：支持 ClusterIP、NodePort 等类型；创建与编辑服务端口、选择器及关联 Pod；列表可查看后端终端状态。
- **Ingress 路由**：配置 HTTP/HTTPS 路由规则、域名与 TLS 证书，将外部请求转发至后端 Service。
- **Gateway API**：支持 Gateway、HTTPRoute、GRPCRoute 等新一代网关资源，适用于多租户路由与细粒度流量治理（按集群 Gateway API 组件安装情况启用）。
- **服务拓扑**：基于 Service、Ingress 与 Pod 关系生成分层拓扑视图，便于梳理调用链与排查流量路径。

### 3.3.4 快照链与快速克隆

块级数据保护基于分层快照链与写时复制：逻辑副本（Replica）按块索引指向实时数据或各历史快照中的有效块，新快照仅记录相对基线的差异，兼顾空间效率与恢复灵活性。

![快照链与写时复制](assets/snapshot-chain.png)

**图 3-8 快照链与写时复制**

- **分层快照链**：快照链式叠加，创建以元数据变更为主，对在线 I/O 影响小。
- **云盘快照**：支持从云盘创建卷快照，统一存储路径自动匹配相应快照类。
- **快速克隆**：可从快照恢复为新云盘并立即挂载，克隆体与源卷共享未变更数据，节省空间。
- **主机级保护**：云主机备份/快照与云盘快照互补，分别面向整机一致性与单盘回滚场景。

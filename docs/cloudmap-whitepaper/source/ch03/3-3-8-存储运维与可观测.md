### 3.3.8 存储运维与可观测

全链路监控存储集群健康、性能、容量，提供**可视化、智能化、预警化**运维能力，提前识别风险、快速定位故障。

- **容量全景监控**：实时展示集群总容量、使用率、各池占比，智能预测容量瓶颈，辅助扩容决策；
- **硬件健康监测**：实时采集磁盘、网卡、控制器状态，提前预警硬件故障；
- **性能指标追踪**：监控 IOPS、吞吐量、时延、队列深度，快速定位性能瓶颈；
- **审计追溯**：云盘、快照、存储池操作全记录，支持查询、追溯，满足合规要求。
- **存储 DRS / SDRS M1（已交付）**：**集群 → 存储智能调度** 与统一存储 Operate 内 **SDRS 策略 / 任务日志** 提供存储层调度策略查看、近期任务追踪及**手动迁盘**入口（以集群 Longhorn/SDRS 组件能力为准）。

全平台监控能力见 **3.14**；本节聚焦存储域指标。

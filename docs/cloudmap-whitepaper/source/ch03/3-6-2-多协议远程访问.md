### 3.6.2 多协议远程访问

- **协议全覆盖**：支持 SSH 终端、RDP 远程桌面、VNC 图形控制台等主流协议，覆盖 Linux 服务器运维、Windows 桌面操作及虚拟化控制台访问等典型需求。

- **虚拟机云桌面**：对已运行且具备业务 IP 的云主机，管理员可将连接分配给指定云桌面用户；用户在云桌面网关门户登录后即可打开已授权桌面，无需记忆各机器地址与端口。

- **裸金属远程登录**：对已部署完成的裸金属节点，同样可通过云桌面入口发起远程会话，实现装机验收、系统调优与日常运维的一体化浏览器访问体验。

- **与现有控制台互补**：KubeVirt 虚拟化层仍保留 Web VNC 等原生控制台能力；云桌面网关面向跨资源池统一远程访问与桌面用户交付。

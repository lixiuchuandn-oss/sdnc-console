### 3.6.2 多协议远程访问

全面支持主流远程协议，覆盖 Linux 运维、Windows 办公、虚拟化控制台等全场景访问需求。

- **全协议兼容**：支持 SSH、RDP、VNC 等协议，一套网关统一承载多类型桌面访问；
- **浏览器直连**：免客户端安装，通过 Web 浏览器直接访问桌面，降低终端管理成本；
- **虚拟机云桌面**：管理员分配权限后，用户直接访问授权虚拟机，无需记忆 IP 与端口；
- **裸金属远程接入**：支持裸金属节点远程运维，实现装机、调优、日常维护一体化；
- **控制台互补**：保留原生 VNC 控制台，与云桌面网关形成互补，适配不同运维场景。

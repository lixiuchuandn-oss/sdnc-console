### 3.4.5 边界服务

扁平子网、VPC 网络经 **3.4.1** 公共子网关联下列边界能力，统一供给后分发至各节点实例。

**EIP（弹性公网 IP）** 可将静态公网 IP 绑定到扁平子网或 VPC 网络内的虚拟机、容器实例，并关联公共子网实现与公网的直接通信；支持对 EIP 设置最大上下行带宽，避免个别业务占满出口带宽。

**SLB（负载均衡）** 支持 IPv4，对后端实例进行健康检查，仅向正常终端分发流量，故障终端自动摘除，提升服务可用性。

**NAT 网关** 支持 SNAT 与 DNAT：SNAT 供扁平子网或 VPC 网络内私有地址访问外部网络；DNAT 供外部访问内网发布的服务。可设置 NAT 网关带宽上限，保障整体出口性能。

### 3.7.2 裸金属全生命周期运维

- **网络发现**：自动扫描并展示尚未纳管的物理设备，运维人员可从发现列表一键发起后续纳管流程，缩短新机上架与扩容响应时间。

- **硬件纳管与检测**：对发现设备执行硬件检测（Commission），自动采集 CPU、内存、磁盘、网卡等配置信息，设备进入「可用」状态后方可部署操作系统。

- **向导式系统部署**：提供部署向导，按操作系统类型、发行版与内核变体选择目标镜像，一键下发装机任务；平台遵循裸金属状态机约束，在不同生命周期阶段仅展示合法操作，避免误操作冲突。

- **电源与回收运维**：支持远程开机、关机、重启；对已部署机器可执行释放回收；对进行中任务支持中止，对故障节点支持标记故障/修复，保障批量运维可控可溯。

- **机器详情透视**：详情视图展示硬件配置、磁盘分区、网络接口及当前状态，为排障、容量规划与变更审批提供完整依据。

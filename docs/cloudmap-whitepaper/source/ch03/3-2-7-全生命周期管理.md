### 3.2.7 全生命周期管理

覆盖虚拟机**从创建、运行、变更到销毁**的全生命周期，提供一站式可视化管理，简化运维、提升效率。

- **一站式管理**：支持虚拟机创建、克隆、快照、热迁移、在线扩容、删除等全流程操作；
- **异构迁移能力**：内置 P2V/V2V 迁移工具，支持物理机、第三方虚拟化平台平滑迁移至 Cloudmap（详见 **3.8**）；
- **一致性数据保护**：支持整机一致性快照、快照链管理、快速克隆，保障数据安全与快速恢复（快照机制详见 **3.3.4**）。
- **虚拟机间亲和/反亲和（已交付）**：创建向导与规格改配支持按**其它虚拟机**配置尽量/必须同宿或分散（Pod 亲和语义），用于同业务组共置或互斥；
- **镜像交付增强（已交付）**：镜像列表支持**上传任务**（控制台上传或 Windows ImageUploader 工具）、镜像**标签删除/重命名**；大镜像上传采用导入阶段无进展超时策略，降低误判失败；
- **调度可观测（已交付）**：虚拟机列表可展示 HSM 自动调度相关告警指纹标签，便于与机房/资源总览调度策略对照排查。

### 3.5.5 网络策略与中断保护

**实现目标**：控制 Pod 间东西向访问，并在节点维护或升级时保障关键业务可用副本数。

**部署位置**：NetworkPolicy、PodDisruptionBudget 作用于容器集群内指定命名空间与工作负载。

**整体价值**：在 **3.4.6** 安全组之外，于容器层实现细粒度访问控制与变更窗口保护。

- **NetworkPolicy**：按命名空间、Pod 标签定义入站/出站规则，限制 Pod 间及与外部的通信范围，实现东西向微隔离。
- **Pod 中断保护（PDB）**：为 Deployment、StatefulSet 等设定最小可用副本数；节点驱逐或计划内中断时避免同时停掉过多实例。
- **策略维护**：支持创建、编辑与 YAML 查看；与工作负载标签选择器配合，按应用粒度生效。

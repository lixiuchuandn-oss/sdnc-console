### 3.4.3 VPC 网络

构建租户专属私有网络，支持灵活子网划分、路由管理与安全隔离，满足多租户、多业务、安全隔离需求。

![Cloudmap 扁平子网与 VPC 网络架构](assets/vpc-network-arch.png)

**图 3-10 Cloudmap 扁平子网与 VPC 网络架构**

- **私有网络隔离**：每个 VPC 独立网段、独立路由、独立安全策略，租户间网络完全隔离；
- **子网精细化划分**：单 VPC 内可创建多个子网，按业务、部门、功能划分，实现资源逻辑隔离；
- **跨 VPC 互通**：支持 VPC 对等连接，不同 VPC 间可控互通，兼顾隔离与协同；
- **自定义 DNS**：支持 VPC 内自建 DNS，满足内部域名解析、业务自定义域名需求。

### 3.4.3 VPC 网络

**实现目标**：为虚拟机、容器、裸金属提供专有逻辑网络，支持子网划分、路由与安全隔离。

**部署位置**：由节点侧 **虚拟网络服务** 在 **3.1.3** 业务网上供给，可跨物理节点延伸。

**整体价值**：不同业务或项目使用独立 VPC，网段、路由与安全策略互不干扰；需对外发布时经 **3.4.1** 公共子网与 **3.4.5** 边界服务出网。

**功能说明**

- **VPC 与子网**：每个 VPC 内可灵活配置子网网段、路由表与安全策略；虚拟机、容器、裸金属挂接至同一 VPC 子网，由 VPC 内路由与安全设备转发。
- **跨节点延伸**：VPC 可跨物理节点调度，实例挂接至同一逻辑网络，无需关心物理位置。
- **VPC DNS**：支持在 VPC 内部部署与配置自定义 DNS，实现内部域名解析。
- **VPC 互联**：允许不同 VPC 建立网络连接，实现跨 VPC 资源互通；各 VPC 原有网段与安全策略可保持不变。

安全组见 **3.4.6**（VPC 侧）。

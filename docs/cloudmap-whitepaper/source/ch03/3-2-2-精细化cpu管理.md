### 3.2.2 精细化 CPU 管理

针对高性能数据库、核心交易、HPC 等场景，提供**细粒度、高可控**的 CPU 资源管理能力。

- **灵活调度模式**：支持 **CPU QoS**（请求/上限）与 **CPU 绑核**（Dedicated CPU Placement），兼顾资源利用率与关键业务稳定性；
- **来宾 CPU 拓扑**：在 Cloudmap 控制台为虚拟机配置 Socket / Core / Thread 拓扑，并与内存热扩容等规则联动；
- **CPU 隔离**：在启用 CPU 绑核后，可隔离 QEMU 模拟器线程，降低对来宾 vCPU 的干扰；
- **物理 NUMA 信息（只读）**：集群节点详情可展示宿主机 NUMA 节点数及各节点 CPU 分布，供运维核对硬件拓扑；
- **NUMA 亲和（规划）**：按物理 NUMA 节点为虚拟机配置 Guest NUMA、或将 vCPU/内存绑定至指定 NUMA 节点——**当前 Cloudmap 管控台未提供**，不得写为已上线能力。

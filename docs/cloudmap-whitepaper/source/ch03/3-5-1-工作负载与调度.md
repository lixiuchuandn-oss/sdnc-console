### 3.5.1 工作负载与调度

覆盖全类型容器工作负载，提供**策略化、智能化、高可用**调度能力，适配不同业务形态。

- **全类型负载支持**：统一管理 Deployment、StatefulSet、DaemonSet、Job/CronJob 等，覆盖无状态、有状态、守护进程、定时任务场景；
- **向导式可视化部署**：图形化界面完成镜像配置、资源限额、环境变量、存储挂载、网络绑定，支持 YAML 声明式编辑，降低容器使用门槛；
- **精细化调度策略**：支持节点亲和、Pod 亲和、污点容忍、GPU 资源精准匹配，保障业务稳定性与资源利用率；
- **弹性扩缩容**：支持手动/自动扩缩容，根据负载动态调整实例数量，适配业务峰谷变化。

计算层调度机制详见 **3.2.1**。

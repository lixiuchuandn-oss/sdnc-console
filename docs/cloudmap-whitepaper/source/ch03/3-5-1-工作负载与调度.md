### 3.5.1 工作负载与调度

**实现目标**：创建、变更与回收 Deployment、StatefulSet、DaemonSet 等长期运行工作负载，并按策略调度至合适节点。

**部署位置**：运行于 Cloudmap 容器集群；持久化卷经 **3.3** 存储类挂载，网络挂接 **3.4.3** VPC 子网。

**整体价值**：微服务与云原生应用在界面完成全生命周期管理，无需单独维护 kubectl 与多套工具链。

- **多类型工作负载**：支持 Deployment（无状态）、StatefulSet（有状态）、DaemonSet（每节点一份）；列表支持按命名空间筛选与全集群视图切换。
- **创建与变配**：向导式配置副本数、镜像、资源限额、环境变量、挂载卷与镜像拉取凭证；支持 YAML 声明式编辑。
- **高级调度**：支持节点亲和/反亲和、Pod 亲和/反亲和、污点容忍；可按 GPU 等稀缺资源精准调度（与 **3.2.5**、**3.11** 智算场景协同）。
- **关联资源**：创建时可选择 ConfigMap、Secret、持久化卷声明（PVC）及镜像拉取 Secret，与 **3.5.4** 配置管理联动。

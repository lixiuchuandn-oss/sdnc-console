### 3.4.4 直通网络

**实现目标**：将物理网卡以直通方式供给虚拟机，满足低时延、高吞吐或独占网卡需求。

**部署位置**：依托节点物理网卡与 **3.1.3** 业务网/物理网络；经 PCI 直通、SR-IOV 或 Multus 附加网络接入虚拟机（硬件直通能力见 **3.2.5**）。

**整体价值**：业务流量绕过虚拟交换转发路径，获得接近物理机的网络性能；适用于电信、金融、HPC 等对网络确定性敏感的场景。

**功能说明**

- **PCI 直通**：整卡或 SR-IOV 虚拟功能（VF）直通至虚拟机，由 guest 直接驱动网卡。
- **Multus 附加网络**：经 SR-IOV、macvtap、macvlan 等类型的网络附件挂接直通网卡。
- **实例挂接**：面向虚拟机；可与扁平子网、VPC 网络、公共子网等业务网卡组合使用（多网卡分平面）。
- **调度约束**：直通网卡与虚拟机须位于同一物理节点，创建与变配时按节点亲和校验。

物理网卡、VLAN 与 Provider 网络编排见 **3.4.7**。

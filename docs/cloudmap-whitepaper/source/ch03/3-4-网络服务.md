## 3.4 网络服务

在 **3.1.3** 超融合网络架构之上，Cloudmap 为虚拟机、容器与裸金属提供多层逻辑网络平面，并支持公网访问、安全流量编排与跨站点互联。

![Cloudmap 网络服务架构](assets/network-service-arch.png)

**图 3-9 Cloudmap 网络服务架构**

平台在物理主机之上叠加 **虚拟网络服务**，为虚拟机、容器提供逻辑网络接入；裸金属可按部署方式直接挂接业务网络。基础网络按 **公共子网**、**扁平子网**、**VPC 网络**、**直通网络** 四类独立供给，分别见 **3.4.1～3.4.4**；边界上的 LB、EIP、NAT 等见 **3.4.5**。虚拟机支持多网卡分挂上述网络；容器通常运行于 VPC 网络；裸金属按装机方案挂接扁平子网或 VPC 网络。

底层 **管理网、存储网、迁移网** 统一承载物理机与裸金属的管理、存储复制及虚拟机迁移等集群内部流量，与上层业务网络分网规划（详见 **3.1.3**），不承载虚拟机、容器业务流量。

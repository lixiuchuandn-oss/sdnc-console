### 3.1.1 超融合与存算分离部署

针对不同规模、性能与成本诉求，Cloudmap 提供**超融合部署**与**存算分离部署**两种核心模式，适配从边缘小集群到大型数据中心的全场景需求。

![超融合与存算分离部署](assets/compute-storage-deployment.png)

**图 3-1 超融合与存算分离部署**

- **超融合部署**：计算、存储资源同节点一体化部署，通用服务器同时承载虚拟机、容器业务并池化本地磁盘，通过万兆交换机组建集群。架构简洁、部署快速、运维简单，**适合边缘站点、中小数据中心、成本敏感场景**。
- **存算分离部署**：计算节点与存储节点独立组网、专网互联，计算资源专注业务运行，存储资源独立扩展性能与容量，可对接分布式存储池或第三方 SAN/NAS 设备。**适合大规模数据中心、核心数据库、高并发业务、需独立扩容存储的场景**。

两种模式可平滑切换、按需组合，边缘优先超融合简化运维，大规模场景采用存算分离保障性能，兼顾灵活性与经济性。

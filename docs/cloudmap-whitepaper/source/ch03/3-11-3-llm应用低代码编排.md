### 3.11.3 LLM应用低代码编排

AI应用全生命周期一站式管理：Cloudmap内嵌AI应用编排工作台，管理人员在同一管理页面即可完成AI应用搭建、企业知识库建设、插件配置、模型接口绑定、业务数据源接入，不用跨多个系统来回切换。

快速搭建本地化RAG知识库问答：依托向量与重排配套模型，批量导入企业制度、产品手册、项目文档，自定义文本拆分、检索召回规则，快速落地本地化智能问答应用，支持多轮上下文对话。

可视化搭建智能工作流与智能代理：通过可视化界面配置提示词、串联多步骤业务流程，对接外部业务接口、拓展自定义插件，将底层推理能力封装为标准化业务应用，缩短AI项目从原型测试到生产上线周期。

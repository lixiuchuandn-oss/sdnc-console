# 6. 智能运维与管理

## 6.1 可视化资源大盘

Cloudmap 提供统一资源大盘，用于呈现中心云、区域云和边缘节点的资源状态、容量趋势和告警概况。运维人员可从全局视图进入单个资源池、节点、虚拟机、容器、云盘或网络对象，减少跨系统排查成本。

- **集群健康度**：实时呈现物理节点、存储池、系统组件的健康评分与运行状态。

- **容量预测**：基于历史数据的 CPU、内存、存储使用趋势分析，智能预测资源瓶颈，辅助扩容决策。

- **Top N 统计**：识别资源消耗较高的虚拟机、节点或存储对象，辅助定位资源争用和容量热点。


## 6.2 自动化巡检与风险预警

- **巡检规则**：巡检覆盖硬件状态、系统服务、网络连通性、证书有效期、存储容量、组件健康和备份状态等关键指标。

- **风险告警**：支持容量风险（如存储池使用率过高）与运行时异常（如服务崩溃、慢 I/O）告警，支持自定义阈值自动触发。

- **告警触达**：支持邮件、Webhook、钉钉或企业微信等渠道，并可配置告警抑制、静默和分级通知，降低重复告警对运维的干扰。


## 6.3 多租户与权限控制

- **资源组**：将计算、存储、网络资源划分为逻辑组，实现部门或项目级的资源物理隔离或逻辑隔离。

- **RBAC 权限体系**：基于角色的访问控制，预置管理员、观察者、成员等角色，支持细粒度的 API 访问权限管理，保障操作合规。

- **SSH Key 管理**：支持统一管理 SSH 公钥，实现虚拟机的安全免密登录与批量管理。


## 6.4 算网大脑与多级边缘管理

为解决分布式云环境下多站点资源分散、链路条件不同和现场运维能力不一致的问题，Cloudmap 采用可用区管理模式和算网协同架构，构建“中心-区域-边缘”的分级管理体系。

- **中心管理**：作为全局管控中枢，维护资源目录、租户权限、镜像模板、策略、监控和审计数据。

- **全局态势感知**：汇聚各区域和边缘节点的运行数据、容量数据和安全事件，形成统一视图。

- **算力调度参考**：结合 CPU/GPU/NPU 类型、资源余量、网络条件、数据位置和租户策略，为业务部署提供调度参考。跨站点自动调度需结合项目网络和业务编排范围实施。

- **区域管理节点**：负责单一可用区或区域内的资源管理、告警汇聚和策略落地。

- **多云纳管**：可管理 Cloudmap 资源池，并按项目接入异构云或公有云资源，统一呈现资源信息和部分运维能力。

- **区域自治**：在中心连接中断时，仍能保障区域内业务的连续运行与独立运维，保障断网情况下的业务连续性。

- **负载节点**：实际承载业务负载的物理节点，支持 x86/ARM/LoongArch 等异构算力混合接入。


## 6.5 全域日志审计与管理

Cloudmap 构建覆盖云原生底座、虚拟化层、容器层、管理平台和租户操作的统一日志体系，面向运维、管理员和审计人员提供不同视角。

- **运维保障视角**：提供物理机、存储、网络组件的底层运行日志，支持专业技术术语检索，助力快速故障定位。

- **IT 管理员视角**：将晦涩的系统日志转化为通俗易懂的告警信息，提供“问题现象-可能原因-处理建议”的引导式排障。

- **审计追责视角**：全量记录用户操作日志，支持操作行为回溯与责任界定，满足合规审计要求。

- **边缘日志回传**：边缘节点可在本地保留运行日志和审计日志，并按链路条件回传中心。弱网场景下，应规划本地留存周期、回传频率和日志容量。

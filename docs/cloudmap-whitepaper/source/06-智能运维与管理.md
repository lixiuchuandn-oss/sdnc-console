# 6. 智能运维与管理


## 6.1 可视化资源大盘

提供全景式的全局监控中心，数据驱动决策

- **集群健康度**：实时呈现物理节点、存储池、系统组件的健康评分与运行状态。

- **容量预测**：基于历史数据的 CPU、内存、存储使用趋势分析，智能预测资源瓶颈，辅助扩容决策。

- **Top N 统计**：快速锁定资源消耗最大的资源争抢型虚拟机，优化资源分配。


## 6.2 自动化巡检与风险预警

- **深度巡检**：内置 100+ 项专家级巡检规则，覆盖硬件状态、系统服务、网络连通性、证书有效期等关键指标。

- **风险告警**：支持容量风险（如存储池使用率过高）与运行时异常（如服务崩溃、慢 I/O）告警，支持自定义阈值自动触发。

- **智能告警**：支持多渠道（邮件、Webhook、钉钉/企业微信）精准触达，支持告警抑制与静默，有效避免“告警风暴”，让运维人员专注于真正重要的问题。


## 6.3 多租户与权限控制

- **资源组**：将计算、存储、网络资源划分为逻辑组，实现部门或项目级的资源物理隔离或逻辑隔离。

- **RBAC 权限体系**：基于角色的访问控制，预置管理员、观察者、成员等角色，支持细粒度的 API 访问权限管理，保障操作合规。

- **SSH Key 管理**：支持统一管理 SSH 公钥，实现虚拟机的安全免密登录与批量管理。


## 6.4 算网大脑与多级边缘管理

为解决分布式云环境下零散算力的集中运维与运营难题，Cloudmap 创新性地引入了 可用区管理模式 与 算网大脑 架构，构建了“中心-区域-边缘”的三级联动体系。

- **算网大脑**：作为全局管控中枢，负责跨区域的算力统筹。

- **全局态势感知**：汇聚各区域的运行数据与安全情报，形成全局统一视图。

- **智能算力调度**：基于用户的算力要求（CPU/GPU/NPU）、网络要求及数据位置，进行全局协商与动态选路，将作业精准调度至最优节点。

- **区域管理节点**：负责单一可用区或区域内的资源管理。

- **多云纳管**：不仅管理 Cloudmap HCI 集群，还支持纳管异构云（如 OpenStack、公有云），屏蔽底层差异。

- **区域自治**：在中心连接中断时，仍能保障区域内业务的连续运行与独立运维，保障断网情况下的业务连续性。

- **负载节点**：实际承载业务负载的物理节点，支持 x86/ARM/LoongArch 等异构算力混合接入。


## 6.5 全域日志审计与管理

构建了覆盖 云原生底座、虚拟化层及容器层的统一日志体系，面向不同角色提供差异化视角。

- **运维保障视角**：提供物理机、存储、网络组件的底层运行日志，支持专业技术术语检索，助力快速故障定位。

- **IT 管理员视角**：将晦涩的系统日志转化为通俗易懂的告警信息，提供“问题现象-可能原因-处理建议”的引导式排障。

- **审计追责视角**：全量记录用户操作日志，支持操作行为回溯与责任界定，满足合规审计要求。

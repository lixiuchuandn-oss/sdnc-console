# 4. 内生安全与云安全服务中心

Cloudmap 遵循**安全原生内嵌、资源池化调度、流量智能编排、全链路合规**设计思路，将安全能力深度融入超融合底层架构，摒弃外挂式安全部署模式，依托三网隔离底座搭建一体化安全资源池，实现边界防护、主机安全、应用防护、数据安全、密评合规一体化闭环，满足等保 2.0、密评、行业监管等合规建设要求。

网络侧三网隔离与内生安全架构见 **3.1.5**；SDN 流量编排入口见 **3.4.8**。


## 4.1 底层原生安全架构

从物理组网层面筑牢安全基线，依托网络分区实现天然隔离，从源头缩减安全攻击面。


### 4.1.1 三网物理隔离架构

严格划分**管理网、业务网、安全网**三张独立平面，三层网络采用 ACL 策略逻辑隔离、路由互不可达：管理网专供平台管控与运维接入，业务网承载租户业务流量，安全网集中部署全部安全硬件与虚拟化安全组件；所有安全检测、加解密流量在安全网闭环流转，避免防护组件与业务资源抢占带宽，杜绝横向渗透风险。


### 4.1.2 分权分级权限体系

基于 RBAC 精细化权限模型，实现三权分立（管理员、运维员、审计员），支持集团、部门、租户多级分权管控；资源分配、网络变更、安全策略配置均绑定操作账号，关键操作强制留痕审批，适配政企内控管理制度。平台 RBAC 与审计见 **4.1.2**、**4.4.2**。


### 4.1.3 硬件可信底座适配

兼容国产可信固件、可信芯片，服务器上电完成可信度量，从硬件启动环节杜绝恶意固件篡改；整机资源接入平台前完成硬件合规校验，筑牢基础设施可信根基。


## 4.2 安全资源池化与流量编排

依托 SDN + SD-WAN 技术实现安全组件池化、流量按需牵引，支撑明文、商密、国密多类型应用加密改造落地。


### 4.2.1 统一安全资源池

将防火墙、WAF、IPS、堡垒机、EDR、漏洞扫描、国密加密网关等软硬件安全设备统一纳管入池，打破单设备绑定单一业务的传统模式，安全能力按需弹性分配给不同租户、不同 VPC。租户可按需开通安全服务，实现类似公有云的自助体验。


### 4.2.2 可视化安全服务链

图形化编排南北向、东西向流量路径，自定义安全检测顺序，流量可一键牵引至安全资源池完成过滤、检测、加解密；支持链路冗余备份，安全网元故障自动切换旁路，保障业务不中断。平台支持多路径高可用服务链；HTTPS 可在资源池入口统一解密，一次解密后可串联多种检测（与 **3.4.8** 协同）。


### 4.2.3 国密与商密一体化加密改造

安全池内置国密、商密加密网关，无需改造业务源码即可完成应用加密升级：支持明文业务一键切换商密/国密传输、商密应用平滑升级国密改造，全链路密钥合规管控，满足密评测评规范。


## 4.3 分层安全防护能力

按照边界—网络—主机—应用—数据五层纵深防御架构，覆盖业务全生命周期防护。


### 4.3.1 边界安全防护

集成池化防火墙、负载均衡、NAT 网关，基于五元组管控外网出入流量；结合 SD-WAN 跨域加密隧道，实现分支互联 IPsec/国密加密传输，防范广域网传输窃听篡改（跨域互联见 **3.4.9**）。


### 4.3.2 内网微隔离防护

VPC 维度配置安全组，容器维度启用 NetworkPolicy，实现虚拟机、容器实例精细化访问控制，最小化内网互通权限，阻断内网横向渗透（分别见 **3.4.6**、**3.5.5**）。


### 4.3.3 主机终端安全

全集群批量部署 EDR/HIDS 客户端，实现主机漏洞扫描、恶意程序查杀、异常行为监控、进程白名单管控；虚拟机、裸金属、云桌面统一终端防护策略。


### 4.3.4 应用安全防护

池化 WAF 组件接入服务链，防护 SQL 注入、XSS 跨站、命令注入等 Web 攻击，支持 HTTPS 国密证书统一托管与解密审计。


### 4.3.5 数据安全防护

依托存储快照、定时备份、跨域异地备份构建数据容灾体系；支持云盘、数据库静态数据加密，备份数据传输加密，防止数据泄露与篡改（备份能力见 **3.9**）。


## 4.4 安全运营与合规审计


### 4.4.1 全域安全态势感知

汇总防火墙、WAF、EDR、网关、平台运维全量安全日志，集中研判攻击行为，生成安全态势大屏，直观展示攻击来源、风险级别、受影响资产；支持资产台账、风险总览与事件聚合处置。


### 4.4.2 全链路操作审计

平台资源变更、安全策略修改、用户登录、云桌面访问、跨域互联配置全量日志留存，日志不可篡改、支持检索导出，满足等保审计溯源要求。


### 4.4.3 周期性合规自查

内置等保、密评合规检查模板，自动周期性巡检配置漏洞、加密合规项，生成整改清单，降低政企测评整改工作量。

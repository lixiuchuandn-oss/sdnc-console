# 4. 内生安全与云安全服务中心


## 4.1 自动化安全资源池与服务市场

Cloudmap 将异构安全能力池化，通过安全服务市场向租户提供类似公有云的便捷体验。租户可自助选购防火墙、WAF、IPS、堡垒机等安全服务，像购买云主机一样简单，实现按需购买、即开即用。

- **自动开单**：平台内置的智能运营引擎自动处理安全订单，业务开通的同时，安全防护即刻生效。

- **自动编排**：基于 Cloudmap 原生网络拓扑（VPC/子网），系统自动构建安全域与防护对象，秒级完成网元分配与策略下发，彻底告别繁琐的人工配置。

- **异构兼容**：统一纳管瑞和云图自研及第三方主流厂商的安全网元，支持利旧。


## 4.2 全场景智能流量编排

基于 SDN 技术实现精细化的流量牵引，支持阻断/审计类型的服务链编排，覆盖云内所有流量路径。平台支持最大 64 路径的高可用服务链，确保复杂安全策略的灵活落地与业务的高可靠性：

- **VPC 内流量编排**：提供对同一 VPC 内不同子网间的互访流量进行检测能力，通过智能流量牵引技术，将流量按预设规则导向指定的安全网元，实现子网间的安全隔离与深度检测。支持基于五元组（源/目的IP、端口、协议）的精细化流量分类，确保关键业务流量优先处理，同时对异常流量进行实时告警与阻断。

- **跨 VPC 流量编排**：针对跨虚拟私有云（VPC）的通信流量，构建动态服务链路径。通过集中式策略管理，实现跨域流量的自动化编排与安全加固，例如将出站流量强制引流至 WAF 进行 Web 攻击防护，或对入站流量通过堡垒机进行身份认证与访问控制。支持多租户场景下的流量隔离，避免不同租户间的策略冲突。

- **南北向流量编排**：云平台为外部网络交互流量提供智能路由与安全防护，通过NAT网关、负载均衡实现流量分发与高可用。结合威胁情报和AI分析，实时检测并阻断恶意流量，生成攻击溯源报告。

- **服务链高可用设计**：支持最大64条path 的多路径冗余服务链，主路径故障时流量自动切换至备用路径，保障业务连续性。平台支持服务链带宽热扩容，按业务流量调整安全资源，平衡安全与成本。

- **SSL 卸载与流量可视**：在资源池入口统一解密 HTTPS 流量，实现一次解密，多重检测，提升检测效率 50% 以上，有效识别并阻断加密流量中的潜在威胁。


## 4.3 云安全中心与态势感知

内置云安全中心向租户与管理员提供统一的安全运营视图，达成"识别风险、管控资产、处理事件"的闭环管理，核心能力包含安全态势把控、威胁精确识别、全资产监管及快速事件处置等层面，并拥有原生一体化的使用体验。

- **安全总览**：整合漏洞、病毒、入侵攻击、基线风险等多维度数据，构建全局风险画像，支持一屏统览全网安全态势，直观呈现整体安全状态。

- **资产管理**：统一管理云内资产、线下资产、移动端资产及边缘资产，全面消除安全管理盲区，实现资产安全的无死角覆盖。

- **智能资产发现**：自动构建资产台账，精准识别资产指纹信息（包括端口、进程、中间件、软件版本等），重点聚焦边缘资产与影子资产的识别与管控，避免遗漏隐性风险。

统一事件处置聚合各类安全告警信息，大幅缩短故障定位与恢复时间，提升安全事件的响应效率。

- **AI 威胁情报**：引入 AI 引擎深度分析威胁行为，可精准识别高级持续性威胁及各类未知威胁，提升威胁检测的前瞻性与准确性。


## 4.4 全栈安全网元与国密改造

支持主流安全产品镜像，类型包括：NGFW、漏扫、IPS、WAF、IDS、网络安全审计、APT检测、数审、EDR、防病毒、堡垒机、WEB漏扫、基线核查、日审、等保综合检查服务、网页防篡改、api审计、数据防泄漏、数据库安全防护网关
支持超大流量场景的云防火墙网元组，以集群形式提供防火墙服务。支持配置云墙的访问控制、入侵防护、防病毒、WEB防护、应用过滤、上网行为审计、WEB漏洞扫描等策略

支持多种流量检测模式，包括标准流量、WAN流量、LAN国密流量、LAN商密等流量检测

支持多种应用交付模式，包括应用国密改造、应用商密改造、商密改国密、国密改商密等。

# 4. 内生安全与云安全服务中心

融合边缘云的安全体系需要同时覆盖中心云、区域云和边缘节点。Cloudmap 将身份权限、网络隔离、流量编排、安全网元、主机防护、日志审计和国密/等保相关能力纳入统一管理，目标是在多站点分布式部署下保持一致的安全策略和可追溯能力。

## 4.1 自动化安全资源池与服务市场

Cloudmap 将异构安全能力池化，通过安全服务市场向租户提供防火墙、WAF、IPS、堡垒机等安全服务。租户可按权限申请安全能力，管理员可结合业务网络、VPC、子网和安全域完成审批与编排。

- **服务开通**：平台将安全服务申请、资源分配、策略关联和状态跟踪纳入统一流程，减少人工跨系统配置。
- **策略编排**：基于 Cloudmap 原生网络拓扑，将指定流量牵引至安全网元，实现安全域划分、访问控制、审计或阻断。
- **异构兼容**：可纳管自研或第三方安全网元，支持项目中的存量设备利旧。不同厂商能力边界以实际适配清单为准。

## 4.2 安全流量编排

平台基于 SDN 技术实现流量牵引，支持阻断型、审计型和旁路检测型服务链。安全策略可覆盖 VPC 内、跨 VPC、南北向和边缘站点访问等路径。

- **VPC 内流量编排**：对同一 VPC 内不同子网间的互访流量进行检测和控制，支持基于源地址、目的地址、端口和协议的流量分类。
- **跨 VPC 流量编排**：针对跨虚拟私有云通信构建服务链路径，通过集中策略管理减少租户间策略冲突。
- **南北向流量编排**：结合 NAT 网关、负载均衡和边界安全网元，对外部访问和出站访问进行统一转发、检测和审计。
- **边缘站点流量治理**：边缘节点可按本地业务需求部署安全网元或接入中心策略。对链路带宽、现场网络拓扑和监管边界有特殊要求的项目，应在实施阶段单独规划。
- **服务链高可用**：服务链可按项目配置多路径冗余和带宽扩展策略，主路径异常时按预设策略切换，降低单点网元故障对业务的影响。

## 4.3 云安全中心与态势感知

云安全中心向租户和管理员提供统一安全运营视图，覆盖资产识别、风险检测、告警聚合、事件处置和审计回溯。

- **安全总览**：整合漏洞、病毒、入侵攻击、基线风险等数据，形成中心云、区域云和边缘节点的安全视图。
- **资产管理**：统一管理云内资产、线下资产和边缘资产，记录主机、端口、进程、中间件、软件版本等指纹信息。
- **事件处置**：聚合告警、资产、策略和处置记录，支撑问题定位、责任追溯和合规审计。
- **威胁分析**：可结合规则、威胁情报和 AI 分析能力识别异常行为；检测效果受数据源完整性、规则质量和项目部署范围影响。

## 4.4 数据安全与合规控制

边缘云场景中，数据通常来源于现场设备、业务系统、视频流、日志和模型交互记录。Cloudmap 通过数据驻留、访问控制、传输保护、备份恢复和审计留痕支撑数据安全管理。

- **数据驻留**：业务数据、模型权重、日志和备份可按项目策略保留在中心、区域或边缘本地，满足本地化处理要求。
- **访问控制**：通过租户、组织、角色和 API 权限限制资源访问范围，关键操作记录审计日志。
- **传输保护**：跨站点访问、远程运维和备份链路应结合专线、VPN、证书和加密策略规划。
- **合规适配**：等保、国密、数据安全和个人信息保护相关要求需要结合客户制度、项目范围和第三方安全产品共同落地，平台提供基础能力和集成入口。

## 4.5 全栈安全网元与国密改造

平台支持多类安全产品镜像和安全网元，包括 NGFW、漏洞扫描、IPS、WAF、IDS、网络安全审计、APT 检测、EDR、防病毒、堡垒机、基线核查、网页防篡改、API 审计、数据防泄漏和数据库安全防护网关等。

面向高流量场景，可按项目部署云防火墙网元组，以集群方式提供访问控制、入侵防护、防病毒、Web 防护、应用过滤、上网行为审计和漏洞扫描等策略。平台也可按项目支持标准流量、WAN 流量、LAN 国密流量和 LAN 商密流量检测，以及应用国密改造、应用商密改造等交付模式。

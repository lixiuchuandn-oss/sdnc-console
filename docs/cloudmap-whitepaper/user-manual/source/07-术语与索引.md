# 六、术语与索引

---

## 1. 常用术语

完整释义见 **《技术白皮书》第 8 章**。下表为手册高频词：

| 术语          | 说明                                         |
| ------------- | -------------------------------------------- |
| Compute Tower | 本 Web 管控平台                              |
| Cloudmap OS   | 资源池侧超融合软件栈                         |
| 资源池        | 接入的一套 Cloudmap/Harvester 集群           |
| 项目          | Kubernetes 命名空间                          |
| 云主机实例    | 池内 VM 列表页名称                           |
| NUMA 亲和     | Guest NUMA 自动映射或手动拓扑                |
| HugePages     | 大页内存（2 MiB / 1 GiB）                    |
| StorageClass  | 存储类，决定卷后端                           |
| NAD           | NetworkAttachmentDefinition，多网卡/直通网络 |
| VPC           | Kube-OVN 逻辑私有网络                        |
| RBAC          | 角色权限；按钮随 write 隐藏                  |
| DRS           | 动态资源调度，自动迁移 VM                    |
| 故障域        | 节点分组，供调度与副本分散                   |

# 四、平台管理

本章说明 Cloudmap 资源池之外的平台级管理入口，包括多云管理与资源池列表、租户管理、系统设置与用户权限。

## 1. 多云管理与资源池列表

**入口**：`顶部导航栏 > 多云管理 > 资源池管理`

**适用角色**：平台管理员；须具备资源池列表读权限，新增、编辑、删除资源池须具备对应写权限。

### 1.1 查看资源池列表

1. 进入 **多云管理**。
2. 打开 **资源池管理**，查看已接入资源池的名称、类型、状态、端点、创建时间等字段。
3. 使用搜索、筛选与 **Reload** 刷新列表。
4. 单击资源池名称进入对应池内详情。

### 1.2 新增资源池

1. 单击 **新增资源池**。
2. 选择云平台类型；Cloudmap 场景选择 **私有云 > Cloudmap**。
3. 填写名称、端点、API 令牌等连接信息。
4. 执行 **连接测试**；通过后提交保存。
5. 回到资源池列表确认状态为在线或可访问。

### 1.3 编辑与删除

1. 在资源池行操作中选择 **编辑**，修改名称、端点、令牌或 TLS 校验策略。
2. 修改连接信息后重新执行连接测试。
3. 删除资源池前确认没有租户、项目或业务流程依赖该池。

**注意**：若未开通多云管理授权，资源池列表菜单可能不显示；可使用第二章的顶栏单池接入路径。

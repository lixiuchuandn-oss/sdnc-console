## 5. 云监控

**参见白皮书**：3.14 统一运维可观测能力。

---

### 5.1 运维监控

**入口**：`云监控 > 运维监控`（path：`monitoring_alerts/alerts-list`）

页顶 **视图 Tag** 在 **集群概览 / 云主机概览 / 云主机资源 / 节点概览** 间切换；右侧 **时间范围**、**自动刷新** 与 **Reload** 作用于当前视图。

![运维监控 — 集群概览](assets/ch03-monitoring/ops-dashboard-cluster-tab.png)

1. 默认进入 **集群概览**：查看池级 **CPU/内存/存储/inode** 等资源大盘。
2. 切换到 **节点概览** 查看各物理节点利用率与状态分布。

![运维监控 — 节点概览](assets/ch03-monitoring/ops-dashboard-nodes-tab.png)

3. 选择 **时间范围** 后图表按区间重绘。
4. **Reload** 触发对端 Prometheus `query_range` 拉取，勿仅用浏览器缓存判断指标是否恢复。

---

### 5.2 运维告警（告警中心）

**入口**：`云监控 > 运维告警`（path：`monitoring_alerts/ops-alert-dashboard`）

页顶 **Tag 切换** 与 **下拉菜单** 组织子视图（无独立侧栏 Tab）：

#### （1）告警中心概览

1. 单击 **告警中心概览** Tag。
2. 查看 **Firing / Pending** 汇总卡片与告警列表。
3. 工具栏 **自动刷新**（间隔可选）与 **手动刷新**。
4. 单击单条告警查看标签、描述、开始时间。

![告警中心概览](assets/ch03-monitoring/ops-alert-overview.png)

#### （2）告警管理（下拉）

| 子页         | 操作                                                 |
| ------------ | ---------------------------------------------------- |
| **告警分组** | 查看/编辑 Alertmanager 分组规则                      |
| **告警规则** | **PrometheusRule** 列表；创建/编辑 PromQL 或阈值规则 |

![告警管理菜单](assets/ch03-monitoring/ops-alert-rules-menu.png)

![告警规则列表](assets/ch03-monitoring/ops-alert-rules-page.png)

#### （3）通知管理（下拉）

| 子页         | 操作                               |
| ------------ | ---------------------------------- |
| **通知策略** | 路由、抑制、分组策略               |
| **通知对象** | 邮件、Webhook、钉钉等 **Receiver** |
| **通知密钥** | Webhook 鉴权 Secret 等敏感配置     |

![通知管理菜单](assets/ch03-monitoring/ops-notification-policy-menu.png)

![通知策略列表](assets/ch03-monitoring/ops-notification-policy-page.png)

**权限**：各子页按 RBAC 显隐；无 write 时 **创建/编辑/删除** 按钮隐藏（非置灰）。

#### 告警处置（概览内）

1. 列表筛选 **Firing / Pending / Resolved**。
2. **确认 / 静默**（须 write；按钮不显示即无权限）。

---

### 5.3 接入管理

**入口**：`云监控 > 接入管理`（path：`monitoring_alerts/access-management`）

1. 查看 **Prometheus** 实例健康、保留时长与 **抓取任务** 列表。
2. 配置 **Prometheus / Alertmanager** 等监控栈接入参数（以页面表单为准）。
3. 保存后 **运维监控**、**运维告警** 数据源生效。

![接入管理](assets/ch03-monitoring/access-management-page.png)

---

### 5.4 云主机性能

**入口**：`云主机详情抽屉 > 性能 Tab`（`compute/ecs` 列表单击名称）

1. 切换 **CPU / 内存 / 网络 / 磁盘** 图表。
2. 选择 **时间范围**（预设或自定义）。
3. 抽屉顶栏 **Reload** 刷新 VM 聚合数据。

![云主机详情 — 性能 Tab](assets/ch03-vm-detail/vm-detail-tab-performance.png)

### 3.2.5 GPU 与设备直通

**参见白皮书**：3.2.5 高性能硬件直通。

---

#### 一、创建向导 · GPU

**入口**：`创建向导 > 计算与规格 > GPU分配`（折叠面板）

**步骤**：

1. **模式** 按钮组：**无 / 直通 GPU / vGPU / SR-IOV GPU**（以集群纳管为准，缺项则不显示）。
2. 模式非 **无** 时，下方表格列出可用设备：**节点、地址、型号** 等。
3. **单选** 一行 GPU；**指定主机** 时仅选该主机上的卡。
4. 可与 **NUMA、大页** 同配（建议性能场景一并配置，见 3.2.2、3.2.3）。
5. **Reload** 图标可刷新 GPU 列表。

---

#### 二、改配 · GPU 管理

**入口**：`详情抽屉 > 资源配置 > GPU管理`

1. 挂载或更换 GPU 设备。
2. 保存后可能须 **关机** 再启动生效（视设备类型）。
3. 直通 GPU 绑定物理节点，**热迁移** 受限。

---

#### 三、USB / PCI / SR-IOV 直通

##### 集群查看与纳管

| Tab | path | 操作 |
| --- | ---- | ---- |
| **USB设备** | `cluster/cluster_usb` | 列表 PermittedHostDevices；**Reload** |
| **PCI设备** | `cluster/cluster_pci` | PCI 地址、节点、是否已分配 |
| **网卡（SR-IOV）** | `cluster/cluster_sriov` | VF/PF 列表；SR-IOV 网卡直通 |

**集群 Tab 为只读纳管视图**；启用直通须在 Harvester **Settings / KubeVirt permitted devices** 配置（运维侧）。

##### 挂载到云主机

| 设备 | 创建 | 改配 |
| ---- | ---- | ---- |
| **USB** | 向导 **高级设置** | `资源配置 > USB管理` |
| **PCI** | 向导 **网络与连接** 直通 / 高级 | 网卡或 PCI 抽屉 |
| **SR-IOV 网卡** | 向导 **网络与连接** | `网卡管理` |

**注意**：直通设备与 **运行节点** 绑定；改 **指定主机** 前须先卸载设备。

---

#### 四、集群 GPU 管理

**入口**：`集群 > 计算资源 > GPU 管理`

查看全集群 GPU 占用，创建前核对余量。

## 3.3.1 统一存储部署与 Ceph 运维

**参见白皮书**：3.3.1 统一存储部署、3.3.2 全闪加速、3.3.5 存储池 QoS、3.3.8 存储运维。

**入口**：`集群 > 统一存储` 分组下 Tab（侧栏 **存储概览、存储配置** 等）

---

### 3.3.1.1 存储概览

**Tab**：`集群 > 统一存储 > 存储概览`（path：`cluster/overview`）

1. 查看 Rook/Ceph **健康状态、容量、Pool、OSD** 等仪表盘卡片。
2. 图表含 IOPS/吞吐等（依赖 Ceph Dashboard 可达时合并展示）。
3. **Reload** 刷新 bundle 与监控数据。

**结果**：只读总览；**部署/改配** 在 **存储配置**。

---

### 3.3.1.2 首次部署统一存储（存储配置向导）

**Tab**：`集群 > 统一存储 > 存储配置`（path：`cluster/harvester_addon`）

**适用角色**：`clouds.storage-addon:write` 或 `clouds:write`。

**前置**：各节点磁盘未被错误占用；网络规划就绪。

**向导五步**（顶栏 Steps）：

| 步  | 名称           | 操作要点                                                                               |
| --- | -------------- | -------------------------------------------------------------------------------------- |
| 1   | **存储网**     | 可选专用存储 VLAN/ClusterNetwork；**不启用则与管理网 mgmt 共用**                       |
| 2   | **存储节点**   | 为每个节点 **勾选数据盘**（BlockDevice）；建议各节点盘数一致                           |
| 3   | **集群服务**   | **MON/MGR** 数量；内置监控面板、严格副本校验等                                         |
| 4   | **容量与策略** | **副本数、压缩、OSD 引擎、每盘 OSD 数**；StorageClass **回收策略、分配模式、在线扩容** |
| 5   | **确认提交**   | 核对摘要 → **提交** → 等待部署完成                                                     |

**注意**：

- 步间 **下一步** 会校验；磁盘不足或网络未选会提示。
- 部署进行中表单可能 **禁用**；完成后进入 **运维 Tab** 视图。

---

### 3.3.1.3 已部署 · 运维 Tab（存储配置页内）

部署完成后，**存储配置** 页切换为 **Tabs**：

#### （1）配置详情

- 只读展示当前 MON 数、副本、压缩、StorageClass 策略、存储网等摘要。

#### （2）存储池

**Tab 内子页**：`存储池`

1. 查看 Rook **CephBlockPool** 列表：名称、副本、应用。
2. **创建 / 编辑 / 删除** Pool（须 write；删除为高风险，有二次确认）。
3. **Reload** 同步 Rook bundle。

#### （3）扩容存储

1. **刷新磁盘** 拉取最新 BlockDevice。
2. **添加节点** 为尚未参与存储的节点增加数据盘配置。
3. 在 **节点磁盘编辑器** 中勾选 **新增磁盘**（**已纳入集群的磁盘不可移除**）。
4. **提交** 触发扩容（确认弹窗）。

#### （4）变更存储网

1. 配置 **Ceph 存储网**（VLAN、ClusterNetwork、CIDR 等；与 Harvester Setting `ceph-storage-network` 对齐）。
2. **保存存储网配置**（确认弹窗）；变更对 **新部署/扩容** 生效，存量 OSD 不自动迁移。

#### （5）SDRS 策略

1. 查看/编辑 **存储 DRS** 指标策略（存储负载均衡）。
2. 启用/禁用规则。

#### （6）任务日志 (N)

查看 SDRS 相关 **任务执行日志**；**Reload** 刷新。

| Tab              | 入口                             | 操作                                                            |
| ---------------- | -------------------------------- | --------------------------------------------------------------- |
| **StorageClass** | `集群 > 统一存储 > StorageClass` | 查看/创建 SC；标记默认类；云盘创建时引用                        |
| **RBD Mirror**   | `集群 > 统一存储 > RBD Mirror`   | 查看镜像同步 CR；行操作 **详情/YAML**；跨集群复制见白皮书 3.3.7 |

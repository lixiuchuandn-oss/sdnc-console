## 3.4.4 VPC 网络操作

**参见白皮书**：3.4.3 VPC。

**前置**：License 启用 **`network.ovn.vpc`**；无特性时 **VPC网络** 侧栏不显示。

**入口**：`VPC网络` 侧栏分组（5 个 Tab）

---

### 3.4.4.1 VPC

**Tab**：`VPC`（`kube_ovn/vpcs`）

**适用角色**：`clouds.vpcs:read` / write。

1. **创建 VPC**：
   - 名称、**命名空间（项目）**、静态路由/DNS 等（以表单为准）。
2. **编辑 / 删除**：删除前须无子网/资源依赖。
3. **详情**：查看关联 **子网** 列表。
4. **Reload** 同步。

---

### 3.4.4.2 子网

**Tab**：`子网`（`kube_ovn/subnets`）

1. **创建**：
   - 选择 **VPC**、填 **CIDR**、网关、**可用区/命名空间**。
   - **私有/公有** 子网类型（以界面为准）。
2. **编辑**：改 DNS、排除 IP 段。
3. **删除**：确认；须无 VM 网卡占用。
4. **详情抽屉**：CIDR、**子网 → 虚拟机** 拓扑（只读）。

**使用 VM**：向导 **网络与连接** 选 **VPC 子网**（3.2.8）。

---

### 3.4.4.3 弹性公网 IP

**Tab**：`弹性公网 IP`（`kube_ovn/kubeovn_eips`）

1. **创建 EIP**（VPC 域）。
2. **绑定** 到 VPC 内 **VM 网卡** 或 **NAT 规则**。
3. **解绑 / 删除** 按行操作。

与 **扁平网络 EIP** 分表管理，勿混用 Tab。

---

### 3.4.4.4 SNAT

**Tab**：`SNAT`（`kube_ovn/kubeovn_snat`）

1. **创建**：VPC 内网段 **出公网**；选 EIP、源 CIDR。
2. **编辑 / 删除** 规则。

---

### 3.4.4.5 DNAT

**Tab**：`DNAT`（`kube_ovn/kubeovn_dnat`）

1. **创建**：EIP + 外部端口 → 内网 IP:端口。
2. 用于暴露 VPC 内 Web/SSH 等服务。

---

### 3.4.4.6 与扁平网络对比

| 项       | 扁平网络         | VPC 网络             |
| -------- | ---------------- | -------------------- |
| 侧栏     | `扁平网络`       | `VPC网络`            |
| 隔离     | 扁平 L2 子网     | 逻辑 VPC + 子网      |
| 边界     | 扁平 Tab EIP/NAT | VPC Tab EIP/NAT      |
| 特性开关 | 一般默认开启     | 须 `network.ovn.vpc` |

### 3.2.7 生命周期、快照与镜像

**参见白皮书**：3.2.7 全生命周期管理、3.3.4、3.8。

---

#### 一、电源与生命周期（详情抽屉工具栏）

**入口**：打开 **云主机详情抽屉** 顶栏工具栏

| 按钮             | 条件                   | 说明                      |
| ---------------- | ---------------------- | ------------------------- |
| **打开终端**     | 运行中；须控制台写权限 | 浏览器内 serial/终端      |
| **开机**         | 已关机                 | 启动 VM                   |
| **关机**         | 运行中                 | 优雅关机                  |
| **重启**         | 运行中                 | 重启来宾                  |
| **暂停 / 恢复**  | 运行中 / 已暂停        | 暂停 vCPU                 |
| **… > 强制停止** | 运行中                 | 相当于断电                |
| **… > 删除**     | —                      | 删除；可能进入 **回收站** |

**… > 热迁移**：仅 **运行中** 且具备写权限；选择目标节点（若需）。

---

#### 二、创建向导 · 存储与磁盘 / 网络（交叉引用）

| 步骤           | 手册要点                                     |
| -------------- | -------------------------------------------- |
| **存储与磁盘** | 系统盘 + 多块数据盘；见 3.3                  |
| **网络与连接** | 扁平 / VPC / NAD 网卡；见 **3.2.8**、**3.4** |
| **登录与凭据** | SSH 密钥、admin 密码                         |
| **高级设置**   | CloudInit、USB、启动策略；见 3.2.6           |

---

#### 三、镜像与模板

##### 云主机镜像

**入口**：`云主机 > 云主机镜像`

1. **上传**：工具栏上传按钮；大镜像显示 **上传任务** 进度。
2. **Windows** 环境可使用 **ImageUploader** 工具（实施文档）。
3. **标签**：支持 **删除 / 重命名** 镜像标签。
4. 创建 VM 时 **存储与磁盘** 步选择镜像。

##### 云主机模板

**入口**：`云主机 > 云主机模板`

1. 从现有 VM 导出或新建模板。
2. **创建向导** 或 **快速创建** 时选择模板快速部署。

---

#### 四、回收站

**入口**：`云主机 > 回收站`

1. 查看已删除实例。
2. **恢复**：还原到 **云主机实例** 列表。
3. **彻底删除**：不可恢复。

---

#### 五、备份与快照（云主机维度）

**入口 A**：`详情抽屉 Tab > 备份/快照`

**入口 B**：`云备份 > 云主机备份 / 云主机快照`

1. **创建备份** 或 **创建快照**（须写权限）。
2. 填写名称、保留策略（视弹窗字段）。
3. 成功后 Tab 列表刷新；亦可在 **云备份** 全局 Tab 查看。

详见 **3.9**。

---

#### 六、迁移记录

**入口**：`云主机 > 高级配置 > 迁移记录`

查看该池 VM 迁移历史；DRS 记录在 **计算配置 > 迁移记录**（见 3.1.3）。

---

#### 七、CloudInit 与 SSH

| 能力               | 入口                                                   |
| ------------------ | ------------------------------------------------------ |
| **SSH 密钥**       | `云主机 > SSH 密钥`；创建时在 **登录与凭据** 引用      |
| **CloudInit 配置** | `云主机 > CloudInit 配置`；详情 **… > CloudInit 管理** |
| **虚拟机间亲和**   | 创建 **基本信息** 或 **… > 虚拟机间亲和性**            |

---

#### 八、诊断

**入口**：`… > 诊断工具`

| 能力          | 说明                                                                           |
| ------------- | ------------------------------------------------------------------------------ |
| **运行诊断**  | 聚合调度、资源、事件等信息排障                                                 |
| **查看 YAML** | 只读 VM CR（运维/advanced）                                                    |
| **实时日志**  | 若菜单提供 **实时日志**，打开 `VmRealtimeLogsDrawer` 查看 serial/virtio 日志流 |

---

#### 九、调度可观测

**云主机实例** 列表 **告警指纹** 列（若有）：展示 HSM 自动调度相关标签，与 **资源总览** 策略对照排查（白皮书 3.2.7）。

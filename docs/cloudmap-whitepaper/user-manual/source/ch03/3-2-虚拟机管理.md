## 3.2 虚拟机管理

**参见白皮书**：3.2 新一代计算虚拟化。

**主入口**：`Cloudmap 资源池 > 云主机 > 云主机实例`

---

### 3.2.0 列表页操作总览

**适用角色**：具备 `clouds.ecs:read`；写操作须 `clouds.ecs:write` 或 `clouds:write`。

#### 筛选与刷新

1. 左侧搜索框按名称过滤；**状态**、**项目** 等下拉筛选。
2. 单击 **重置** 清空筛选。
3. 右侧 **Reload** 从集群同步列表。

#### 创建入口

列表右上角工具栏提供两种建机方式（须 `clouds.vm-quick-create:write` / `clouds.vm-create-wizard:write`）：

| 按钮         | 说明                           |
| ------------ | ------------------------------ |
| **快速创建** | 简化表单，适合常规规格快速建机 |
| **创建向导** | 六步完整向导（推荐复杂场景）   |

无写权限时两按钮均 **不显示**。

![云主机列表创建入口](assets/ch03-vm/vm-list-toolbar.png)

**快速创建** 在列表页弹出单页表单，填写项目、镜像、规格与扁平子网后即可提交：

![快速创建弹窗](assets/ch03-vm/vm-quick-create-modal.png)

**创建向导** 打开全屏 Modal，左侧为六步步骤条，右侧为配置摘要与 **上一步 / 下一步 / 创建**（见下文各步截图）。

#### 打开详情

1. 单击表格 **名称** 列链接，打开右侧 **详情抽屉**。
2. 抽屉内 Tab：**详情** / **性能** / **备份/快照**。

#### 行操作

行末 **…** 菜单常见：**开机 / 关机 / 删除 / 创建备份** 等（视状态与权限）。

后续小节按 **创建向导** 六步与 **详情改配** 分述；**侧栏 Tab 全索引** 见 **3.0**；**详情抽屉** 见 **3.2.12**。

---

### 创建向导六步一览

左侧步骤条顺序（可点击切换，离开当前步会校验）：

| 序号 | 步骤名称       | 主要内容                                                | 详见 |
| ---- | -------------- | ------------------------------------------------------- | ---- |
| 1    | **基本信息**   | 资源池、项目、运行位置、名称、故障域/节点、虚拟机间亲和 | **3.2.1**  |
| 2    | **计算与规格** | CPU/内存、热扩容、CPU 高级、NUMA、大页、GPU             | **3.2.2**～**3.2.5** |
| 3    | **存储与磁盘** | 系统盘来源、数据盘                                      | **3.2.9**  |
| 4    | **网络与连接** | 网卡、扁平/VPC/NAD                                      | **3.2.8**  |
| 5    | **登录与凭据** | SSH 密钥、密码                                          | **3.2.10** |
| 6    | **高级设置**   | 启动策略、固件/TPM、USB                                 | **3.2.11** |

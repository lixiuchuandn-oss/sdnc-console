## 3.4 网络服务

**参见白皮书**：3.4 网络服务。

**集群侧物理/集群网络**见 **3.4.1**。**平台网络**见 **3.4.2**。**扁平网络**逐步操作见 **3.4.3**。**VPC** 见 **3.4.4**。**虚拟网元**见 **3.4.8**。

---

### 3.4.1 公共子网与物理网络

#### 物理网络

**入口**：`集群 > 基础网络 > 物理网络`（`cluster/kubeovn_public_networks`）

1. **创建** ProviderNetwork：名称、默认网卡、VLAN 等。
2. 保存后供 **公共子网**、**NAD** 引用。

#### 公共子网

**入口**：`集群 > 基础网络 > 公共子网`（`cluster/kubeovn_public_subnets`）

1. **创建** 子网：CIDR、网关、关联物理网络。
2. 供 **弹性 IP、NAT** 等边界能力使用。

#### VLAN / 交换机 / 集群网络

**入口**：`集群 > 基础网络 > VLAN`、`交换机`；`平台网络 > 集群网络`

操作步骤见 **3.4.1 集群基础网络**。

---

### 3.4.2 扁平子网（概要）

**专章**：**3.4.3 扁平网络操作**（扁平子网、安全组、EIP、SNAT、DNAT 逐步说明）。

**入口**：`扁平网络 > 扁平子网`

1. **创建** 扁平网段。
2. 创建云主机 **网络与连接** 步选择 **扁平** 模式并选子网。
3. **安全组**：`扁平网络 > 安全组` 创建规则并关联网卡。

---

### 3.4.3 VPC 与子网（概要）

**专章**：**3.4.4 VPC 网络操作**。

**前置**：License/特性启用 **VPC**（`network.ovn.vpc`）。

**入口**：`VPC网络 > VPC`

1. **创建 VPC**，填写名称、命名空间等。
2. **子网**：`VPC网络 > 子网`，选 VPC、填 CIDR、网关、DNS。
3. 创建 VM 时 **网络与连接** 选 **VPC** 及子网。

---

### 3.4.4 NAD 与多网卡

**NAD / IP 地址池 / 集群 LB** 见 **3.4.2**。

**入口**：`集群 > 平台网络 > NAD 网络`

1. 创建 **NetworkAttachmentDefinition**。
2. 创建向导 **网络与连接**：**添加网卡**，类型选 **NAD / SR-IOV** 等。
3. **IP 地址池**：`IP 地址池` Tab 管理地址段。

**改配**：`详情 > 资源配置 > 网卡管理` 增删改网卡、MAC、模型。

---

### 3.4.5 边界服务（EIP / NAT / 负载均衡）

#### 扁平网络边界

| 能力            | 入口                     |
| --------------- | ------------------------ |
| **弹性公网 IP** | `扁平网络 > 弹性公网 IP` |
| **SNAT**        | `扁平网络 > SNAT`        |
| **DNAT**        | `扁平网络 > DNAT`        |

#### VPC 边界

| 能力            | 入口                    |
| --------------- | ----------------------- |
| **弹性公网 IP** | `VPC网络 > 弹性公网 IP` |
| **SNAT / DNAT** | 对应 Tab                |

**典型操作**：

1. **申请 EIP** → **绑定** 到 VM 网卡或 LB。
2. **SNAT**：内网出公网；**DNAT**：公网映射到内网 IP:端口。

#### 集群负载均衡

**入口**：`集群 > 平台网络 > 负载均衡`（`cluster/load_balancers`）

创建 LB、监听器、后端池（Harvester/Kube-OVN CR，以界面表单为准）。

**虚拟网元侧 LB** 见 **3.4.8**。

---

### 3.4.6 安全组

**入口**：`扁平网络 > 安全组`（扁平）；VPC 侧安全组在 Kube-OVN 相关 Tab（若有）

1. **创建** 安全组。
2. **添加入站/出站规则**：协议、端口、源/目的 CIDR。
3. 创建 VM 或 **网卡管理** 时关联安全组。

---

纳管与配置 VR 实例（与 SDN 控制面对接）。**操作步骤见 3.4.8**。

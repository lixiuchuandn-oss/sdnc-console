## 3.4.2 平台网络（NAD / 负载均衡 / IP 地址池）

**参见白皮书**：3.4.3、3.4.4、3.4.5。

**入口**：`集群 > 平台网络` 侧栏分组

---

### 3.4.2.1 NAD 网络

**Tab**：`NAD 网络`（`cluster/nads`）

**适用角色**：`clouds.nads:read` / write。

1. **列表**：NetworkAttachmentDefinition；命名空间、名称、类型（bridge/macvlan/sriov 等）。
2. **创建**：
   - 选 **命名空间**、填 **名称**。
   - 选 **网络类型**、关联 **ClusterNetwork / VLAN** 或 CNI 配置（以表单为准）。
   - **确定** 写入 CR。
3. **编辑 / 删除**：行操作（删除有确认）。
4. **YAML**：查看/编辑 manifest。
5. **Reload** 同步 Harvester 网络缓存。

**使用**：创建向导 **网络与连接** 选 **NAD**；直通 SR-IOV 见 **3.2.8**、**3.2.5**。

---

### 3.4.2.2 IP 地址池

**Tab**：`IP 地址池`（`cluster/ippools`）

1. **列表**：Harvester **IPPool**；CIDR、已分配数、状态。
2. **创建**：
   - 名称、**CIDR 或 IP 范围**、关联网关/DNS（以表单为准）。
   - 供 **LoadBalancer Service** 或平台 LB 自动分配 VIP。
3. **编辑 / 删除**：须 write。
4. **Reload** 刷新。

**注意**：与 **Kube-OVN EIP**（扁平/VPC Tab）不同；IPPool 面向 **Harvester LB** 等集群内分配。

---

### 3.4.2.3 集群负载均衡

**Tab**：`负载均衡`（`cluster/load_balancers`）

1. **列表**：Harvester LoadBalancer CR / Kube-OVN LB 资源（以界面列为准）。
2. **创建**：
   - 名称、命名空间、**监听端口/协议**。
   - **后端池**：Pod 或 VM IP:端口。
   - 关联 **IP 地址池**（若需自动 VIP）。
3. **编辑**：改监听、成员、健康检查。
4. **删除**：行操作 + 确认。
5. **Reload** 同步。

**与虚拟网元 SLB**（`oniaas_network/slb`）区别见 **3.4.8**。

---

## 10. 容器服务

**参见白皮书**：3.5 云原生容器全栈管理。

**入口**：`Cloudmap 资源池 > 容器服务`

**通用**：各 Tab 列表支持 **搜索、筛选、Reload**；写操作须对应 `clouds.containers.*:write`；无权限时 **创建/删除/YAML 保存** 不显示。

---

### 10.1 工作负载

**Tab**：`容器服务 > 工作负载`（`containers/workloads`）

#### 列表

- 类型：**Deployment / StatefulSet / DaemonSet**（Tab 或类型筛选）。
- 列：名称、命名空间、就绪副本、镜像、创建时间。

#### 创建 Deployment 示例

1. 工具栏 **创建** → 选 **Deployment**。
2. **基本信息**：名称、**命名空间**、副本数。
3. **容器**：镜像、拉取策略、**CPU/内存 requests & limits**。
4. **高级调度**（展开）：
   - **nodeSelector**、**节点亲和/反亲和**；
   - **Pod 亲和/反亲和**；
   - **污点容忍**。
5. **确定**；就绪副本等于期望副本即 **Available**。

#### 行操作

| 操作       | 说明                                 |
| ---------- | ------------------------------------ |
| **编辑**   | 表单改镜像、副本、资源               |
| **扩缩容** | 改 `replicas`                        |
| **YAML**   | 直接编辑 manifest                    |
| **删除**   | 级联删 Pod（StatefulSet 须注意 PVC） |

**StatefulSet**：须配置 **volumeClaimTemplates**；删 STS 不自动删 PVC。

**DaemonSet**：每节点一 Pod；用于日志/监控 Agent。

---

### 10.2 容器实例（Pod）

**Tab**：`容器服务 > 容器实例`（`containers/pods`）

1. **列表**：Phase、节点、重启次数、所属工作负载。
2. **单击名称**：
   - **详情**：容器状态、事件、资源。
   - **日志**：`PodLogViewer` 流式日志；选容器名、Previous 实例。
   - **终端**：`PodTerminal` Web 终端（须容器 running 且镜像含 shell）。
3. **删除 Pod**：Deployment 下 Pod 会自动重建。

---

### 10.3 任务

**Tab**：`容器服务 > 任务`（`containers/jobs`）

#### Job

1. **创建**：镜像、命令、**completions/parallelism**、**backoffLimit**。
2. 查看 **Succeeded/Failed** 计数；失败看 **事件**。

#### CronJob

1. **创建**：**Cron 表达式**、Job 模板（镜像、命令）。
2. **挂起/恢复**：行操作 **suspend**。
3. 查看 **最近调度时间** 与衍生 Job 列表。

---

### 10.4 服务、Ingress 与网关

#### 服务

**Tab**：`containers/services`

1. **创建**：
   - 类型 **ClusterIP / NodePort / LoadBalancer**。
   - **Selector** 匹配 Pod 标签；**端口** 映射 targetPort。
2. **LoadBalancer**：可关联 **IP 地址池**（3.4.2）。
3. **编辑 / 删除**。

#### Ingress 路由

**Tab**：`containers/ingresses`

1. **创建**：Host、Path、**Backend Service**、TLS Secret（HTTPS）。
2. 须集群 **Ingress Controller** 已部署。

#### 网关路由

**Tab**：`containers/gateway_api`

1. **Gateway**：监听端口、协议、**GatewayClass**。
2. **HTTPRoute / GRPCRoute**：绑定 Gateway、规则、后端 Service。
3. 分资源类型 Tab 或筛选创建。

#### 服务拓扑

**Tab**：`containers/service_topology`

- **只读** React Flow 图：Service → Pod 关系。
- 选命名空间、Service；**Reload** 刷新拓扑。

---

### 10.5 配置管理与镜像仓库

#### 配置管理

**Tab**：`containers/configs`

| 子类型        | 操作                                  |
| ------------- | ------------------------------------- |
| **ConfigMap** | 键值对或文件片段；挂载到工作负载      |
| **Secret**    | Opaque/TLS/dockerconfigjson；敏感数据 |

**创建** → 选类型 → 填 data → **确定**。

#### 镜像仓库

**Tab**：`containers/registries`

1. **添加仓库**：Harbor 等 URL、**凭证 Secret**。
2. **浏览镜像**：选仓库 → 列 tags（若 API 支持）。
3. 创建 Pod 时 **imagePullSecrets** 引用该凭证。

---

### 10.6 网络策略与 PDB

#### 网络策略

**Tab**：`containers/networkpolicies`

1. **创建**：
   - **Pod 选择器**（本策略保护哪些 Pod）。
   - **Ingress 规则**：允许来自某命名空间/Pod 的流量。
   - **Egress 规则**：出站限制。
2. 默认拒绝须显式 **allow** 规则。

#### Pod 中断保护

**Tab**：`containers/pdbs`

1. **创建**：选 **工作负载**；设 **minAvailable** 或 **maxUnavailable**。
2. 节点 drain/升级时保证最少可用副本。

---

### 10.7 YAML 与刷新

- 多数资源 **YAML** 按钮：CodeMirror 编辑 → **保存** → 触发池层 **onRefresh(true)**。
- 工具栏 **Reload** 使用 **`createHarvesterToolbarRefresh`** 语义，从集群拉取最新列表。

---

### 10.8 与云主机网络边界

容器 **LoadBalancer/Ingress** 与 **Kube-OVN EIP/NAT**（3.4.3、3.4.4）配合实现南北向流量；Pod 网络默认 CNI 与 VM 扁平/VPC **相互独立**。

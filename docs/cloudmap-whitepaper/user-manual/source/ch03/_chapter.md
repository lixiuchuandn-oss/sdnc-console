# 三、资源池功能

本章按 **Cloudmap 资源池** 侧栏分组组织，目录以控制台实际入口为准。

- **白皮书**：说明能力、架构与价值。
- **本章**：说明 **菜单路径、操作步骤、注意事项**。

阅读路径建议：

1. 首次使用先读 **第二章** 进入资源池；查 Tab 对应章节用下方 **资源池功能索引**。
2. 云主机见 **7. 云主机**；云存储见 **11. 云存储**；网络分别见 **13. 扁平网络** 与 **14. VPC 网络**。
3. 白皮书原 3.x 节号保留在正文 **参见白皮书** 字段中，不作为本手册目录主线。

文中 **入口** 统一写作：`多云管理 > … > Cloudmap 池内 Tab`；池内步骤省略重复前缀时，默认已在当前 Cloudmap 资源池上下文中。

## 3.15 多级边缘管理

**参见白皮书**：3.15 算网大脑与多级边缘管理（架构权威章节）。

---

### 3.15.1 接入多池

**入口**：`多云管理 > 资源池管理`

1. 分别 **接入** **中心 Cloudmap 池** 与 **边缘 Cloudmap 池**（各为独立云实例）。
2. 在 **多云总览**（若启用）查看跨池统计。

---

### 3.15.2 边缘池日常操作

边缘池进入后 **侧栏与中心一致**（3.2–3.14 各节同样适用），但需注意：

| 场景 | 操作注意 |
| ---- | -------- |
| **单节点/三节点** | 创建 VM 时 **副本存储、高可用** 约束更严 |
| **网络** | 边缘可能仅 **扁平网**；VPC Tab 视 License |
| **离线/弱网** | **Reload** 失败时检查链路与边缘 Tower 部署 |
| **升级** | 各站点 **离线升级** 独立执行（系统设置） |

---

### 3.15.3 云边策略

中心统一下发策略、模型、镜像同步等 **控制面能力** 以白皮书 **3.15、3.11.5** 及项目交付说明为准；控制台操作以实际启用的 **算网/边缘** 菜单为准。

---

### 3.15.4 智算边缘

边缘站点部署 **推理实例** 时：优先 **Xinference 池** 或 **GPU 云主机**（3.11）；监控回传见 **3.14**。

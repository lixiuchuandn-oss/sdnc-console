### 7.3 创建虚拟机与运行位置

**参见白皮书**：3.2.1 资源动态调度。

---

#### 一、创建向导 · 步骤「基本信息」

**入口**：`云主机实例 > 创建向导 > 基本信息`

![创建向导第一步-基本信息](assets/ch03-vm/vm-wizard-step-basic.png)

**前置条件**：已选资源池；租户须在 **项目** 列表中有可用命名空间。

**步骤**：

1. **资源池**（自池内创建时通常已锁定，不显示选择框）。
2. **项目**：下拉选择命名空间；打开下拉时会 **重新加载** 项目列表。
3. **运行位置**（三按钮 **块级均分** 一行）：
   - **自动调度**（默认）：平台按资源与策略选择节点。
   - **指定主机**：下方出现 **节点表格**；可搜索、按 Ready 筛选；**单选** 一行作为目标主机。
   - **故障域**：出现 **故障域** 下拉；须选择已创建的故障域，或配置 **节点标签** 键值对（至少一项）。
4. **信息** 区：**名称**（必填）、**描述**（可选）。
5. **高级调度**（运行位置 ≠ 指定主机 时显示）：可配置 **虚拟机间亲和/反亲和**（按其它云主机同宿或分散）。
6. 单击 **下一步**；校验通过后进入 **计算与规格**。

**注意**：

- 租户若提示 **未分配到可用项目**，联系管理员在 **项目管理** 或 **租户管理** 中分配。
- **指定主机** 时，向导内 **虚拟机间亲和** 等部分高级调度不可用。
- 指定主机 + **GPU** 时，须在后续步骤选择该节点上的 GPU。

---

#### 二、指定主机 · 节点表格操作

1. 在 **运行位置** 选 **指定主机**。
2. 使用表格上方 **搜索** 过滤主机名。
3. **状态** 筛选：全部 / 运行中 / NotReady。
4. 单击行首单选框选中目标节点；选中行高亮。
5. 表格列含 CPU/内存 **使用率**（悬停 **?** 可看说明）。

---

#### 三、故障域模式

1. **运行位置** 选 **故障域**。
2. **故障域** 下拉：选择 **计算配置 > 故障域** Tab 中已创建的域。
3. 可选：在 **节点标签** 编辑器增加 `key=value` 条件。
4. 域与标签 **至少填一项**，否则无法下一步。

---

#### 四、已创建云主机 · 修改运行位置

**入口**：`云主机详情抽屉 > … > 调度策略 > 节点选择器`

（界面标题可能为 **节点调度** / **ChangeNodeScheduling**，以抽屉为准。）

**步骤**：

1. 打开云主机 **详情抽屉**。
2. 单击右上角 **…**，展开 **调度策略 > 节点选择器**。
3. 在 Segmented 控件选择 **自动调度 / 固定主机 / 故障域**（文案以界面为准）。
4. 按模式填写固定主机或故障域/标签。
5. **保存**；按策略可能触发迁移或下次启动生效。

**注意**：固定单机会增加单机故障风险；能力说明见白皮书 3.2.1。

---

#### 五、快速创建（简版）

**入口**：`云主机实例 > 快速创建`

1. 在弹窗填写 **项目、名称、镜像、CPU、内存、磁盘、网络** 等必填项。
2. **确定** 提交；适合无 NUMA/多盘/复杂网络的场景。
3. 复杂需求请用 **创建向导**。

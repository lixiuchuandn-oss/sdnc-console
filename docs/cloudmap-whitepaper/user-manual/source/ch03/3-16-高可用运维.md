## 3.16 高可用与业务连续性

**参见白皮书**：3.16 高可用与业务连续性。

---

### 3.16.1 节点故障

**现象**：云主机 **Unknown / 节点 NotReady**、运维告警 firing。

**步骤**：

1. `云监控 > 运维告警` 确认告警。
2. `集群 > 计算配置 > 计算节点` 查看故障节点。
3. 等待 **调度重建**（Eviction/HA 策略）或手动 **热迁移/开机** 到健康节点。
4. 业务仍异常：从 **云备份** 恢复（3.9）。

---

### 3.16.2 计划内维护

1. 节点 **进入维护模式**（3.1.3）。
2. 对该节点 VM 执行 **热迁移** 或 **关机**。
3. 硬件维护完成后 **退出维护模式**。

---

### 3.16.3 数据保护演练

| 步骤 | 入口 |
| ---- | ---- |
| 配置定时备份 | `云备份 > 定时策略` |
| 创建快照 | `云备份 > 云主机快照` 或 `云存储 > 云盘快照` |
| 演练恢复 | `云备份 > 恢复任务` 在 **测试项目** 恢复 VM |
| 验证 RTO | 记录从任务提交到 VM 可用的时间 |

---

### 3.16.4 控制面 HA

Compute Tower 与 Cloudmap **控制面多副本** 属 **部署架构**（安装文档）；控制台 **离线升级** 须在维护窗口执行（系统设置）。

---

### 3.16.5 存储多副本

Longhorn/Ceph **副本数** 在 **StorageClass / 存储配置** 中设置；单副本边缘场景须接受相应 RPO/RTO（白皮书 3.16）。

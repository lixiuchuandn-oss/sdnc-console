## 3.4.3 扁平网络操作

**参见白皮书**：3.4.2 扁平网络。

**入口**：`扁平网络` 侧栏分组（5 个 Tab）

---

### 3.4.3.1 扁平子网

**Tab**：`扁平子网`（`flat_network/flat_public_subnets`）

**适用角色**：`clouds.subnets.flat:read` / write。

1. **创建**：
   - 名称、**CIDR**、网关、DNS。
   - 关联 **ProviderNetwork**（若表单要求）。
2. **编辑**：改描述、DHCP/静态分配策略（以表单为准）。
3. **删除**：须无 VM 占用或先解绑网卡。
4. **详情**：单击名称查看 **子网详情抽屉**（CIDR、已用 IP、关联 VM）。
5. **Reload** 同步 Kube-OVN Subnet。

**使用 VM**：创建向导 **网络与连接** 选 **扁平子网**（3.2.8）。

---

### 3.4.3.2 安全组

**Tab**：`安全组`（`flat_network/security_groups`）

1. **创建** 安全组：名称、描述。
2. **管理规则**：
   - **入站 / 出站** 规则：协议（TCP/UDP/ICMP）、端口范围、源/目的 CIDR。
   - 支持 **允许 / 拒绝**。
3. **关联资源**：创建 VM 或 **网卡管理** 时绑定安全组。
4. **删除** 规则或整组（确认弹窗）。

---

### 3.4.3.3 弹性公网 IP

**Tab**：`弹性公网 IP`（`flat_network/flat_kubeovn_eips`）

1. **申请/创建 EIP**：从 **公共子网** 或地址池分配公网 IP。
2. **绑定**：
   - 行操作 **绑定** → 选 **云主机网卡** 或 LB。
3. **解绑**：释放关联，EIP 可保留或删除。
4. **删除 EIP**：确认后回收地址。

---

### 3.4.3.4 SNAT

**Tab**：`SNAT`（`flat_network/flat_kubeovn_snat`）

**场景**：内网 VM **出公网**（源地址转换）。

1. **创建**：
   - 选择 **EIP** 或公网出口。
   - 指定 **内网 CIDR / 子网 / VM** 作为源。
2. **编辑 / 删除** 规则。
3. **Reload** 刷新 OvnEip/Fip CR 状态。

---

### 3.4.3.5 DNAT

**Tab**：`DNAT`（`flat_network/flat_kubeovn_dnat`）

**场景**：公网 IP:端口 **映射到内网** IP:端口。

1. **创建**：
   - **EIP**、**外部端口**、**内部 IP**、**内部端口**、协议。
2. 保存后外网访问 EIP:Port 转发至内网服务。
3. **删除** 规则释放映射。

---

### 3.4.3.6 典型组网顺序

1. `集群 > 基础网络` 配置 **物理网络 / 公共子网**（3.4.1）。
2. **扁平子网** 创建租户网段。
3. VM 网卡接入扁平子网；可选 **安全组**。
4. 需公网：**EIP → SNAT/DNAT**。

## 3.10 云数据库

**参见白皮书**：3.10 云数据库服务。

**入口**：`Cloudmap 资源池 > 云数据库 > 云 RDS`

---

### 3.10.1 查看实例

1. 进入 **云 RDS** Tab。
2. 列表：实例名、状态、版本、项目、节点等。
3. **搜索 / 筛选 / Reload** 与标准列表一致。

---

### 3.10.2 创建实例

**前置**：PaaS 模板与 StorageClass、网络已就绪。

**步骤**：

1. 工具栏 **创建**（须 `clouds.paas-databases:write` 或等效 write）。
2. 选择 **数据库类型/版本**（模板驱动）。
3. 配置 **CPU、内存、存储、网络（VPC/扁平）**、**管理员密码**。
4. **确定**；列表状态变为 **Running**（或中间 **Creating**）。
5. 创建成功后列表 **自动刷新**。

---

### 3.10.3 实例运维

单击实例名进入 **详情**（若有）：

| 操作 | 说明 |
| ---- | ---- |
| **启停** | 行操作或详情 |
| **改配** | 扩容 CPU/内存/磁盘（视模板支持） |
| **备份** | 跳转或内嵌备份入口（视模板） |

具体按钮以 PaaS Section 实现为准。

---

### 3.10.4 与云主机关系

云 RDS 实例底层多为 **Cloudmap 资源池 VM + 编排模板**；网络与存储排障可交叉参考 **3.2、3.3、3.4**。

## 6. 集群

本节覆盖 Cloudmap 资源池内 **集群** 侧栏分组，包含计算资源、基础网络、平台网络、统一存储、对象存储与直通设备等集群级配置。

**入口**：`Cloudmap 资源池 > 集群`

**使用建议**：

1. 新资源池接入后，先检查 **计算配置 / 项目管理 / GPU 管理**，确认节点、命名空间和硬件资源可用。
2. 配置业务网络前，先完成 **基础网络** 与 **平台网络**。
3. 使用云盘、云数据库或备份前，先确认 **统一存储** 与 **StorageClass** 状态正常。
4. 集群级配置通常需要平台管理员权限；无写权限时创建、编辑、删除按钮不显示。

### 7.5 内存热扩容与大页内存

**参见白皮书**：3.2.3 内存优化。

---

#### 一、创建向导 · 内存与热扩容

**入口**：`创建向导 > 计算与规格`

##### 内存规格

1. **内存** 按钮组：4 GB / 8 GB / 16 GB / **自定义**。
2. 选 **自定义** 后输入 GiB 数值。

##### 热扩容

1. 勾选 **启用 CPU/内存热扩容**。
2. **NUMA 亲和**、**大页内存** 复选框变为 **禁用**；若已勾选会清除并 **提示**。
3. 热扩容与 CPU 拓扑联动，按界面锁定项填写。

##### 内存 QoS（CPU 高级折叠内）

| 项                  | 说明                                                  |
| ------------------- | ----------------------------------------------------- |
| **内存请求 / 上限** | 填 GiB；K8s QoS 语义                                  |
| **内存峰值保护**    | 勾选 **启用**：业务峰值时自动取消「最多使用内存」限制 |

---

#### 二、大页内存（HugePages）

##### 创建向导

1. 在 **大页内存** 行勾选 **启用**。
2. **页大小** 下拉：**2 MiB** 或 **1 GiB**。
3. 单击 **?** 查看：须节点预留 hugepages、降低 TLB 开销等说明。
4. 若同时启用热扩容，无法勾选大页。

##### 改配

**入口**：`… > 性能调优 > 性能设置 > 大页内存`

1. 勾选 **启用**，选择页大小。
2. **确定** 提交。
3. **变更大页通常须重启云主机** 后生效（改配抽屉 Tooltip 有说明）。

##### 约束与排障

| 情况           | 处理                                        |
| -------------- | ------------------------------------------- |
| **1 GiB 大页** | 虚拟机内存须为 **整数 GiB**                 |
| 启动/调度失败  | 到 **计算节点** 查看 hugepages 预留是否足够 |
| 与热扩容       | **互斥**，不可同时启用                      |

---

#### 三、运行中扩容内存（热扩容已启用）

1. 确认详情 Tag 为 **热扩容已启用**（非「待重启」「不可用」）。
2. **资源配置 > 调整规格** 或 **性能设置** 增加内存（不超过 maxMemory）。
3. 运行中提交；观察 **热扩容中** Tag，完成后在来宾 OS 内确认。

**注意**：热扩容不可用常见原因：磁盘非共享存储、挂载阻止迁移的设备等；悬停 Tag 查看具体提示。

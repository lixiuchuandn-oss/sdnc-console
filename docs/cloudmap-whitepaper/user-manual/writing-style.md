# Cloudmap 使用手册 · 写作约束

面向 **运维人员、租户管理员、实施工程师**。与《技术白皮书》分工如下：

| 文档     | 写什么                       | 不写什么                 |
| -------- | ---------------------------- | ------------------------ |
| 白皮书   | 能力、架构、价值、部署形态   | 逐步点击路径、界面字段名 |
| 使用手册 | 菜单路径、操作步骤、注意事项 | 采购话术、架构长论述     |

## 1. 文风

- 第二人称或祈使句：**「进入…」「单击…」「在…中选择」**。
- 短句、编号步骤；一步一事。
- 与白皮书一致：**不虚构**未交付能力；规划项标注 **「规划」** 或 **「选配」**。

## 2. 每条操作说明结构

| 要素         | 说明                                        |
| ------------ | ------------------------------------------- |
| **适用角色** | 管理员 / 租户用户 / 需写权限                |
| **入口**     | 顶栏平台 → 侧栏 → Tab（与现网中文菜单一致） |
| **前置条件** | 资源池已接入、项目已分配、节点 Ready 等     |
| **步骤**     | 1. 2. 3. …                                  |
| **结果**     | 列表出现、状态变更、任务完成                |
| **注意**     | 互斥项、须重启、权限不足时的表现            |
| **参见**     | 白皮书章节号，如「能力说明见白皮书 3.2.2」  |

## 3. 界面路径写法

- 用 **`>`** 连接：`多云管理 > 资源池管理 > 某 Cloudmap 池 > 计算 > 虚拟机`。
- 按钮、Tab、字段名与 **控制台中文文案** 一致，不加英文 slug。
- 权限：无写权限时按钮 **隐藏**（非置灰），手册中注明「需 `xxx:write` 权限」。

## 4. 与白皮书章节对照

使用手册第 3 章 **节号与白皮书 3.x 对齐**，便于交叉引用；手册不复制白皮书整段，只写 **怎么做**。

## 5. 排版

- 一节一文件，目录 `user-manual/source/ch03/`。
- 章 `#`、节 `##`、小节 `###`。
- 截图放在 `source/assets/`（可按模块分子目录），Markdown 使用 `![](assets/xxx.png)`。
- 截图清单与重跑命令见 [SCREENSHOTS.md](SCREENSHOTS.md)；白皮书对照见 [COVERAGE.md](COVERAGE.md)。

## 6. 单条操作模板（复制使用）

```markdown
#### 操作名称

**适用角色**：
**入口**：`多云管理 > …`
**前置条件**：

1. …
2. …

**结果**：…

**注意**：…

**参见**：白皮书 3.x.x
```

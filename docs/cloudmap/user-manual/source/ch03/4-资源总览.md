## 4. 资源总览

**主入口**：`Cloudmap 资源池 > 资源总览`

资源总览面向平台管理员与运维，提供资源池的整体视图与机房、网络拓扑。侧栏含三个项：

| 侧栏项       | 内容                                                        | 章节    |
| ------------ | ----------------------------------------------------------- | ------- |
| **集群总览** | 告警、CPU、内存、存储、物理主机、存储设备、云主机等资源卡片 | **4.1** |
| **机房拓扑** | 机柜内按 U 位排列的设备视图（物理服务器/交换机/占位）       | **4.2** |
| **网络拓扑** | 物理网络与集群网络的连接关系图                              | **4.3** |

说明：集群总览与网络拓扑为只读视图；机房拓扑在具备写权限时可管理机柜与设备。更细的实时指标曲线见 **5 云监控**。

---

### 4.1 集群总览

**适用角色**：具备资源总览读权限的管理员或运维。

**入口**：`资源总览 > 集群总览`

集群总览以卡片汇总资源池的关键状态，分两行展示，多数卡片可单击下钻到对应监控视图。

1. 进入目标资源池，侧栏单击 **集群总览**。
2. 查看第一行卡片：
   - **告警**：可在 **严重告警 / 注意** 间切换，列出告警标题、描述与触发时间。
   - **CPU**：以环图展示已分配比例，并显示总核数、已分配/可用。
   - **内存**：展示可分配、已分配、系统预留与总量。
   - **储存空间**：总容量、使用占比、已用/剩余，并标注默认数据保护模式与保护后可用容量。
3. 查看第二行卡片：
   - **物理主机**：环图中心为总台数，图例区分 **活跃 / 维护中 / 隔离中 / 其他**。
   - **存储设备**：统计存储设备 **已就绪 / 异常 / 其他**。
   - **云主机**：总数及 **运行中 / 已暂停 / 已关机 / 其他**。
4. 单击 **CPU / 内存** 卡进入 **运维监控 · 集群概览**；单击 **物理主机** 卡进入 **节点概览**；单击 **云主机** 卡进入 **云主机概览**；单击 **告警** 卡进入 **运维告警**。

![集群总览](assets/ch03-monitoring/overview-cards.png)

**操作效果**：用于一屏掌握资源池容量、主机与云主机分布，并据此下钻排查。

**注意**：本页为只读，数据自动轮询刷新，无手动刷新按钮，也不提供导出。inode、负载等更细指标在 **运维监控** 中查看（见 **5.1**）；节点维护见 **6.1 计算资源**。

---

### 4.2 机房拓扑

**入口**：`资源总览 > 机房拓扑`

机房拓扑按 **机柜 + U 位** 展示设备的物理摆放，每台设备占一块刀片。具备写权限时可管理机柜与设备。

---

#### 4.2.1 查看机柜与设备

1. 进入 **机房拓扑**。多机柜时用顶部 **机柜切换** 选择机柜。
2. 机柜体按 U 位顺序展示设备刀片，设备类型与展示内容：
   - **物理服务器**：管理 IP、CPU/内存/存储使用率、温度、就绪指示。
   - **物理交换机**：端口与 LLDP 内嵌信息。
   - **占位插板**：自定义标签占位。
3. 单击设备刀片上的 **详情** 打开对应详情抽屉（物理节点信息或交换机详情）。

![机房拓扑](assets/ch03-monitoring/datacenter-rack.png)

**操作效果**：直观对照设备的物理位置与运行状态，便于巡检与定位。

---

#### 4.2.2 管理机柜与设备

**适用角色**：具备机房拓扑写权限的管理员或运维。

1. 无机柜时单击 **创建机柜**；已有机柜时在机柜头工具栏单击 **新机柜**。
2. 在机柜表单中填写 **机柜名称** 与 **排序序号**，保存。
3. 单击机柜头的 **加设备**，在表单中选择：
   - **设备类型**：物理交换机 / 物理服务器 / 占位插板；
   - **选择设备**（节点或交换机）；
   - **U 位**；占位插板填 **自定义标签**。
4. 机柜头工具栏还可 **编辑 / 删除** 机柜、**刷新** 机柜数据。

**操作效果**：机柜与设备布局保存后即时反映在拓扑视图中。

**注意**：删除机柜或设备前请确认无误；本页变更仅影响拓扑展示，不改变设备实际接线。

---

### 4.3 网络拓扑

**入口**：`资源总览 > 网络拓扑`

网络拓扑以连线图展示网络层级关系，提供 **物理网络** 与 **集群网络** 两种视图。

1. 进入 **网络拓扑**，用顶部 **物理网络 / 集群网络** 切换视图。
2. 资源较多时用下拉 **选择物理网络 / 选择集群网络** 指定要查看的对象。
3. **物理网络** 视图按 交换机 → 交换口 → 网口 → 网卡 → 物理机 → 物理网络 → VLAN → 子网 的链路展示，物理网络节点标注 **已就绪 / 未就绪**，交换口与网口间附加 LLDP 链路。
4. **集群网络** 视图展示 交换机 → 交换口 → 网口 → 物理机 → 集群网络 的链路。
5. 用工具栏 **放大 / 缩小 / 适配画布** 调整视图，**刷新** 重新拉取。

![网络拓扑](assets/ch03-monitoring/network-topology.png)

**操作效果**：用于核对物理网络、VLAN、子网与节点的连接关系，排查链路问题。

**注意**：本页为只读可视化，图上节点不弹出抽屉；编辑物理网络、集群网络见 **6.2 网络管理**。

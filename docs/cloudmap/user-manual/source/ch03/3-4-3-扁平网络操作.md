## 13. 扁平网络

**入口**：`Cloudmap 资源池 > 扁平网络`

扁平网络用于管理 Kube-OVN 扁平子网、安全组、弹性公网 IP 与 NAT 规则。它与 **VPC 网络** 分表管理；需要逻辑 VPC 隔离时见 **3.4.4**。

---

### 13.1 扁平子网

**Tab**：`扁平网络 > 扁平子网`

1. 查看扁平子网列表，确认名称、CIDR、网关、可用 IP 范围与项目。
2. 单击 **创建**，填写子网名称、CIDR、网关、排除 IP 或可用 IP 范围。
3. 保存后，在云主机创建向导 **网络与连接** 步骤选择该扁平子网。
4. 删除前确认没有云主机网卡、EIP 或 NAT 规则依赖。

---

### 13.2 安全组

**Tab**：`扁平网络 > 安全组`

1. 创建安全组并填写名称、项目与描述。
2. 在入方向、出方向规则中配置协议、端口范围与源/目的地址。
3. 将安全组绑定到云主机网卡或相关网络对象。
4. 变更后使用 **Reload** 确认规则已同步。

---

### 13.3 弹性公网 IP

**Tab**：`扁平网络 > 弹性公网 IP`

1. 单击 **创建公网 IP**，选择公网子网或地址池。
2. 将 EIP 绑定到扁平网络中的云主机网卡，或供 SNAT、DNAT 规则引用。
3. 解绑或删除前确认没有 NAT 规则仍在使用该 EIP。

---

### 13.4 SNAT

**Tab**：`扁平网络 > SNAT`

1. 单击 **创建**，选择 EIP 与源网段。
2. 保存后，源网段内云主机可通过该 EIP 出公网。
3. 排查不通时，先核对公网子网、EIP 状态与安全组规则。

---

### 13.5 DNAT

**Tab**：`扁平网络 > DNAT`

1. 单击 **创建**，选择 EIP、外部端口、内部 IP 与内部端口。
2. 保存后，外部访问流量转发到指定云主机或服务。
3. 删除 DNAT 前确认业务已迁移或停止对外发布。

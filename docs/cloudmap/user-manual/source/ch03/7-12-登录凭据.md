### 7.12 登录凭据

**入口**：`创建向导 > 登录与凭据`（第 5 步）

**前置**：若使用 SSH 密钥，可先在 `云主机 > SSH 密钥` 创建公钥（见 3.2.7）。

---

#### 登录方式

**登录方式**（单选，必填）：

| 选项              | 说明                                                   |
| ----------------- | ------------------------------------------------------ |
| **设置账户密码**  | 写入 Cloud-Init `chpasswd`                             |
| **设置 SSH 公钥** | 注入 `ssh_authorized_keys`                             |
| **稍后设置**      | 不生成 Cloud-Init；创建后手动配置或 **CloudInit 管理** |

---

#### 设置账户密码

1. 选 **设置账户密码**。
2. **登录账号**：`root` 或 `cloudmap`。
3. **登录密码**：
   - 长度 **8–64** 位；
   - **不可** 含空白或冒号 `:`。
4. 平台自动生成 **userData** Cloud-Config 片段（可在 **高级设置** 查看/微调）。

---

#### 设置 SSH 公钥

1. 选 **设置 SSH 公钥**。
2. **登录账号**：`root` 或 `cloudmap`。
3. **选择 SSH 公钥**：多选；展开下拉时 **Reload** 密钥列表。
4. 须至少选 **1** 把密钥，否则校验失败。

**密钥来源**：`云主机 > SSH 密钥` Tab 中维护的 Harvester SSHKey CR。

---

#### 稍后设置

1. 选 **稍后设置** 可不填账号密码。
2. 创建成功后通过 **控制台/CloudInit** 或 **打开终端** 配置登录。

---

#### 改配

**入口**：`详情抽屉 > … > CloudInit 管理`

1. 编辑 **userData / networkData**（CodeMirror）。
2. **保存** 后重启或按提示生效。
3. 与向导 **高级设置** 中 Cloud-Init 字段联动同一 spec。

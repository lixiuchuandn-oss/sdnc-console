### 3.2.4 快速创建与硬件兼容

**参见白皮书**：3.2.4 硬件生态兼容。

#### 一、快速创建

**适用角色**：具备云主机写权限的租户用户或平台管理员。**参见**：第 4 章。

**入口**：`云主机 > 云主机实例 > 快速创建`

![云主机列表 · 创建入口](assets/ch03-vm/vm-list-toolbar.png)

**适用场景**：常规规格、**Kube-OVN 扁平子网**、单系统盘，无需 NUMA/多网卡/GPU/复杂调度。

**步骤**：

1. 单击 **快速创建**，打开弹窗。

![快速创建弹窗](assets/ch03-vm/vm-quick-create-modal.png)

2. **名称**：填写云主机名称（同项目内别名不可重复）。
3. **规格**：点选 **2C/4G、4C/8G、8C/16G、16C/32G** 或自定义 CPU/内存。
4. **镜像**：下拉选择 **云主机镜像**（仅 Ready 镜像可选）。
5. **系统盘**：容量（GiB）；使用默认 **StorageClass**。
6. **网络**：选择 **扁平子网**（固定 Kube-OVN 扁平 VPC；网卡类型为 managedtap，与创建向导扁平模式一致）。
7. **登录**（若有）：SSH 密钥或密码（以弹窗字段为准）。
8. 单击 **确定** 提交。

**命名空间规则**（界面不展示，但影响创建结果）：

| 账号类型         | 创建所在项目                                         |
| ---------------- | ---------------------------------------------------- |
| 管理员等平台用户 | 固定 `default`（除非产品配置另有约定）               |
| 租户用户         | 优先 **租户控制台工作区** 命名空间，否则租户绑定项目 |

**注意**：

- 无 NUMA、大页、GPU、指定主机、VPC 多网卡等；请用 **创建向导**（3.2.1、3.2.2、3.2.8）。
- 网络仅扁平子网；VPC 专网请用向导 **网络与连接**。
- 成功后列表自动刷新。

#### 二、硬件与架构兼容

**入口**：`集群 > 计算配置 > 计算节点`；`云主机镜像` 列表

| 核对项            | 操作                                                                                            |
| ----------------- | ----------------------------------------------------------------------------------------------- |
| **CPU 架构**      | 节点详情/列表查看 **x86 / ARM**；创建向导会回填 `clusterArch`，ARM 下 **热扩容** 等项可能不可用 |
| **镜像架构**      | 镜像须与节点架构匹配（如 `amd64` / `arm64`）                                                    |
| **VirtIO / SCSI** | 系统盘总线在向导 **存储与磁盘** 选择；ARM + ISO 光驱总线多为 SCSI                               |
| **GPU / PCI**     | `集群 > 计算资源 > GPU 管理`、`直通设备` 确认已纳管后再分配                                     |
| **信创 / 异构**   | 混合节点池时在 **运行位置** 用故障域/指定主机约束架构一致节点                                   |

**参见白皮书**：3.2.4、3.1.4 多元算力形态。

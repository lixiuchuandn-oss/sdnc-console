## 6. 集群

**主入口**：`Cloudmap 资源池 > 集群`

集群菜单管理资源池底层的计算、网络、存储与直通设备等平台级资源，面向平台管理员与运维。左侧栏按五个分组组织，本章按分组逐节说明：

| 侧栏分组     | 内容                                                                                              | 章节    |
| ------------ | ------------------------------------------------------------------------------------------------- | ------- |
| **计算资源** | 计算配置（计算节点、故障域、部署集、DRS 规则、迁移记录）、项目管理、GPU 管理                      | **6.1** |
| **网络管理** | 物理网络（交换机、物理网络、公共子网、VLAN）、集群网络（集群网络、NAD 网络、负载均衡、IP 地址池） | **6.2** |
| **统一存储** | 存储配置（概览、部署、运维、RBD Mirror）、StorageClass                                            | **6.3** |
| **对象存储** | 对象存储网关、对象存储用户、S3 存储桶、COSI 接口                                                  | **6.4** |
| **直通设备** | USB 设备、PCI 设备、网卡                                                                          | **6.5** |

说明：

- 集群资源大多为平台级，变更会影响整池云主机与网络存储，操作前请确认影响范围。
- 多数列表的工具栏提供 **刷新**，会经后端从集群重新拉取最新状态，而非仅读本地缓存。
- 集群侧的物理/集群网络与 **云主机网卡**、**扁平/VPC 网络**（参见 **7.2.5**、**13 扁平网络**、**14 VPC 网络**）分属不同层级；本章只说明集群侧的物理网络与集群网络。

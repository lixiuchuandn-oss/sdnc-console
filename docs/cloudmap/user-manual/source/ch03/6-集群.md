## 6. 集群

**入口**：`Cloudmap 资源池 > 集群`

本节覆盖资源池级集群管理能力，包括基础网络、平台网络、统一存储与对象存储；计算资源中的项目、GPU、故障域、DRS 等也在本菜单下维护。

---

### 6.1 基础网络

**入口**：`集群` 侧栏 **基础网络**、**平台网络** 分组

---

#### 6.2.1 交换机

**Tab**：`集群 > 基础网络 > 交换机`

**适用角色**：平台管理员或网络运维。**参见**：第 4 章（集群网络权限）。

1. **列表**：Harvester **Switch** CR（物理交换机抽象）；名称、厂商、管理 IP、状态。
2. **创建 / 编辑**：
   - 填写名称、描述、**管理地址**、SNMP/SSH 凭证（以表单为准）。
   - 保存后写入集群。
3. **HMS 探测**（若有 write）：
   - 行操作 **探测** → 经 Tower HMS 拉取端口/LLDP 等信息。
   - 探测失败查看返回消息与网络连通性。
4. **SSH 终端**（若有）：
   - 行操作 **SSH** → 打开 **WebSSH 抽屉** 登录交换机（需凭证正确）。
5. **Reload** 刷新 Switch 列表。

**用途**：机房拓扑、VLAN 规划与 **集群网络** 配置时的物理侧参考。

---

#### 6.2.2 物理网络

#### 物理网络

**Tab**：`集群 > 基础网络 > 物理网络`

1. **创建**：
   - **名称**、**默认网卡**（节点 uplink 接口名）。
   - **VLAN**（可选）、**ExcludeIPs** 等（以表单为准）。
2. **保存** 后状态 **Active**；供 **公共子网**、部分 **NAD** 引用。
3. **编辑 / 删除**：行操作；删除前须无子网依赖。
4. **详情抽屉**：查看关联子网、节点接口。
5. **Reload** 同步。

#### 公共子网

**Tab**：`集群 > 基础网络 > 公共子网`

1. **创建**：
   - 选 **ProviderNetwork**、填 **CIDR**、**网关**、**可用 IP 范围**。
2. 供 **EIP 池**、**NAT 公网侧** 等使用（与 **扁平子网** 租户网不同层）。
3. **编辑 / 删除** 行操作。
4. **Reload** 刷新。

**扁平租户子网** 在 `扁平网络 > 扁平子网`（**3.4.3**），勿与 **公共子网** 混淆。

---

#### 6.2.3 集群网络

**Tab**：`集群 > 平台网络 > 集群网络`

1. **列表**：**ClusterNetwork** 资源；名称、节点覆盖、关联 VLAN 配置数。
2. **创建**：
   - 填写名称、选择 **节点**（多选）。
   - 保存创建 ClusterNetwork CR。
3. **详情抽屉**：
   - **基本信息**：节点、标签。
   - **VLAN 配置**：关联 **VlanConfig** 列表；可 **添加 VLAN**（VLAN ID、范围、Uplink 等）。
   - **编辑 / 删除** VLAN 条目（删除有确认）。
4. **Reload** 强制同步 Harvester 网络资源。

**与 Ceph 存储网**：统一存储 **存储网** 步骤可选 ClusterNetwork + VLAN（见 **3.3.1**）。

---

#### 6.2.4 VLAN

**Tab**：`集群 > 基础网络 > VLAN`

1. 查看 **VlanConfig** / VLAN 相关 CR 列表（名称、VLAN ID、ClusterNetwork）。
2. **创建 / 编辑**：绑定 ClusterNetwork、VLAN ID、网段或 uplink 策略（以表单为准）。
3. **删除**：确认后删除 CR。
4. **Reload** 刷新。

**注意**：VLAN 与 **ProviderNetwork / 子网** 配合使用；租户 VPC 见 **3.4.4**。

---

#### 6.2.5 Kube-OVN

| 层级                      | 控制台位置                           |
| ------------------------- | ------------------------------------ |
| **物理 / 集群网络**       | 本节：交换机、ClusterNetwork、VLAN   |
| **虚拟 VPC / 子网 / EIP** | `网络 > Kube-OVN` 分组（见 **3.4**） |
| **云主机网卡**            | 创建向导 **网络与连接**（**3.2.8**） |

物理网络变更可能影响 **NAD、ProviderNetwork**；改配前建议核对 **资源总览 > 网络拓扑**（**3.15**）。

## 3.1 资源融合部署与总览

**参见白皮书**：3.1 资源融合部署能力。

---

### 3.1.1 集群总览

**适用角色**：具备资源总览读权限的管理员。

**入口**：`Cloudmap 资源池 > 资源总览 > 集群总览`

**步骤**：

1. 进入目标资源池。
2. 侧栏展开 **资源总览**，单击 **集群总览**。
3. 查看节点、CPU/内存/存储汇总、组件健康等卡片与图表。
4. 单击工具栏 **Reload** 同步最新数据。

**结果**：展示当前集群资源使用与关键组件状态（只读）。

---

### 3.1.2 机房拓扑与网络拓扑

#### 机房拓扑

**入口**：`资源总览 > 机房拓扑`

1. 页面展示 **机房 → 机架 → 计算节点** 层级拓扑图。
2. **单击节点**：侧栏或浮层显示 CPU/内存摘要、就绪状态。
3. 可 **缩放、拖动画布**；工具栏 **Reload** 同步最新布局。
4. 本页 **只读**；节点维护见 **3.1.3 计算节点**。

#### 网络拓扑

**入口**：`资源总览 > 网络拓扑`

1. 查看 **物理网络、子网与云主机** 的连接关系图。
2. 单击 **子网或网络** 节点查看网段、关联网卡数量。
3. **Reload** 刷新；本页 **只读**。
4. 编辑物理网络见 **3.4.1**。

---

### 3.1.3 计算节点与故障域

**入口**：`集群 > 计算资源 > 计算配置`

页内 **Tab**：

#### 计算节点

1. 打开 **计算节点** Tab，查看节点列表：Ready 状态、CPU/内存容量与分配、维护模式等。
2. 单击节点名称打开 **节点详情**，可查看 **NUMA 拓扑**、标签、污点等（用于 NUMA/调度排查，见 3.2.2）。
3. 计划维护：在节点行操作或详情中 **进入维护模式** / **退出维护模式**。
4. 工具栏 **Reload** 同步节点状态。

#### 故障域

1. 切换到 **故障域** Tab。
2. **创建**：填写名称，选择归属节点并打标。
3. 创建云主机时 **运行位置** 选 **故障域**，在下拉框选择此处创建的域名（见 3.2.1）。

#### DRS 规则

1. 切换到 **DRS 规则** Tab。
2. **新建规则**：配置指标阈值与触发策略（负载等）。
3. 启用/禁用规则；满足条件时平台自动发起虚拟机迁移。

#### 迁移记录

1. 切换到 **迁移记录 (N)** Tab。
2. 查看 DRS 或手动触发的迁移任务状态与历史。

**参见白皮书**：3.2.1 资源动态调度。

---

### 3.1.4 项目管理

**入口**：`集群 > 计算资源 > 项目管理`

1. **列表**：Kubernetes **Namespace**；名称、状态、标签、资源用量（若有）。
2. **创建项目**：
   - 填 **名称**（须 DNS 兼容）、描述。
   - **确定** 后出现在列表。
3. **编辑 / 删除**：行操作；删除前须无 VM/PVC 等资源（或强制策略以界面为准）。
4. **配额**（若启用）：编辑 **ResourceQuota** 限制 CPU/内存/PVC 数。
5. 创建云主机时在向导 **项目** 下拉选择此处命名空间。

**租户**：仅见管理员分配的 project；空列表联系 **租户管理**（第 5 章）。

---

### 3.1.5 GPU 管理

**入口**：`集群 > 计算资源 > GPU 管理`

1. 查看集群已纳管 GPU 列表：节点、PCI 地址、模式（直通/vGPU 等）。
2. 创建云主机时在 **计算与规格** 步骤分配 GPU（见 3.2.5）。

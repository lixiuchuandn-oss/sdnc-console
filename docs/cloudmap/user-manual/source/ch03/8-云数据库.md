## 8. 云数据库

**主入口**：`Cloudmap 资源池 > 云数据库 > 云 RDS`

**适用角色**：具备云数据库权限的租户用户或平台管理员。**参见**：第 4 章（云数据库权限）。

云数据库以 **云 RDS** 一个侧栏项提供。每个 RDS 实例底层是一台基于数据库镜像的 Cloudmap 资源池云主机，因此实例的电源、规格、备份等沿用云主机能力，数据库本身则通过自带的管理台访问。

---

### 8.1 查看实例

**入口**：`云数据库 > 云 RDS`

<!-- 待补截图：云 RDS 实例列表。建议保存为 assets/ch03-database/rds-list.png 后取消下一行注释 -->
<!-- ![云 RDS 列表](assets/ch03-database/rds-list.png) -->

1. 进入 **云 RDS** 列表，查看：实例名称、引擎类型（MySQL / PostgreSQL / MongoDB / RocketMQ / Kafka 等）、版本、状态、IP 地址、节点、CPU、内存、创建时间。
2. 按 实例名称、状态、节点筛选；**刷新** 从资源池重新同步。
3. 单击实例名称打开 **云主机详情抽屉**，查看资源配置、网卡、性能等（详情结构见 **7.3**）。

**操作效果**：列表反映各 RDS 实例的运行状态与规格；数据与云主机列表同源。

**注意**：列表不单独展示项目列，实例所在项目在创建时按账号自动决定。

---

### 8.2 创建实例

**入口**：`云数据库 > 云 RDS > 创建实例`

<!-- 待补截图：创建 RDS 实例弹窗。建议保存为 assets/ch03-database/rds-create-modal.png 后取消下一行注释 -->
<!-- ![创建 RDS 实例](assets/ch03-database/rds-create-modal.png) -->

**前置条件**：已有对应引擎的数据库镜像；资源池有可用扁平子网；租户须有可用项目。

1. 单击工具栏 **创建实例**，打开创建弹窗（标题随所选引擎变化）。
2. 填写 **云数据库名称**（已自动生成，可改）。
3. 选择 **规格**：预设 2C/4G、4C/8G、8C/16G、16C/32G，或选 **自定义** 填写 vCPU 与内存。
4. 选择 **RDS 类型**（数据库引擎）与 **RDS 版本**。
5. 选择 **镜像**（按类型/版本过滤）。
6. 填写 **系统盘容量**（不小于镜像所需最小值）。
7. 选择 **网络**：从扁平子网中选择（云数据库固定使用 Kube-OVN 扁平子网）。
8. 单击 **立即创建**。

**操作效果**：

- 列表新增该实例，状态由 **创建中** 进入 **运行中**。
- 底层按所选镜像创建云主机并接入扁平子网。

**注意**：

- 创建表单不含数据库账号密码或参数模板；初始账号以镜像约定为准，通过数据库管理台维护（见 8.3）。
- 云数据库仅支持扁平子网，不在创建时选择 VPC；如需 VPC，请按云主机方式自行规划。

---

### 8.3 连接与数据库管理

**入口**：`云 RDS > 行操作 > 数据库管理`

1. 在目标实例行操作中选择 **数据库管理**，打开实例自带的数据库管理台。
2. 在管理台中创建库表、维护账号、执行 SQL 等。

**操作效果**：管理台由数据库镜像提供，用于库级操作；实例无 IP 时入口不可用。

**注意**：平台层不提供独立的参数调优、SQL 审计、主备切换等 RDS 控制台能力；这些通过镜像自带管理台或库内操作完成。

---

### 8.4 实例运维

**入口**：`云 RDS > 单击名称 > 详情抽屉`，或 `行操作`

RDS 实例的运维复用云主机能力：

| 操作          | 入口与说明                                                 |
| ------------- | ---------------------------------------------------------- |
| **电源**      | 详情抽屉开机/关机/重启/暂停/恢复（见 **7.4.1**）           |
| **改配**      | 详情抽屉 **资源配置** 调整 CPU/内存、磁盘（见 **7.5**）    |
| **备份/快照** | 详情抽屉 **备份与快照** Tab（见 **7.3.5**、**12 云备份**） |
| **编辑标签**  | 行操作 **编辑标签** 维护实例标签                           |

**操作效果**：在云主机层完成实例的生命周期与容量管理。

**注意**：删除实例即删除底层云主机，删除前确认数据已备份；网络与存储排障可参考 **11 云存储**、**13 扁平网络**。

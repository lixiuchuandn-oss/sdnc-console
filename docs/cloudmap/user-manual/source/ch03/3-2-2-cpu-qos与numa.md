### 7.4 CPU 调优

**参见白皮书**：3.2.2 精细化 CPU 管理。

---

#### 计算规格

**入口**：`创建向导 > 计算与规格`

##### 1. 基础 CPU / 内存

1. **CPU**：选 **2 核 / 4 核 / 8 核 / 自定义**；自定义时可填 vCPU 数量。
2. **内存**：选 **4 GB / 8 GB / 16 GB / 自定义**。
3. 展开 **CPU 拓扑**（若有）：配置 **插槽（Socket）/ 核（Core）/ 线程（Thread）**。

##### 2. CPU / 内存热扩容

1. 勾选 **启用 CPU/内存热扩容**（ARM 架构可能不可用）。
2. 启用后：**NUMA 亲和**、**大页内存** 自动 **禁用** 并提示。
3. 热扩容对拓扑有约束（常见为 `sockets=vCPU, cores=1, threads=1`），界面会自动锁定。

##### 3. CPU 高级

| 配置项        | 操作说明                                                               |
| ------------- | ---------------------------------------------------------------------- |
| **CPU 绑定**  | 勾选 **Dedicated CPU**（绑核）                                         |
| **CPU QoS**   | 填 **请求 / 上限**（核数）；与绑核、NUMA 互斥时会被清空                |
| **CPU 隔离**  | 绑核后可勾选隔离 QEMU 线程（若有选项）                                 |
| **NUMA 亲和** | 下拉：**未启用 / Guest NUMA 自动映射 / 手动 NUMA 拓扑**                |
| **手动拓扑**  | 选 **手动** 后设 **节点数 2–8**；下方显示 **预览**（各节点 vCPU/内存） |
| **说明**      | 单击 NUMA 旁 **?** 查看拓扑说明                                        |

**NUMA 启用时**：自动开启 **CPU 绑定**，并 **清空 CPU QoS**；界面弹出提示。

**校验失败**（无法保存选项）时常见原因：

- 未启用 **CPU 绑定**
- 与 **热扩容** 同时启用
- 手动模式：vCPU 总数不能被节点数整除；**插槽数** 不是节点数整数倍

##### 4. 完成本步

单击 **下一步** 进入 **存储与磁盘**。

---

#### 性能设置

**入口**：`云主机详情 > … > 性能调优 > 性能设置`

**步骤**：

1. 打开云主机 **详情抽屉**。
2. **… > 性能调优 > 性能设置**，打开 **性能设置** 抽屉。
3. 修改 **CPU 拓扑、CPU 绑定、CPU QoS、NUMA 模式、大页**（大页见 3.2.3）等。
4. **确定** 提交；详情顶栏可能出现 **变更同步中** Tag。
5. 抽屉内 **Reload** 或关闭重开确认生效。

**注意**：部分 CPU/NUMA 变更需 **重启云主机**；热扩容进行中禁止再次改规格。

---

#### 调整规格

**入口**：`详情抽屉工具栏 > 资源配置 > 调整规格`

1. 修改 vCPU、内存等 **基础规格**。
2. 若已启用 **热扩容** 且 VM 运行中，部分内存/CPU 变更可在线完成（受上限约束）。
3. 提交后等待 **配置已同步** Tag 变绿。

---

#### 热扩容设置

**入口**：`… > 性能调优 > 热扩容设置`

1. 启用或调整 **maxSockets / maxMemory** 等热扩容上限。
2. 首次启用可能提示 **热扩容待重启**；按 Tag 提示重启后生效。

---

#### 查看宿主机 NUMA

**入口**：`集群 > 计算配置 > 计算节点 > 单击节点名`

在节点详情查看 **NUMA 节点数** 与各节点 CPU 分布，用于选手动 NUMA **节点数** 与排障。

---

#### 其它调度相关改配

| 菜单路径                      | 用途                                      |
| ----------------------------- | ----------------------------------------- |
| **调度策略 > 节点选择器**     | nodeSelector、固定主机/故障域（见 3.2.1） |
| **调度策略 > 节点亲和性**     | 按节点标签亲和/反亲和                     |
| **调度策略 > 虚拟机间亲和性** | 与其它云主机同宿/分散                     |
| **调度策略 > 高可用设置**     | 重启策略、Eviction 等                     |

**注意**：**运行位置 = 指定主机** 创建时，部分亲和项在创建向导中不可用，但已创建 VM 可在详情中改 **节点亲和性**（视实现为准）。

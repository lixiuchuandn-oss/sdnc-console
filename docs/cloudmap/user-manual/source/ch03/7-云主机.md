## 7. 云主机

**主入口**：`云主机 > 云主机实例`

云主机是 Cloudmap 资源池中最核心的计算资源。本章按 **创建、查看、变更、删除** 四条主线组织，并把镜像、模板、密钥等创建前的准备资源单列说明。涉及网络、存储、备份等跨模块配置时，本章只说明在云主机界面里的入口与结果，详细字段到对应章节查看（网络见 **13 扁平网络**、**14 VPC 网络**，存储见 **11 云存储**，备份见 **12 云备份**，监控见 **5 云监控**，日志见 **15 日志管理**）。

创建云主机有两条路径，按需求复杂度选择：

| 路径 | 适用场景 | 章节 |
| ---- | -------- | ---- |
| **快速创建** | 常规规格、扁平子网、单系统盘，无需 NUMA、多网卡、GPU、指定主机等高级配置 | **7.1** |
| **通过向导创建** | 需要分步配置计算调优、多磁盘、多网卡、直通设备、登录凭据、固件等完整能力 | **7.2** |

本章其余内容：查看云主机与详情见 **7.3**；电源、终端、迁移、克隆、回收站等生命周期操作见 **7.4**；创建后修改 CPU、内存、磁盘、网卡、GPU、调度策略等见 **7.5**；删除见 **7.6**；云主机镜像、模板、SSH 密钥与 CloudInit 配置见 **7.7**。

### 7.8 启动策略

**创建向导 · 高级设置** 字段逐步说明见 **3.2.11**；系统盘/ISO/引导顺序见 **3.2.9**。

---

#### 高可用设置

**入口**：`详情抽屉 > … > 调度策略 > 高可用设置`

| 配置         | 说明                                       |
| ------------ | ------------------------------------------ |
| **运行策略** | Always / RerunOnFailure / Manual / Halted  |
| **驱逐策略** | LiveMigrateIfPossible / LiveMigrate / None |

保存后按策略影响 **节点维护** 时是否热迁移。

---

#### 引导顺序

**改配引导顺序**：`资源配置 > 磁盘管理` 中 **上移/下移** 磁盘 boot 顺序。

**弹出 CD-ROM**：`… > 弹出 CD-ROM`（ISO 引导且光驱 occupied）；运行中可能 **强制重启**（确认弹窗）。

---

#### 固件设置

EFI/Secure Boot/TPM 若在创建时已设，改配须通过 **YAML** 或后续版本抽屉（以界面为准）；变更后通常 **关机再启动**。

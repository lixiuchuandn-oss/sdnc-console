## 14. VPC 网络

**前置**：须启用 VPC 网络特性（随多云管理授权）；未启用时 **VPC 网络** 侧栏不显示。

**主入口**：`Cloudmap 资源池 > VPC 网络`

**适用角色**：具备 VPC 网络相应权限的平台管理员、网络运维或租户用户。**参见**：第 4 章（VPC 网络权限）。

VPC 网络提供逻辑隔离的私有网络，含 **VPC、子网、弹性公网 IP、SNAT、DNAT** 五个侧栏项。它与 **扁平网络**（见 **13**）平行分组，EIP/SNAT/DNAT 各自独立一套（互不混用）。VPC 网络下 **不含安全组**。

> 层级关系：先创建 **VPC**（绑定项目）→ 在 VPC 下建 **子网** → 云主机接入子网；公网出入通过 **EIP + SNAT/DNAT** 实现。VPC 的写权限不包含子网写权限，各 Tab 权限独立。

---

### 14.1 VPC

**入口**：`VPC 网络 > VPC`

![VPC 列表](assets/ch03-network/vpc-list-page.png)

---

#### 14.1.1 查看 VPC

1. 查看 VPC 列表：名称、ID、UID、CIDR（业务 VPC 常显示为 `-`）、项目、创建时间。
2. 按 名称/ID、项目筛选。
3. 单击行展开可查看该 VPC 下的 **关联子网**（名称、CIDR、项目、网关、类型、已用/总数）。

**操作效果**：总览 VPC 及其子网；内置 VPC 会带「公共/扁平/Provider」标记。

---

#### 14.1.2 创建 VPC

1. 单击工具栏 **创建 VPC**。

![创建 VPC](assets/ch03-network/vpc-create-modal.png)

2. 填写：
   - **名称**（显示名，支持中文）；
   - **绑定项目**（单选命名空间，通常一个 VPC 对应一个项目用于租户隔离）；
   - **静态路由**（可选，多条，每条填目的网段 CIDR 与下一跳 IP）。
3. 单击提交。

**操作效果**：创建一个业务 VPC，绑定到所选项目，供其下子网与 EIP/NAT 使用。

**注意**：创建表单不含 VPC 自身 CIDR、BGP、外部网关等字段。

---

#### 14.1.3 管理 VPC

| 操作          | 说明                                          |
| ------------- | --------------------------------------------- |
| **编辑 VPC**  | 修改名称、绑定项目、静态路由                  |
| **创建子网**  | 从行操作进入新建子网，VPC 已预选              |
| **查看 YAML** | 查看定义                                      |
| **删除**      | 高风险确认；须先删除其下子网，内置 VPC 不可删 |

**操作效果**：VPC 无独立详情页，结构化信息看子网详情或 YAML。

---

### 14.2 子网

**入口**：`VPC 网络 > 子网`

![VPC 子网列表](assets/ch03-network/vpc-subnet-list-page.png)

---

#### 14.2.1 查看子网

1. 查看列表：名称、ID、CIDR、所属 VPC、项目、网关、NAT（开启/关闭）、DHCP（启用/关闭）、已用/总数、创建时间；管理员另可见 **ACL** 条数。
2. 按 名称/ID、VPC、NAT、DHCP 筛选。
3. 单击名称打开 **子网详情** 抽屉（只读）：所属 VPC、子网类型、协议、项目、地址与 DHCP/NAT、IP 用量与排除 IP、ACL 条数。

---

#### 14.2.2 新建 VPC 子网

**前置条件**：已存在业务 VPC。

1. 单击工具栏 **新建 VPC 子网**（或从 VPC 行操作 **创建子网**）。

![新建 VPC 子网](assets/ch03-network/vpc-subnet-create-modal.png)

2. 填写：
   - **名称**；
   - **所属 VPC**（业务 VPC，编辑时不可改）；
   - **CIDR**（IPv4）、**网关**（须在 CIDR 内）；
   - **排除 IP**（可选，单 IP 或范围，须在 CIDR 内）；
   - **启用 NAT 出网**（默认开启）；
   - **启用 DHCP 服务**（默认开启）。
3. 单击提交。

**操作效果**：在所属 VPC 下创建子网，供云主机在创建向导 **网络与连接** 选用（见 **7.2.5**）。

**注意**：创建表单不含网关类型、DNS、协议选择（固定 IPv4）；子网已被云主机占用时不可改 CIDR/网关。

---

#### 14.2.3 编辑、ACL 与删除

| 操作                   | 说明                                                  |
| ---------------------- | ----------------------------------------------------- |
| **编辑**               | 改名称、排除 IP、NAT、DHCP；无占用时可改 CIDR/网关    |
| **编辑 ACL**（管理员） | 配置子网访问控制规则（动作、方向、匹配、优先级等）    |
| **删除**               | 高风险确认；有云主机挂接或被 SNAT/DNAT 引用时禁止删除 |

**操作效果**：子网详情为只读视图，变更通过编辑弹窗完成。

---

### 14.3 弹性公网 IP

**入口**：`VPC 网络 > 弹性公网 IP`

![VPC 域 EIP 列表](assets/ch03-network/vpc-eip-list-page.png)

1. 查看列表：名称、ID、所属 VPC、所在公共子网、IP 地址、MAC、类型、状态、创建时间；按名称/ID/IP、状态、类型筛选。
2. 单击 **创建公网IP**，填写：
   - **名称**；
   - **VPC**（业务 VPC）；
   - **公共子网**（EIP 从公共子网分配，公共子网在 `集群 > 网络管理 > 物理网络` 维护，见 **6.2.3**）；
   - **可访问的范围**：不限（0.0.0.0/0）或指定 CIDR（写入 VPC 路由）；
   - **指定 IP**（可选，须在所选公共子网网段内）。
3. 行操作 **查看元数据 / 删除**。

**操作效果**：EIP 作为该 VPC 的公网地址，供 SNAT 出网或 DNAT 对外发布引用。

**注意**：EIP 页不直接绑定云主机网卡，公网访问通过 SNAT/DNAT 关联；与 **扁平网络 EIP**（见 **13.3**）分属两套，勿混用。

---

### 14.4 SNAT

**入口**：`VPC 网络 > SNAT`

![VPC 域 SNAT](assets/ch03-network/vpc-snat-list.png)

1. 查看列表：名称、ID、CIDR、所属 VPC、公网 IP、创建时间；按名称/ID、VPC 筛选。
2. 单击 **创建 SNAT 网关**，填写：
   - **名称**（可选）；
   - **选择 VPC**（先选 VPC，再过滤 EIP 与子网）；
   - **选择公网 IP**（该 VPC 下已有 EIP）；
   - **选择 VPC 子网**（该 VPC 下子网，源网段取其 CIDR）。
3. 行操作 **查看元数据 / 删除**。

**操作效果**：所选 VPC 子网内的云主机经该公网 IP 访问外网。

**注意**：同一「公网 IP + 子网」组合不可重复创建 SNAT。

---

### 14.5 DNAT

**入口**：`VPC 网络 > DNAT`

![VPC 域 DNAT](assets/ch03-network/vpc-dnat-list.png)

1. 查看列表：名称、ID、公网 IP、公网端口、协议、内部 IP、内部端口、所属 VPC、创建时间；按名称/ID、VPC、协议筛选。
2. 单击 **创建 DNAT 规则**，填写：
   - **名称**（可选）；
   - **VPC**、**公网 IP**（该 VPC 下 EIP）；
   - **协议**（TCP/UDP，默认 TCP）；
   - **公网端口**（单端口或范围，如 `1-10`）；
   - **子网** 与 **虚拟机**（内部 IP 由所选云主机在该子网的网卡自动解析）；
   - **内部端口**（映射条数须与公网端口一致）。
3. 行操作 **查看元数据 / 删除**。

**操作效果**：外部访问公网 IP 的指定端口转发到 VPC 内云主机的对应端口。

**注意**：同一「公网 IP + 协议」下公网端口不可冲突；目标云主机须挂接该子网且非回收站。

---

### 14.6 与扁平网络对比

| 项            | 扁平网络（**13**）         | VPC 网络（本章）             |
| ------------- | -------------------------- | ---------------------------- |
| 隔离          | 扁平二层子网               | 逻辑 VPC + 子网              |
| 安全组        | 有（见 **13.2**）          | 无                           |
| EIP/SNAT/DNAT | 选 **扁平子网**，无 VPC    | 先选 **VPC**，EIP 须属该 VPC |
| 公共子网来源  | 集群 物理网络（**6.2.3**） | 集群 物理网络（**6.2.3**）   |
| 特性开关      | 一般默认开启               | 须启用 VPC 网络特性          |

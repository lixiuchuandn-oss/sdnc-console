## 3.3.6 对象存储 RGW 与 S3

**参见白皮书**：3.3.6 对象存储与文件服务。

**入口**：`集群 > 对象存储` 侧栏分组

---

### 3.3.6.1 对象存储网关

**Tab**：`对象存储网关`（path：`cluster/object_gateways`）

**适用角色**：平台管理员或存储运维。**参见**：第 4 章（对象存储权限）。

1. 查看 **CephObjectStore**（RGW 网关）列表：命名空间、阶段、端点。
2. **创建**：填写命名空间、名称、存储类、网关副本、SSL 等（表单以界面为准）。
3. **编辑 / 删除**：行操作或详情（删除为高风险操作，有确认）。
4. **Reload** 同步 Rook 资源。

**Tower S3 客户端 Endpoint**：在网关详情或平台配置中维护 `towerRgwS3ClientByStore`（管理员）；供 **S3 存储桶** 页代发 S3 API。

---

### 3.3.6.2 对象存储用户

**Tab**：`对象存储用户`（path：`cluster/rgw_users`）

1. **创建用户**：选择 **ObjectStore**、命名空间、CR 名称。
2. 列表查看 **CephObjectStoreUser** 状态。
3. 行操作 **查看密钥**：平台经 **rook-secret** 只读展示 **AK/SK**（敏感，仅授权人员）。
4. **编辑 / 删除** 用户。

---

### 3.3.6.3 S3 存储桶

**Tab**：`S3 存储桶`（path：`cluster/rgw_s3_buckets`）

**说明**：Tower **代发 S3**，不在本地持久化桶数据；须先选 **ObjectStoreUser** 或配置连接。

**步骤**：

1. 顶部选择 **对象存储用户**（下拉来自 Rook bundle）。
2. **Reload** 刷新桶列表（代发 `list-buckets`）。
3. **创建桶**：输入桶名 → 确定。
4. **删除桶**：行操作（高风险确认）。
5. **对象列表**：行操作 **查看对象** → 抽屉内浏览前缀、分页 **ListObjects**。

**前置**：网关 Endpoint 可达；用户 CR 已 Ready 且 Secret 含密钥。

---

### 3.3.6.4 COSI 接口

**Tab**：`COSI 接口`（path：`cluster/cosi`）

1. 查看 **Container Object Storage Interface** 相关资源（COSI Driver/Claim 等，以界面为准）。
2. 供 Kubernetes 工作负载通过 COSI 声明对象存储（与 **容器服务** 联动）。

---

### 3.3.6.5 与容器 / 云主机区别

| 方式              | 场景                               |
| ----------------- | ---------------------------------- |
| **S3 存储桶 Tab** | 管理员/运维 **手工** 桶与对象管理  |
| **COSI**          | 集群内应用 **声明式** 挂载对象存储 |
| **云盘（RBD）**   | 块存储，见 **3.3**                 |

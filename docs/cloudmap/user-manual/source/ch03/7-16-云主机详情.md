### 7.16 云主机详情

**入口**：`云主机实例` 列表单击 **名称**（名称列为可点击链接）

**适用角色**：租户用户或平台管理员。**参见**：第 4 章（云主机权限）。

---

#### 抽屉结构

![详情抽屉 · 详情 Tab](assets/ch03-vm-detail/vm-detail-drawer-detail-tab.png)

| 区域         | 内容                                                       |
| ------------ | ---------------------------------------------------------- |
| **顶栏**     | 名称、ID、**运行状态** Tag                                 |
| **状态 Tag** | **配置已同步/变更同步中**；**热扩容** 系列 Tag（见 3.2.3） |
| **Sync**     | 强制刷新聚合 VM 数据                                       |
| **工具栏**   | 终端、电源、**资源配置** 下拉、**…** 更多                  |
| **Tab**      | **详情** / **性能** / **备份/快照**（Segmented 切换）      |

![更多操作菜单](assets/ch03-vm-detail/vm-detail-more-menu.png)

---

#### 电源终端

| 按钮                                 | 条件                  |
| ------------------------------------ | --------------------- |
| **打开终端**                         | 运行中；serial 控制台 |
| **开机 / 关机 / 重启 / 暂停 / 恢复** | 视状态                |

---

#### 资源配置

| 菜单项       | 抽屉               | 说明                           |
| ------------ | ------------------ | ------------------------------ |
| **调整规格** | VmSpecConfigDrawer | CPU/内存（非 NUMA 细项）       |
| **磁盘管理** | VmDiskManage       | 挂载、扩容、引导顺序；见 3.2.9 |
| **网卡管理** | VmNicManage        | 增删改网卡；见 3.2.8           |
| **GPU管理**  | VmGpuManage        | 见 3.2.5                       |
| **USB管理**  | VmUsbManage        | 挂载/卸载 USB                  |

![磁盘管理子抽屉](assets/ch03-vm-detail/vm-detail-disk-manage.png)

![调整规格子抽屉](assets/ch03-vm-detail/vm-detail-spec-config.png)

---

#### 更多菜单

##### 生命周期

| 项              | 说明                        |
| --------------- | --------------------------- |
| **克隆**        | 复制为新 VM 向导/弹窗       |
| **保存模板**    | 写入 **云主机模板**         |
| **热迁移**      | 仅 **运行中**；可选目标节点 |
| **中止迁移**    | 迁移进行中显示              |
| **弹出 CD-ROM** | ISO 引导且光驱 occupied     |
| **强制停止**    | 相当于断电                  |
| **删除**        | 可能进入 **回收站**         |

##### 性能调优

| 子项           | 说明                                         |
| -------------- | -------------------------------------------- |
| **性能设置**   | CPU 高级、**NUMA**、**大页**（3.2.2、3.2.3） |
| **热扩容设置** | maxSockets/maxMemory、启用热插拔             |

部分变更须 **重启** 确认（抽屉内弹窗提示）。

##### 调度策略

| 子项               | 说明                          |
| ------------------ | ----------------------------- |
| **节点选择器**     | 自动/固定主机/故障域（3.2.1） |
| **节点亲和性**     | nodeAffinity 规则             |
| **虚拟机间亲和性** | podAffinity/antiAffinity      |
| **高可用设置**     | evictionStrategy 等（3.2.6）  |

![节点选择器改配](assets/ch03-vm-detail/vm-detail-node-scheduling.png)

##### CloudInit 管理

编辑 userData/networkData（3.2.10）。

##### 诊断工具

| 子项          | 说明                     |
| ------------- | ------------------------ |
| **运行诊断**  | 调度、事件、资源聚合排障 |
| **查看 YAML** | VM CR 只读               |

---

#### 详情 Tab

展示 **项目、节点、镜像、CPU/内存、磁盘摘要、网卡、调度标签** 等。

**调度诊断** 区展示 nodeSelector/nodeAffinity，便于对照 **Pending** 原因。

---

#### 性能 Tab

1. 切换 **CPU / 内存 / 网络 / 磁盘** 图表。
2. 选择时间范围；顶栏 **Reload** 刷新（3.14.4）。

![性能 Tab](assets/ch03-vm-detail/vm-detail-tab-performance.png)

---

#### 备份快照 Tab

**创建备份 / 创建快照** 快捷入口；列表与 **云备份** 全局 Tab 同源（3.9）。

![备份/快照 Tab](assets/ch03-vm-detail/vm-detail-tab-backup.png)

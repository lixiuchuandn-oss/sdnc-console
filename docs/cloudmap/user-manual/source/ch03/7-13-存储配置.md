### 7.13 存储配置

**入口**：`创建向导 > 存储与磁盘`（第 3 步）

---

#### 系统盘

| 字段           | 说明                                                  |
| -------------- | ----------------------------------------------------- |
| **来源**       | **镜像** / **ISO** / **现有云盘**                     |
| **镜像/ISO**   | 下拉选择 **云主机镜像**（仅 Ready）；ISO 用于安装介质 |
| **现有云盘**   | 选择未挂载 PVC；总线随卷类型推断                      |
| **名称**       | 系统卷名（新建时自动生成后缀，可改）                  |
| **容量 (GiB)** | 新建时必填；选已有卷时为卷容量                        |
| **块设备总线** | VirtIO（推荐）/ SCSI / SATA / IDE / NVMe              |

**ISO 启动规则**：

1. 系统盘选 **ISO** 时，光驱总线固定：**ARM64 → SCSI**，**x86 → SATA**（界面 tooltip 说明）。
2. 须 **至少添加一块非光驱数据盘** 作为系统盘目标，否则无法 **下一步**。

**StorageClass**：新建卷使用池默认 **StorageClass**（随镜像/策略写入，常规场景界面不单独展示）。

---

#### 数据盘

1. 单击 **添加数据盘** 增加条目。
2. 每条数据盘可选来源：

| 来源         | 操作                            |
| ------------ | ------------------------------- |
| **新建**     | 填名称、容量、总线              |
| **已有云盘** | 下拉选 Bound 且未挂载卷         |
| **ISO**      | 挂载为 CD-ROM；须配合系统盘策略 |

3. 行末 **删除** 图标移除该盘。
4. 多块盘时按列表顺序决定 **引导顺序**（与改配 **磁盘管理** 一致）。

---

#### 后续步骤

| 场景                | 注意                                            |
| ------------------- | ----------------------------------------------- |
| **Windows / 旧 OS** | 总线选 **SATA/IDE** 或确保镜像含 VirtIO 驱动    |
| **大容量数据**      | 确认 StorageClass 支持 **在线扩容**（见 3.3.1） |
| **直通 / 指定主机** | 已有卷须在目标节点可访问                        |

---

#### 改配

**入口**：`详情抽屉 > 资源配置 > 磁盘管理`

| 操作            | 说明                                  |
| --------------- | ------------------------------------- |
| **挂载/卸载**   | 添加数据盘或卸载非系统盘              |
| **扩容**        | 改容量（SC 须 allow expansion）       |
| **更换系统盘**  | **更换系统盘** 抽屉（高风险，有确认） |
| **引导顺序**    | 调整磁盘 boot 优先级                  |
| **弹出 CD-ROM** | `… > 弹出 CD-ROM`（ISO 引导时）       |

写操作成功后抽屉 **Reload** 或关闭重开以见 **配置已同步** Tag。

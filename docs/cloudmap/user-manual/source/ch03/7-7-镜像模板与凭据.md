### 7.7 镜像、模板与凭据

本节说明创建云主机前需要准备的资源：镜像、模板、SSH 密钥与 CloudInit 配置。它们都在 **云主机** 菜单下管理，供 **快速创建** 与 **创建向导** 选用。

---

#### 7.7.1 云主机镜像

**入口**：`云主机 > 云主机镜像`

**适用角色**：平台管理员或已分配该资源池镜像写权限的租户用户。

![云主机镜像列表工具栏](assets/image-list-toolbar.png)

**浏览器上传镜像**：

**前置条件**：资源池状态为 **在线**；平台镜像暂存目录剩余空间大于待传文件。

1. 单击工具栏 **新增镜像**。
2. 在弹窗中选择 **浏览器上传** 页签（租户场景可能仅此页签）。
3. 单击 **选择镜像文件**，选择本地 `.iso` 或磁盘镜像（如 `.qcow2`）；系统按文件名自动填充 **镜像名称** 与 **镜像类型**，可按需修改。
4. 单击 **提交任务**。平台在后台分片上传到暂存目录；弹窗关闭后自动打开 **镜像上传任务** 抽屉查看进度。

![新增镜像 · 浏览器上传](assets/image-create-browser-upload.png)

![镜像上传任务抽屉](assets/image-upload-tasks-drawer.png)

5. 上传完成后抽屉提示文件已上传至平台；镜像列表出现状态为 **待同步** 的行。
6. 在列表搜索定位该行，单击行末 **…** 选择 **同步**，将镜像导入集群。同步进行中请勿删除该行。

![镜像列表 · 待同步与同步操作](assets/image-list-pending-sync.png)

7. 同步成功后状态变为 **就绪**，可在快速创建与创建向导中选用。

**注意**：

- 合并后的镜像文件须不小于 1 MiB，过小文件会在同步阶段失败。
- 大文件或浏览器不稳定时，可在 **新增镜像 > Windows 桌面工具** 下载上传工具直传集群。
- 工具栏 **上传任务** 可随时查看历史任务；**待同步** 期间不可在抽屉内删除任务记录，须在镜像列表删除镜像数据。常见问题见 **6 常见问题**。

---

#### 7.7.2 URL 导入与镜像标签

**入口**：`云主机 > 云主机镜像`

1. **URL 导入**：单击 **新增镜像 > URL 导入**，填写镜像名称与 `http(s)` 下载地址。
2. **标签**：对镜像执行 **删除 / 重命名** 标签操作。

**操作效果**：URL 导入由集群直接下载并同步；就绪后与上传镜像一样可在创建时选用。

---

#### 7.7.3 云主机模板

**入口**：`云主机 > 云主机模板`

1. 进入 **云主机模板** 列表，可按名称、**公共模板 / 私有模板** 筛选。
2. 模板来源：从现有云主机 **保存模板**（见 7.4.5），或从模板列表新建。
3. 在目标模板行单击 **使用模板创建虚拟机**，按需调整后单击 **创建**，快速部署相同配置的云主机；也可在 **创建向导** 或 **快速创建** 中选用模板。
4. 不再需要的模板可 **删除** 或 **批量删除**；可 **查看 YAML** 核对定义。

**操作效果**：模板固化一套规格、磁盘、网络与启动配置，减少重复填写，便于标准化批量部署。

---

#### 7.7.4 SSH 密钥

**入口**：`云主机 > SSH 密钥`

1. 在 **SSH 密钥** 列表单击 **创建**，填写 **名称** 与 **公钥内容** 并提交。
2. 创建云主机时，在 **登录与凭据** 步的 **设置 SSH 公钥** 中选用该密钥（参见 **7.2.6**）。
3. 不再使用的密钥可 **删除** 或 **批量删除**（不可恢复）。

**操作效果**：所选公钥通过 Cloud-Init 注入云主机的授权密钥，支持免密登录。删除密钥不影响已注入到云主机的公钥。

---

#### 7.7.5 CloudInit 配置

**入口**：`云主机 > CloudInit 配置`

1. 在 **Cloud Init 模板** 列表中维护可复用的初始化脚本（按名称/ID 筛选）。
2. 创建或改配时引用，或在详情 **… > CloudInit 管理** 中针对单台云主机编辑（参见 **7.5.8**）。

**操作效果**：用于统一下发账号、密码、网络、初始化命令等；针对单台云主机变更后通常须重启生效。

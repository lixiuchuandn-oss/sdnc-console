### 6.4 对象存储

**适用角色**：平台管理员或存储运维。**参见**：第 4 章（对象存储权限）。

对象存储分组含 **S3 存储桶、对象存储用户、对象存储网关、COSI 接口** 四个侧栏项，基于统一存储的对象网关提供 S3 兼容能力。下面按部署到使用的顺序说明。

---

#### 6.4.1 对象存储网关

**入口**：`集群 > 对象存储 > 对象存储网关`

1. 查看对象存储网关列表：项目、阶段、端点。
2. **创建**：填写项目、名称、存储类、网关副本、SSL 等。
3. 行操作 **编辑 / 删除**（删除为高风险，有确认）。
4. **刷新** 同步。

**操作效果**：网关提供 S3 接入端点，是对象存储用户与 S3 存储桶的基础。

**注意**：在网关详情或平台配置中可维护 **Tower S3 客户端 Endpoint**（管理员），供 **S3 存储桶** 页代发 S3 请求时使用。

---

#### 6.4.2 对象存储用户

**入口**：`集群 > 对象存储 > 对象存储用户`

1. 查看对象存储用户列表与状态。
2. **创建用户**：选择 **对象存储网关**、项目、用户名。
3. 行操作：
   - **查看密钥**：只读展示 AK/SK（敏感信息，仅授权人员）。
   - **编辑 / 删除** 用户。

**操作效果**：用户的 AK/SK 用于 S3 客户端访问；S3 存储桶页选用该用户后即可代发 S3 请求。

---

#### 6.4.3 S3 存储桶

**入口**：`集群 > 对象存储 > S3 存储桶`

**前置条件**：网关端点可达；对象存储用户已就绪且持有密钥。

1. 顶部选择 **对象存储用户**（或配置连接）。
2. **刷新** 拉取桶列表（由平台代发 S3 请求）。
3. **创建桶**：输入桶名后确定。
4. **删除桶**：行操作（高风险确认）。
5. **查看对象**：行操作打开抽屉，浏览前缀、分页查看对象。

**操作效果**：平台代发 S3 请求管理桶与对象，本地不持久化桶数据。

---

#### 6.4.4 COSI 接口

**入口**：`集群 > 对象存储 > COSI 接口`

1. 查看容器对象存储接口（COSI）相关资源。
2. 供 Kubernetes 工作负载以声明方式申请对象存储（与容器服务联动，参见 **10 容器服务**）。

**操作效果**：

| 方式          | 场景                         |
| ------------- | ---------------------------- |
| **S3 存储桶** | 管理员/运维手工管理桶与对象  |
| **COSI 接口** | 集群内应用声明式挂载对象存储 |

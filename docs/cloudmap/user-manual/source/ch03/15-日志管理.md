## 15. 日志管理

**入口**：`日志管理` 侧栏分组（3 个 Tab）

**说明**：基于 **Banzaicloud Logging Operator**（Flow/ClusterFlow/Output）；须集群已部署 Logging 栈。

---

### 15.1 日志采集对象

**Tab**：`日志采集对象`（`logs_config/logs-target`）

**适用角色**：平台管理员或运维。**参见**：第 4 章（日志采集权限）。

1. **列表**：已声明的采集 **目标**（VM、Pod、节点、容器等类型）。
2. **创建**：
   - 选择 **资源类型**（如云主机、命名空间、标签选择器）。
   - 指定 **命名空间/名称/标签** 匹配范围。
3. **编辑 / 删除**：行操作。
4. **Reload** 同步 Logging CR。

**用途**：定义 **哪些工作负载** 产生日志需被采集。

---

### 15.2 日志接收端

**Tab**：`日志接收端`（`logs_config/log-outputs`）

1. **列表**：**Output/ClusterOutput**；类型 Loki、Elasticsearch、S3、Forward 等。
2. **创建**：
   - 名称、**后端类型**、Endpoint、认证 Secret。
3. **测试**（若有）：验证连通性。
4. **编辑 / 删除**。

**注意**：接收端 URL/凭证错误会导致 **无日志入库** 或堆积。

---

### 15.3 日志采集配置

**Tab**：`日志采集配置`（`logs_config/logs-flow-config`）

1. **列表**：**Flow / ClusterFlow** 路由规则。
2. **创建**：
   - **match** 段：选采集对象标签/命名空间。
   - **localOutputRefs / globalOutputRefs**：指向 **日志接收端**。
   - 可选 **过滤器**（parser、grep 等，以表单为准）。
3. **启用/禁用** 或 **删除** 规则。
4. **Reload** 刷新。

**链路**：采集对象 → Flow 匹配 → Output 转发 → 外部 Loki/ES。

---

### 15.4 查看日志

| 来源         | 入口                                                                          |
| ------------ | ----------------------------------------------------------------------------- |
| **容器 Pod** | `容器服务 > 容器实例 > 日志`（**10.2**）                                      |
| **云主机**   | 配置 VM 采集对象 + Flow 后，在外部 Loki/ES 查询；或 **诊断工具**（**7.3.6**） |
| **节点**     | ClusterFlow 采集 `/var/log` 等（视规则）                                      |

---

### 15.5 运维监控

池级指标与告警 **不在** 本分组，见 **5. 云监控**（`云监控` Tab）。

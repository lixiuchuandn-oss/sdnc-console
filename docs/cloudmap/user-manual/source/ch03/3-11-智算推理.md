## 3.11 智算推理

**参见白皮书**：3.11 智算推理能力。

---

### 3.11.1 Xinference 资源池

**入口**：`多云管理 > 资源池管理 > Xinference 类型池`

进入后为 **推理服务** 专属 Tab（模型部署、API 端点等；以控制台现网界面为准）。

**典型操作**：

1. 查看 **已部署模型** 与副本状态。
2. **部署模型**：选镜像/权重、GPU 节点、副本数。
3. 获取 **推理 API 地址** 与 Token（若有）。

---

### 3.11.2 Cloudmap 池内 GPU 算力

无独立 Xinference 池时，在 **Cloudmap 池** 内：

1. **GPU 管理**（3.1.5）查看卡余量。
2. **创建云主机** 时 **直通 GPU / vGPU**（3.2.5）。
3. **NUMA + 大页** 调优（3.2.2、3.2.3）提升推理性能。

---

### 3.11.3 监控

- **云主机详情 > 性能 Tab**：CPU/GPU/内存曲线（若采集）。
- **云监控 > 运维监控**：池级指标（3.14）。

边缘/云边场景见 **3.15** 与白皮书 **3.11.5**。

### 7.4 CPU 调优

**参见白皮书**：3.2.2 精细化 CPU 管理。

---

#### 计算规格

**入口**：`创建向导 > 计算与规格`

**操作步骤**：

1. 在创建向导进入 **计算与规格** 页面。
2. 在 **CPU** 中选择预设核数；需要自定义规格时选择 **自定义** 并填写 vCPU 数量。
3. 在 **内存** 中选择预设容量；需要自定义容量时选择 **自定义** 并填写内存值。
4. 展开 **CPU 拓扑**，按业务需要填写 Socket、Core、Thread。
5. 如果需要独占物理核，勾选 **Dedicated CPU**。
6. 如果需要限制或保障 CPU 资源，填写 **CPU QoS** 的请求值和上限值。
7. 如果需要 NUMA 优化，选择 **Guest NUMA 自动映射** 或 **手动 NUMA 拓扑**。
8. 选择手动 NUMA 时，填写 NUMA 节点数，并查看页面下方的拓扑预览。
9. 如果需要后续在线扩容，开启 **CPU 内存热扩容**。
10. 单击 **下一步**，进入 **存储与磁盘**。

**操作效果**：

- 云主机创建后会按所选 vCPU、内存和拓扑启动。
- 开启 **Dedicated CPU** 后，云主机会申请独占 CPU 资源，适合性能敏感业务。
- 设置 **CPU QoS** 后，调度和运行时会按请求值和上限值控制 CPU 资源。
- 启用 NUMA 后，系统会按 NUMA 策略组织 vCPU 和内存，降低跨 NUMA 访问带来的性能损耗。
- 启用热扩容后，后续可在支持范围内调整 CPU 或内存；同时 NUMA 和大页内存会被禁用，界面会给出提示。
- 如果配置互斥或不满足校验，页面会阻止进入下一步，并提示需要修改的字段。

**校验说明**：

- NUMA 需要先启用 **Dedicated CPU**。
- NUMA 与热扩容不能同时启用。
- 手动 NUMA 模式下，vCPU 总数必须能被 NUMA 节点数整除。
- 手动 NUMA 模式下，Socket 数必须匹配 NUMA 节点数要求。

#### 性能设置

**入口**：`云主机详情 > … > 性能调优 > 性能设置`

**操作步骤**：

1. 打开云主机 **详情抽屉**。
2. 打开 **更多菜单**。
3. 选择 **性能调优**。
4. 选择 **性能设置**。
5. 在抽屉中修改 CPU 拓扑、Dedicated CPU、CPU QoS、NUMA 模式或大页配置。
6. 单击 **确定** 提交。
7. 等待详情顶栏状态从 **变更同步中** 变为 **配置已同步**。
8. 单击抽屉内 **Reload**，确认配置已更新。

**操作效果**：

- 修改会写入云主机规格配置。
- 配置同步期间，详情页会显示 **变更同步中**。
- 同步完成后，详情页会显示 **配置已同步**。
- 部分 CPU、NUMA 或大页配置需要重启云主机后生效；界面会在状态或提示中说明。
- 如果热扩容正在进行，系统会阻止再次修改规格，避免配置状态冲突。

---

#### 调整规格

**入口**：`详情抽屉工具栏 > 资源配置 > 调整规格`

**操作步骤**：

1. 打开云主机 **详情抽屉**。
2. 在工具栏选择 **资源配置**。
3. 选择 **调整规格**。
4. 修改 vCPU 或内存。
5. 单击 **确定** 提交。
6. 等待详情顶栏状态变为 **配置已同步**。

**操作效果**：

- 云主机规格会更新为新的 vCPU 和内存配置。
- 如果云主机已开启热扩容且当前状态支持在线变更，部分 CPU 或内存调整可在线完成。
- 如果当前配置需要重启，页面会显示待重启提示；重启后新规格完全生效。
- 如果调整超出热扩容上限，页面会阻止提交或提示先调整热扩容上限。

---

#### 热扩容设置

**入口**：`… > 性能调优 > 热扩容设置`

**操作步骤**：

1. 打开云主机 **详情抽屉**。
2. 打开 **更多菜单**。
3. 选择 **性能调优**。
4. 选择 **热扩容设置**。
5. 开启热扩容。
6. 设置 CPU 热扩容上限。
7. 设置内存热扩容上限。
8. 单击 **确定** 提交。
9. 如果页面提示 **热扩容待重启**，按提示重启云主机。

**操作效果**：

- 系统会记录云主机可在线扩容的 CPU 和内存上限。
- 首次启用热扩容后，云主机可能需要重启才能具备在线扩容能力。
- 热扩容启用后，NUMA 和大页内存不可同时使用。
- 后续执行 **调整规格** 时，只能在热扩容上限内调整。

---

#### 查看宿主机 NUMA

**入口**：`集群 > 计算配置 > 计算节点 > 单击节点名`

**操作步骤**：

1. 进入 **集群**。
2. 打开 **计算配置**。
3. 进入 **计算节点** 列表。
4. 单击目标节点名称。
5. 在节点详情中查看 NUMA 节点数、CPU 分布和内存分布。

**操作效果**：

- 可以确认宿主机 NUMA 拓扑是否满足云主机调优要求。
- 可以据此选择手动 NUMA 的节点数。
- 排查 NUMA 创建失败时，可以用该页面核对节点资源是否满足要求。

---

#### 调度策略

**入口**：`云主机详情 > … > 调度策略`

**操作步骤**：

1. 打开云主机 **详情抽屉**。
2. 打开 **更多菜单**。
3. 选择 **调度策略**。
4. 选择 **节点选择器**，配置固定主机或故障域。
5. 选择 **节点亲和性**，配置基于节点标签的调度偏好。
6. 选择 **虚拟机间亲和性**，配置同宿或分散策略。
7. 选择 **高可用设置**，配置重启策略或驱逐策略。
8. 单击 **确定** 提交。

**操作效果**：

- 节点选择器会限制云主机可运行的宿主机范围。
- 节点亲和性会影响调度器选择节点的优先级。
- 虚拟机间亲和性会影响多台云主机的同宿或分散关系。
- 高可用设置会影响节点故障或维护时云主机的恢复行为。
- 已创建云主机修改调度策略后，可能需要迁移或重启才能体现最终运行位置。

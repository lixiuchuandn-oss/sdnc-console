## 16. 典型场景

**主入口**：跨资源池多个菜单协作完成。

前面各章按菜单逐项说明功能，本章给出几条 **端到端操作流程（SOP）**，把分散在多章的步骤串成一条可照做的主线。每条场景标注目标、前置条件、分步操作（指向对应章节）、验证与注意事项。

---

### 16.1 交付一台可公网访问的云主机

**目标**：从零交付一台能被公网访问（或可访问公网）的云主机。

**适用角色**：平台管理员或具备相应写权限的租户用户。

**前置条件**：已进入目标资源池；有可用项目；公共子网已在集群侧规划（见 **6.2.3**）。

**步骤**：

1. **准备项目**：确认有可用项目，或新建项目（见 **6.1.6**）。
2. **准备子网**：按隔离需求二选一——扁平子网（见 **13.1**）或 VPC + 子网（见 **14.1**、**14.2**）。
3. **准备镜像**：上传并同步云主机镜像至 **就绪**（见 **7.7.1**）。
4. **创建云主机**：用快速创建（见 **7.1**）或创建向导（见 **7.2**），在网络步选用上一步的子网，并设置登录凭据（见 **7.2.6**）。
5. **配置公网**：
   - 创建弹性公网 IP（扁平见 **13.3**、VPC 见 **14.3**）；
   - 出公网用 SNAT（**13.4** / **14.4**）；对外发布服务用 DNAT（**13.5** / **14.5**）。
6. **放行安全组**（扁平网络）：按需在安全组放行入/出方向端口（见 **13.2**）。

**验证**：

- 在云主机详情确认 **运行中** 与已分配 IP（见 **7.3**）。
- 出公网：登录云主机访问外网；对外发布：从外部访问 EIP 的映射端口。

**注意**：EIP 来自公共子网；扁平与 VPC 的 EIP/NAT 各自独立，勿混用；目标云主机须运行中且已分配 IP，DNAT 才能解析到内部地址。

### 16.2 交付一台带 GPU 的云主机

**目标**：交付一台分配了 GPU 的云主机。

**适用角色**：平台管理员或具备云主机创建向导写权限的用户。

**前置条件**：GPU 已由运维在集群侧纳管并启用；镜像与节点架构匹配。

**步骤**：

1. **核对 GPU 余量**：在 `集群 > 计算资源 > GPU 管理` 查看全集群 GPU 占用与空闲（见 **6.1.7**）。
2. **进入创建向导**（见 **7.2**）。
3. **基本信息**：如需绑定特定主机上的 GPU，运行位置选 **指定主机** 或 **故障域**（见 **7.2.2**）。
4. **计算与规格**：展开 **GPU 分配**，选择模式（直通/vGPU/SR-IOV）并在表格中单选一块 GPU（见 **7.2.3**）。
5. 完成存储、网络、登录、高级设置（见 **7.2.4**–**7.2.7**）。
6. 提交创建（见 **7.2.8**）。

**验证**：在云主机详情确认规格含 GPU、状态运行中（见 **7.3**）；进入来宾系统确认识别到 GPU。

**注意**：指定主机时须选该节点上的 GPU；直通 GPU 绑定物理节点，会限制热迁移（见 **7.4.3**）；GPU、PCI/USB 直通设备需位于同一节点。

### 16.3 为云主机配置定时备份并演练恢复

**目标**：为云主机建立周期性备份，并验证可成功恢复。

**适用角色**：平台管理员或具备云备份写权限的租户用户。

**前置条件**：资源池的备份目标已正确配置。

**步骤**：

1. **手动备份验证**：先手动为目标云主机创建一次备份，确认能到 **就绪**（见 **12.1.2**）。
2. **创建定时策略**：设置类型（备份/快照）、频率（每天/每周/自定义 Cron）与保留数量（见 **12.3.2**）。
3. **演练恢复**：从一个就绪备份执行 **恢复**，恢复模式选 **新建虚拟机** 以免影响现网（见 **12.1.3**）。
4. **跟踪恢复任务**：在恢复任务 Tab 查看进度（见 **12.4**）。

**验证**：恢复任务完成后，在云主机列表确认新建的云主机可启动并运行（见 **7.3**）。

**注意**：**替换** 模式会停止并覆盖原云主机，演练请用 **新建**；保留数量超出后会自动清理最早的备份；删除云主机前确认已有可恢复点。

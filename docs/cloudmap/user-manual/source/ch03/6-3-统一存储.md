### 6.3 统一存储

**适用角色**：平台管理员或存储运维。**参见**：第 4 章（统一存储权限）。

统一存储分组含 **存储配置** 与 **StorageClass** 两个侧栏项。**存储配置** 是一个页面：未部署时为部署向导，部署完成后切换为多个运维 Tab（存储概览、配置详情、存储池、扩容存储、变更存储网、SDRS 策略、任务日志、RBD Mirror）。

---

#### 6.3.1 存储概览

**入口**：`集群 > 统一存储 > 存储配置 > 存储概览`

![存储概览](assets/ch03-cluster/storage-overview.png)

1. 进入 **存储配置**，部署完成后默认进入 **存储概览** Tab。
2. 查看分布式存储的健康状态、容量、存储池、OSD 等仪表盘卡片，以及 IOPS/吞吐等图表。
3. **刷新** 重新拉取概览与监控数据。

**操作效果**：只读总览；部署与改配在同页其它 Tab 进行。

---

#### 6.3.2 首次部署统一存储

**入口**：`集群 > 统一存储 > 存储配置`

![统一存储部署向导](assets/ch03-cluster/storage-deploy-wizard.png)

**前置条件**：各节点数据盘未被占用；网络规划就绪。

未部署时，**存储配置** 显示部署向导，按顶部步骤逐步配置：

| 步  | 名称           | 操作要点                                                                       |
| --- | -------------- | ------------------------------------------------------------------------------ |
| 1   | **存储网**     | 可选专用存储 VLAN/集群网络；不启用则与管理网共用                               |
| 2   | **存储节点**   | 为每个节点勾选数据盘；建议各节点盘数一致                                       |
| 3   | **集群服务**   | 设置 MON/MGR 数量、是否内置监控面板等                                          |
| 4   | **容量与策略** | 副本数、压缩、OSD 引擎、每盘 OSD 数；StorageClass 回收策略、分配模式、在线扩容 |
| 5   | **确认提交**   | 核对摘要后提交，等待部署完成                                                   |

**操作步骤**：

1. 逐步填写各步并单击 **下一步**（每步有校验，磁盘不足或网络未选会提示）。
2. 在最后一步核对摘要并 **提交**。
3. 等待部署完成，页面切换为运维 Tab 视图。

**操作效果**：部署成功后形成统一分布式存储，并生成可供云盘使用的 StorageClass。

**注意**：部署进行中表单可能禁用；请勿中途变更节点磁盘占用。

---

#### 6.3.3 存储运维

**入口**：`集群 > 统一存储 > 存储配置`（部署完成后）

部署完成后，**存储配置** 页提供以下运维 Tab：

| Tab            | 操作                                                                                                                    |
| -------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **配置详情**   | 只读查看当前 MON 数、副本、压缩、StorageClass 策略、存储网等摘要                                                        |
| **存储池**     | 查看存储池列表（名称、副本、应用）；创建/编辑/删除存储池（删除为高风险，有二次确认）                                    |
| **扩容存储**   | **刷新磁盘** 拉取最新数据盘 → **添加节点** → 在节点磁盘编辑器勾选新增磁盘（已纳入集群的磁盘不可移除）→ **提交**（确认） |
| **变更存储网** | 配置 Ceph 存储网（VLAN、集群网络、CIDR），**保存**（确认）；变更对新部署/扩容生效，存量不自动迁移                       |
| **SDRS 策略**  | 查看/编辑存储负载均衡（存储 DRS）规则，启用/禁用                                                                        |
| **任务日志**   | 查看存储 DRS 相关任务执行日志，**刷新**                                                                                 |

**操作效果**：在不重新部署的前提下扩容、调整存储网与负载均衡策略。

**注意**：扩容只增不减，已纳入集群的数据盘不可在此移除；存储网变更不会自动迁移存量 OSD。

---

#### 6.3.4 RBD Mirror

**入口**：`集群 > 统一存储 > 存储配置 > RBD Mirror`

1. 在 **存储配置** 页切换到 **RBD Mirror** Tab，查看镜像复制配置与 Peer 状态、同步延迟。
2. **创建 / 编辑**：配置对端集群地址、存储池、密钥。
3. **查看 YAML** 核对同步配置；**刷新** 同步。

**操作效果**：用于块存储跨集群/跨池的镜像复制（灾备）。

---

#### 6.3.5 StorageClass

**入口**：`集群 > 统一存储 > StorageClass`

![StorageClass 列表](assets/ch03-cluster/storageclass-list.png)

1. 查看 StorageClass 列表：名称、Provisioner、关联存储池、回收策略、是否默认（系统类已过滤）。
2. 单击名称打开详情抽屉查看参数。
3. **刷新** 同步集群 StorageClass。

**操作效果**：StorageClass 决定云盘的存储后端与策略；创建云盘或在创建向导 **存储与磁盘** 中按需选用（参见 **7.2.4**、**11 云存储**）。统一存储部署时会按所选策略生成对应 StorageClass（见 6.3.2）。

**注意**：本页为只读视图，不在此创建或删除 StorageClass；StorageClass 由统一存储部署与集群配置生成。

### 7.13 创建向导 · 高级设置

**参见白皮书**：3.2.6 高级启动管理。

**入口**：`创建向导 > 高级设置`（第 6 步）

---

#### 启动可用性

| 字段         | 选项 / 说明                                       |
| ------------ | ------------------------------------------------- |
| **运行策略** | Always / RerunOnFailure（默认）/ Manual / Halted  |
| **驱逐策略** | LiveMigrateIfPossible（默认）/ LiveMigrate / None |

**含义**：宿主机维护或节点驱逐时，VM 是否 **热迁移** 或 **停机**。

---

#### 固件 TPM

| 字段              | 说明                             |
| ----------------- | -------------------------------- |
| **使用 EFI 固件** | UEFI 启动；Windows 11 等场景勾选 |
| **Secure Boot**   | 依赖 EFI；与镜像兼容             |
| **TPM 2.0**       | 来宾合规/BitLocker 等            |

**注意**：EFI/TPM 变更后通常须 **关机再启动** 生效。

---

#### USB 设备

1. **添加 USB 设备** 行：从下拉选 **PermittedHostDevices** 中已纳管 USB。
2. 展开下拉或 **Reload** 刷新设备列表。
3. 与 **指定主机** 联动：仅显示目标节点可用设备。
4. 集群级查看：`集群 > 直通设备 > USB设备`（3.2.5）。

---

#### Cloud-Init

若 **登录与凭据** 步已生成 userData，此处可 **预览/覆盖** 完整 Cloud-Init 文本。

**虚拟机间亲和** 若在 **基本信息 > 高级调度** 已配置，此处不再重复。

---

#### 提交创建

1. 核对右侧 **摘要面板**（CPU/内存/盘/网卡/位置）。
2. 单击 **创建**；校验失败会定位到对应步骤。
3. 成功后关闭向导，**云主机实例** 列表自动刷新。

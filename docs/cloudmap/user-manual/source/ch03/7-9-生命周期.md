#### 电源管理

**入口**：打开 **云主机详情抽屉** 顶栏工具栏

| 按钮             | 条件                   | 说明                      |
| ---------------- | ---------------------- | ------------------------- |
| **打开终端**     | 运行中；须控制台写权限 | 浏览器内 serial/终端      |
| **开机**         | 已关机                 | 启动 VM                   |
| **关机**         | 运行中                 | 优雅关机                  |
| **重启**         | 运行中                 | 重启来宾                  |
| **暂停 / 恢复**  | 运行中 / 已暂停        | 暂停 vCPU                 |
| **… > 强制停止** | 运行中                 | 相当于断电                |
| **… > 删除**     | —                      | 删除；可能进入 **回收站** |

**… > 热迁移**：仅 **运行中** 且具备写权限；选择目标节点（若需）。

#### 镜像模板

##### 云主机镜像

**入口**：`多云管理 > 资源池管理 > 目标 Cloudmap 池 > 云主机 > 云主机镜像`

**适用角色**：平台管理员或已分配该池 **镜像写权限** 的租户用户。

![云主机镜像列表工具栏](assets/image-list-toolbar.png)

##### 浏览器上传镜像

**前置条件**：资源池状态为 **在线**；Tower 镜像暂存目录剩余空间大于待传文件。

1. 单击工具栏 **新增镜像**。
2. 在弹窗中选择 **浏览器上传** 页签（租户场景可能仅显示此页签）。
3. 单击 **选择镜像文件**，选择本地 `.iso` 或磁盘镜像（如 `.qcow2`）；系统会按文件名自动填充 **镜像名称** 与 **镜像类型**，可按需修改。
4. 单击 **提交任务**。Tower 在后台分片上传到本机暂存目录；弹窗关闭后自动打开 **镜像上传任务** 抽屉，可查看分片进度。

![新增镜像 · 浏览器上传](assets/image-create-browser-upload.png)

![镜像上传任务抽屉](assets/image-upload-tasks-drawer.png)

5. 上传完成后，抽屉提示 **文件已上传至 Tower**；镜像列表会出现状态为 **待同步** 的行。
6. 在列表搜索框输入镜像名称定位该行，单击行末 **…**，选择 **同步**，将镜像导入 Cloudmap 集群（Harvester）。同步进行中请勿删除该行。

![镜像列表 · 待同步与同步操作](assets/image-list-pending-sync.png)

7. 同步成功后，状态变为 **就绪**，可在创建云主机向导 **存储与磁盘** 步选用该镜像。

**注意**：

- 合并后的镜像文件须 **不小于 1 MiB**（平台校验），过小文件会在同步阶段失败。
- 大文件或浏览器不稳定时，可在 **新增镜像 > Windows 桌面工具** 下载 **ImageUploader.exe** 直传集群（实施文档另有说明）。
- 工具栏 **上传任务** 可随时打开抽屉查看历史任务；**待同步** 期间不可在抽屉内删除任务记录，须在镜像列表删除镜像数据。

#### 其他能力

1. **URL 导入**：**新增镜像 > URL 导入**，填写镜像仓、名称与 `http(s)` 下载地址。
2. **标签**：支持 **删除 / 重命名** 镜像标签。
3. 创建 VM 时在 **存储与磁盘** 步选择镜像。

##### 云主机模板

**入口**：`云主机 > 云主机模板`

1. 从现有 VM 导出或新建模板。
2. **创建向导** 或 **快速创建** 时选择模板快速部署。

---

#### 回收站

**入口**：`云主机 > 回收站`

1. 查看已删除实例。
2. **恢复**：还原到 **云主机实例** 列表。
3. **彻底删除**：不可恢复。

---

#### 备份快照

**入口 A**：`详情抽屉 Tab > 备份/快照`

**入口 B**：`云备份 > 云主机备份 / 云主机快照`

1. **创建备份** 或 **创建快照**。
2. 填写名称、保留策略（视弹窗字段）。
3. 成功后 Tab 列表刷新；亦可在 **云备份** 全局 Tab 查看。

详见 **3.9**。

#### 迁移记录

**入口**：`云主机 > 高级配置 > 迁移记录`

查看该池 VM 迁移历史；DRS 记录在 **计算配置 > 迁移记录**（见 3.1.3）。

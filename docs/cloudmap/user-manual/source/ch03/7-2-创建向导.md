### 7.2 通过向导创建

**适用角色**：具备创建向导写权限的租户用户或平台管理员。

创建向导按 **基本信息、计算与规格、存储与磁盘、网络与连接、登录与凭据、高级设置** 六步组织，左侧为步骤导航，中间为当前步表单，右侧为实时摘要。每一步通过校验后才能进入下一步；已通过的步骤会在左侧导航打勾，可随时点回修改。

下面 7.2.2–7.2.7 对应六个步骤，逐项说明字段的操作方式、效果与注意事项；7.2.8 说明提交与查看结果。

---

#### 7.2.1 进入创建向导

1. 进入目标 Cloudmap 资源池。
2. 在左侧菜单打开 **云主机**，进入 **云主机实例** 列表。
3. 单击列表工具栏的 **创建向导**（与 **快速创建** 并列），打开 **创建云主机** 向导。

**操作效果**：向导默认锁定在当前资源池上下文。也可从 **云主机模板** 或现有云主机的 **克隆** 入口进入，此时向导会预填模板或源云主机的配置（参见 **7.4.4**、**7.7.3**）。

---

#### 7.2.2 第一步：基本信息

设定项目、运行位置与名称。

![创建向导 · 基本信息](assets/ch03-vm/vm-wizard-step-basic.png)

**前置条件**：已选资源池；租户须在 **项目** 下拉中有可用命名空间。

**操作步骤与说明**：

1. **资源池**：自池内进入时已锁定，不显示选择框；跨池创建时下拉选择目标资源池，切换后会重新加载项目列表。
2. **项目**：下拉选择命名空间（业务上的项目），打开下拉时会重新加载列表。租户侧会过滤系统与公共项目。
3. **运行位置**：三选一按钮，决定调度方式。
   - **自动调度**（默认）：由平台按资源与策略选择节点；可勾选 **参与指标自动调度**，让平台按节点负载指标择优。
   - **指定主机**：下方出现 **主机列表** 表格，可按名称/IP 搜索、按 **健康/未就绪** 筛选，单选一行作为目标节点；表格列含 CPU/内存使用率。
   - **故障域**：出现 **故障域** 下拉，从集群已创建的故障域中选择。
4. **虚拟机名称**（必填）：显示名称，支持中文；同项目内不可重复，重名会即时提示。
5. **描述**（可选）：填写备注信息。
6. **部署集**（运行位置非「指定主机」时可选）：将本机加入部署集，按集策略分散或同宿；与 **参与指标自动调度** 互斥。
7. 单击 **下一步**；校验通过后进入 **计算与规格**。

**操作效果**：运行位置决定云主机调度到的节点范围；指定主机或故障域会写入相应的调度约束。

**注意**：

- 租户若提示 **未分配到可用项目**，请联系管理员在 **租户管理** 中分配（参见 **5 租户管理**）。
- 选 **指定主机** 时，部署集与指标自动调度不可用。
- 指定主机或故障域会影响后续 GPU、直通设备、扁平子网等按节点过滤的可选项；如需 GPU/直通设备，确保该节点具备对应资源（参见 **7.2.3**、**7.2.5**）。

---

#### 7.2.3 第二步：计算与规格

设定 CPU、内存及其调优，并可分配 GPU。

![创建向导 · 计算与规格](assets/ch03-vm/vm-wizard-step-compute.png)

**操作步骤与说明**：

1. **vCPU 分配**：点选预设 **2 核 / 4 核 / 8 核**，或选 **自定义** 后在右侧输入框填写核数（1–512）。
2. **内存分配**：点选预设 **4 GB / 8 GB / 16 GB**，或选 **自定义** 后填写 GiB 容量。
3. **热扩容**：勾选 **启用** 后，云主机支持运行中在线扩容 CPU/内存，上限为当前配额的 4 倍，不支持缩容；启用后 CPU 拓扑被锁定为「插槽=vCPU、每插槽 1 核、1 线程」。**ARM 架构不支持热扩容**，此项会置灰。
4. **CPU 高级配置**（折叠面板，按需展开）：
   - **CPU 拓扑**：填写插槽、每插槽核心数、线程；总 vCPU = 插槽 × 核心 × 线程，不一致时页面给出 **同步到 vCPU** 按钮。热扩容启用时此项锁定。
   - **CPU 模式**：Host-Passthrough / Host-Model / 自定义；选 **自定义** 时填写型号名称（如 `Skylake-Client-IBRS`）。
   - **CPU 绑定**：勾选后云主机独占固定物理核，减少切换损耗，适合性能敏感业务；启用后 **CPU QoS** 会被清空且不再生效。
   - **CPU 隔离**：将 QEMU 模拟器线程与来宾 vCPU 隔离，降低干扰；需先启用 **CPU 绑定** 或 NUMA。
   - **NUMA 亲和**：选择 **关闭 / 自动映射 / 手动拓扑**；手动模式填写 NUMA 节点数并查看拓扑预览。
   - **CPU QoS**：填写「平时至少需要」与「最多使用」核数；**CPU 峰值保护** 勾选后峰值时自动取消上限限制。
5. **内存高级配置**（折叠面板）：
   - **内存 QoS**：填写内存请求与上限（GiB）；**内存峰值保护** 勾选后峰值时取消内存上限。
   - **大页内存**：勾选 **启用** 并选择 **2 MiB** 或 **1 GiB** 页大小；旁边的说明图标解释预留与 TLB 收益。
6. **GPU 分配**（折叠面板）：
   - **GPU 模式**：**无 / 直通 GPU / vGPU / SR-IOV GPU**（以集群纳管为准，缺项不显示）。
   - 模式非「无」时，下方表格列出 **节点、总线、设备**；单选一行 GPU；可按关键字搜索，右上角刷新可重新拉取。
7. 单击 **下一步**，进入 **存储与磁盘**。

**操作效果**：云主机按所选 vCPU、内存、拓扑与设备启动。绑核、NUMA、大页面向性能敏感场景，可显著降低跨核/跨节点访问损耗。

**校验说明（注意）**：

- NUMA 需先启用 **CPU 绑定**；手动 NUMA 模式下 vCPU 总数须能被节点数整除。
- **热扩容** 与 **NUMA、大页** 互斥，启用其一会自动关闭另一方并提示。
- 启用 **CPU 绑定** 时，目标节点须已开启 CPU 管理，否则无法进入下一步。
- 指定主机 + GPU 时，须选该节点上的 GPU；GPU 余量可在 `集群 > 计算资源 > GPU 管理` 核对（参见 **6 集群**）。

#### 7.2.4 第三步：存储与磁盘

配置系统盘与数据盘。

![创建向导 · 存储与磁盘](assets/ch03-vm/vm-wizard-step-disks.png)

**系统盘**：

1. **来源**：**镜像** / **ISO** / **现有虚拟磁盘**。
   - **镜像**：从就绪的 **云主机镜像** 中选择磁盘镜像，作为系统盘内容。
   - **ISO**：选择 ISO 安装介质，系统盘以 CD-ROM 方式挂载；此时须**至少添加一块非光驱数据盘**作为安装目标，否则无法进入下一步。
   - **现有虚拟磁盘**：选择一块未挂载的现有卷，总线随卷类型推断。
2. **名称**：系统卷名，默认自动生成可改。
3. **容量**：新建时填写 GiB；ISO 来源时容量由所选镜像决定，不可修改。
4. **总线**：VirtIO（推荐）/ SCSI / SATA / IDE / NVMe；ISO 光驱总线按架构固定（ARM 为 SCSI，x86 为 SATA）。

**数据盘**：

1. 单击 **添加数据盘** 增加条目。
2. 每条数据盘可选来源：**新建卷**（填名称、容量、总线、存储类、卷模式）、**已有云盘**（选 Bound 且未挂载的卷）、**ISO**（挂载为 CD-ROM）。
3. 单击行内 **删除** 移除该盘。
4. 多块盘时，列表顺序决定引导顺序。

**操作效果**：系统盘与数据盘随云主机一并创建/挂载；新建卷使用所选或默认 StorageClass。

**注意**：

- Windows 或旧系统建议系统盘总线选 **SATA/IDE**，或确保镜像内含 VirtIO 驱动。
- 大容量数据盘需确认 StorageClass 支持在线扩容（参见 **6 集群** 统一存储、**11 云存储**）。
- 指定主机或直通场景下，选用的现有卷须在目标节点可访问。

---

#### 7.2.5 第四步：网络与连接

配置主网卡与辅助网卡。

![创建向导 · 网络与连接](assets/ch03-vm/vm-wizard-step-networks.png)

**主网卡 · 网络类型**：

1. **扁平子网**：选择 Kube-OVN 扁平子网；可填 **静态 IP、MAC**（格式错误会即时提示）；旁边可打开子网详情查看网段、网关。
2. **VPC 子网**：先选 **VPC**，再选 **子网**；子网若 NAD 未同步会置灰并提示同步中；同样可填静态 IP/MAC。
3. **直通网卡 / 直通 SR-IOV**：先选 **节点**，再从该节点的 **PCI 网卡** 或 **Multus 直通** 选项中选择；与运行位置联动，仅显示该节点设备。
4. **NAD 网络**：选择一个 NetworkAttachmentDefinition（不含 Kube-OVN 类型 NAD）。
5. 主网卡为默认出口，须配置一种有效模式。

**辅助网卡**：

1. 单击 **添加网卡** 增加第二块及更多网卡。
2. 每块网卡独立选择模式，可混合扁平、VPC、直通。
3. 单击行内删除图标移除该网卡。
4. 同一扁平子网在同一云主机内只能使用一次；同一 PCI/Multus 直通资源不可重复选用。

**通用属性**：可设置 **接口类型**、**模型**（virtio/e1000 等）、**MAC 地址**、**静态 IP**（写入 Kube-OVN 注解，非 Cloud-Init network-config）。

**操作效果**：云主机按所选网卡接入对应网络；静态 IP/MAC 在创建时固定下发。

**注意**：

- 多块 PCI 直通网卡须位于同一节点，且与 GPU、USB 等其它直通设备在同一节点。
- 故障域/自动调度下，直通设备须落在具备该设备的节点，否则会 Pending。
- 子网、EIP、安全组等网络资源管理参见 **13 扁平网络**、**14 VPC 网络**。

---

#### 7.2.6 第五步：登录与凭据

设置系统登录方式。

![创建向导 · 登录与凭据](assets/ch03-vm/vm-wizard-step-login.png)

**前置条件**：若用 SSH 公钥，可先在 `云主机 > SSH 密钥` 创建公钥（参见 **7.7.4**）。

**登录方式**（单选，必填）：

| 选项 | 说明 |
| ---- | ---- |
| **设置账户密码** | 选择登录账号（`root` 或 `cloudmap`），填写密码；平台自动生成对应的 Cloud-Init 片段 |
| **设置 SSH 公钥** | 选择登录账号，再从下拉中多选 SSH 公钥（至少 1 把），注入授权密钥 |
| **稍后设置** | 不生成 Cloud-Init，创建后通过控制台或 CloudInit 管理手动配置 |

**密码规则**：长度 8–64 位，不可包含空白字符或冒号（`:`）。

**操作效果**：所选凭据通过 Cloud-Init 注入；生成的 Cloud-Config 可在 **高级设置** 中预览或微调。SSH 公钥下拉展开时会刷新密钥列表。

---

#### 7.2.7 第六步：高级设置

配置启动策略、固件与 USB 设备等。

![创建向导 · 高级设置](assets/ch03-vm/vm-wizard-step-advanced.png)

**启动与可用性**：

- **运行策略**：始终运行（Always）/ 故障重试（RerunOnFailure，默认）/ 手动（Manual）/ 停止（Halted）。
- **驱逐策略**：尽可能热迁移（LiveMigrateIfPossible，默认）/ 强制热迁移（LiveMigrate）/ 不迁移（None）；决定节点维护时云主机是否热迁移。

**固件与 TPM**：

- **使用 EFI 固件**：UEFI 启动，Windows 11 等场景勾选；勾选后可再设 **持久化变量** 与 **启用安全启动**。
- **TPM**：勾选 **启用**（可再选 **持久化状态**），用于来宾合规、BitLocker 等。
- **输入设备**：勾选 **USB Tablet** 改善光标定位。

**管理配置**：

- **Guest Agent**：勾选 **安装 QEMU Guest Agent**，便于读取 IP、执行优雅关机等（无 Cloud-Init 时自动生成）。

**USB 设备**：

1. 单击 **新增 USB 设备**，从下拉选择集群已纳管且启用的 USB 设备；下拉展开或 **刷新资源** 可更新列表。
2. 与运行位置联动，仅显示目标节点可用设备。
3. 若提示未检测到可用 USB 资源，须先由运维在集群侧配置允许的 USB 直通设备。

**Cloud-Init**：若 **登录与凭据** 步已生成 userData，此处可预览或覆盖完整文本。

**操作效果**：以上配置写入云主机启动规格；EFI/TPM 等固件项在创建时一次性固定，后续变更通常须关机再启动。

---

#### 7.2.8 提交创建并查看结果

1. 在右侧 **摘要** 面板核对 CPU/内存、磁盘、网卡、运行位置等关键项。
2. 单击 **创建**。若有未完成的步骤或校验未通过，向导会提示并跳回对应步骤。
3. 提交成功后提示 **创建成功**，向导关闭并返回。

**操作效果**：

- **云主机实例** 列表自动刷新，新增该云主机记录。
- 网络、磁盘、镜像、登录与高级配置随云主机一并写入。
- 创建中显示中间状态，完成后进入运行中或可启动状态。

**查看结果**：在 **云主机实例** 列表单击名称打开详情，查看基础信息、资源配置、网卡与磁盘（参见 **7.3**）。若长期 **Pending** 或失败，在详情 **诊断工具 > 运行诊断** 查看调度与事件信息（参见 **7.3.6**）；常见原因与处理见 **6 常见问题**。

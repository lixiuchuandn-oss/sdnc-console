### 7.10 网络配置

**参见白皮书**：3.4 网络服务、3.4.4 直通网络。

**入口**：`创建向导 > 网络与连接`（第 4 步）

---

#### 主网卡

1. **网络模式**（主网卡）常见选项：
   - **扁平 / Kube-OVN 扁平子网**：选 **子网**；可填 **静态 IP、MAC**（格式错误会 inline 提示）。
   - **VPC 子网**：先选 **VPC**，再选 **子网**；子网若 NAD 未同步会 **置灰**（提示同步中）。
   - **NAD 网络**：选 **NetworkAttachmentDefinition**（不含 kube-ovn 类型 NAD）。
   - **直通整卡 / 直通 SR-IOV**：选 **PCI 网卡** 或 **Multus NAD**（sriov/macvtap/macvlan）；与 **指定主机** 联动，仅显示该节点设备。
2. 主网卡为默认出口，须配置一种有效模式。

---

#### 辅助网卡

1. 单击 **添加网卡** 增加第二块及更多网卡。
2. 每块网卡 **独立** 选择模式（可混合扁平 + VPC + 直通）。
3. 单击 **删除** 图标移除某条辅助网卡。
4. **直通类** 网卡：同一 PCI/Multus 资源不可重复选用；与创建向导其它 PCI 占用互斥。

---

#### 静态 IP MAC

| 字段        | 说明                                                                    |
| ----------- | ----------------------------------------------------------------------- |
| **静态 IP** | Kube-OVN 扁平/VPC 子网；写入 VM annotation，非 CloudInit network-config |
| **MAC**     | 可选自定义；须符合 MAC 格式校验                                         |

子网旁 **详情** 图标（若有）可打开 **子网详情抽屉** 查看 CIDR、网关。

---

#### 运行位置

| 运行位置          | 网络注意                                             |
| ----------------- | ---------------------------------------------------- |
| **指定主机**      | 直通 PCI 须在该主机；Multus 选项按节点过滤           |
| **故障域 / 自动** | 直通设备在调度后须落在具备该设备的节点，否则 Pending |

---

#### 改配已有网卡

**入口**：`云主机详情 > 资源配置 > 网卡管理`

1. **添加 / 删除 / 修改** 网卡、模型（virtio/e1000 等）、MAC。
2. 保存后等待 **配置已同步**；部分变更须 **重启** 或 **关机** 后生效。

扁平/VPC/EIP 边界配置见 **3.4**、**3.4-1**。

## 13. 扁平网络

**主入口**：`Cloudmap 资源池 > 扁平网络`

**适用角色**：具备扁平网络相关权限的平台管理员或网络运维；租户对扁平子网为只读。**参见**：第 4 章（扁平网络权限）。

扁平网络管理 Kube-OVN 扁平子网及其安全组、弹性公网 IP 与 NAT，含 **扁平子网、安全组、弹性公网 IP、SNAT、DNAT** 五个侧栏项。它与 **VPC 网络** 平行分组，各有一套 EIP/NAT；需要逻辑 VPC 隔离时见 **14 VPC 网络**。

> 扁平网络的 EIP 依赖 **公共子网**，公共子网在 `集群 > 网络管理 > 物理网络` 规划（见 **6.2.3**）。

---

### 13.1 扁平子网

**入口**：`扁平网络 > 扁平子网`

1. 查看扁平子网列表：名称、ID、子网分类、CIDR、网关、DHCP、VLAN（无 VLAN 显示 overlay）、已用/总数、创建时间。
2. 单击 **创建扁平子网**，填写：
   - **名称**、**CIDR**、**网关**；
   - **VLAN**（可选，不选为纯 overlay）；
   - **排除 IP**（多行，可保留给网关/保留地址）；
   - **启用 DHCP 服务**（默认开启）。
3. 行操作 **查看详情 / 查看 YAML / 删除**。
4. 保存后，在云主机创建向导 **网络与连接** 选用该扁平子网（见 **7.2.5**）。

**操作效果**：扁平子网为云主机提供二层互通的地址段。

**注意**：删除前须无云主机网卡、EIP、SNAT/DNAT 引用，否则会被拦截；租户对扁平子网为只读。

---

### 13.2 安全组

**入口**：`扁平网络 > 安全组`

---

#### 13.2.1 创建安全组

1. 查看安全组列表：名称、子网、规则数、应用到云主机数、描述、更新时间。
2. 单击 **新建安全组**，填写 **名称**、选择 **扁平子网**、填写 **描述**（可选）。

**操作效果**：安全组绑定到某扁平子网，对该子网上的云主机生效。

---

#### 13.2.2 配置访问控制规则

1. 在目标安全组行操作选择 **访问控制**，打开抽屉，含 **入方向 / 出方向 / 关联云主机** 三个 Tab。
2. 在 **入方向** 或 **出方向** 添加规则，每条规则填写：
   - **优先级**（数值越小越优先）；
   - **策略**：允许 / 拒绝；
   - **协议**：TCP / UDP / ICMP；
   - **源**（入方向）或 **目的**（出方向）：CIDR 或 IP；
   - **源端口 / 目的端口**（可选）。
3. 在 **关联云主机** Tab 将同子网的云主机 **加入 / 移出** 本安全组。

**操作效果**：规则按方向与优先级对关联云主机的进出流量放行或拒绝。

**注意**：安全组只能关联 **同一扁平子网** 上的云主机；变更后用 **刷新** 确认规则已同步。

---

### 13.3 弹性公网 IP

**入口**：`扁平网络 > 弹性公网 IP`

1. 查看 EIP 列表：名称、ID、所在公共子网、IP 地址、MAC、类型、状态、创建时间。
2. 单击 **创建公网IP**，填写：
   - **名称**；
   - **公共子网**（EIP 从公共子网分配，非扁平子网）；
   - **指定 IP**（可选，须在所选公共子网网段内）。
3. 行操作 **查看元数据 / 删除**。

**操作效果**：EIP 作为公网地址，供 SNAT 出公网或 DNAT 对外发布引用。

**注意**：EIP 页不直接绑定云主机网卡；公网访问通过 SNAT/DNAT 关联（见 13.4、13.5）。解绑或删除前确认无 NAT 规则在用。

---

### 13.4 SNAT

**入口**：`扁平网络 > SNAT`

1. 查看 SNAT 列表：名称、ID、扁平子网/CIDR、公网 IP、创建时间。
2. 单击 **创建 SNAT 网关**，填写：
   - **名称**（可选）；
   - **选择公网 IP**（已有 EIP）；
   - **选择扁平子网**（源网段取该子网 CIDR）。
3. 行操作 **查看元数据 / 删除**。

**操作效果**：所选扁平子网内的云主机经该公网 IP 访问外网。

**注意**：同一「公网 IP + 扁平子网」组合不可重复创建 SNAT；不通时核对公共子网、EIP 状态与安全组。

---

### 13.5 DNAT

**入口**：`扁平网络 > DNAT`

1. 查看 DNAT 列表：名称、ID、公网 IP、公网端口、协议、内部 IP、内部端口、创建时间。
2. 单击 **创建 DNAT 规则**，填写：
   - **名称**（可选）；
   - **公网 IP**、**协议**（TCP/UDP）；
   - **公网端口**（支持单端口或范围，如 `80` 或 `1-10`）；
   - **子网** 与 **虚拟机**（内部 IP 由所选云主机网卡解析；多网卡时再选网卡/IP）；
   - **内部端口**（数量须与公网端口一致）。
3. 行操作 **查看元数据 / 删除**。

**操作效果**：外部访问公网 IP 的指定端口被转发到内部云主机的对应端口。

**注意**：同一「公网 IP + 协议」下公网端口不可冲突；目标云主机须运行中且已分配 IP。删除 DNAT 前确认对外业务已迁移或停用。

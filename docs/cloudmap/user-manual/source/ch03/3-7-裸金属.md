## 3.7 裸金属

**参见白皮书**：3.7；API 见 `docs/maas-integration.md`；前端 `pages/cnmc/clouds/maas/`。

**入口**：`多云管理 > 资源池管理 > MAAS 类型资源池`

进入后侧栏为 **MAAS 池** Tab（与 Cloudmap 侧栏结构不同）。

---

### 3.7.1 概览

**Tab**：**概览 / Dashboard**

查看机器总数、按状态分布、子网与镜像摘要；**Reload** 刷新。

---

### 3.7.2 机器列表与详情

**Tab**：**机器**

1. 列表：主机名、状态（Ready/Deployed/…）、电源、IP。
2. 单击进入 **详情**：硬件、网卡、磁盘、事件。
3. 行操作 / 详情页 **操作**：**开机、关机、部署、释放** 等。
4. **部署**：选择 **镜像、子网**；确认后进入 OS 安装流程。

---

### 3.7.3 发现

**Tab**：**发现**

1. 新机器 PXE 启动后出现在 **发现** 列表。
2. **接纳** 为可用机器或 **忽略**。

---

### 3.7.4 镜像

**Tab**：**镜像**

1. 查看 MAAS 镜像 catalog。
2. **同步** 自定义镜像（若有按钮）。
3. 部署机器时在 **部署** 对话框选择镜像。

---

### 3.7.5 网络

**Tab**：**网络**

查看 **子网、VLAN、空间（space）**；创建/编辑子网（须权限）。

---

### 3.7.6 接入配置

在 **资源池管理** 接入 MAAS 时配置：

- `provider=maas`
- API URL、OAuth 密钥（BFF OAuth1 v2）

连接测试通过后租户/运维方可使用上述 Tab。

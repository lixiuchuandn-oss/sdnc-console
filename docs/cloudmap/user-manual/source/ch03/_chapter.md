# 3. 功能操作指南

本章与 **《技术白皮书》第 3 章** 节号对齐。

- **白皮书**：说明能力、架构与价值。
- **本章**：说明 **菜单路径、操作步骤、注意事项**。

阅读路径建议：

1. 首次使用先读 **第 2 章** 进入资源池；**查 Tab 对应章节** 用 **3.0 侧栏功能索引**。
2. 云主机：**3.2.0 → 3.2.1–3.2.11（创建向导六步）→ 3.2.12（详情改配）**；性能见 3.2.2–3.2.3。
3. 存储 **3.3 / 3.3.1 / 3.3.2 / 3.3.6**；网络 **3.4.1–3.4.4、3.4.8**；容器 **3.5**；备份 **3.9**；监控 **3.14**。

文中 **入口** 统一写作：`多云管理 > … > Cloudmap 池内 Tab`；池内步骤省略重复前缀时，默认已在当前 Cloudmap 资源池上下文中。

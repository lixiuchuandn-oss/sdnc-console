## 9. 虚拟网元

**入口**：`网络 > 虚拟网元` 侧栏分组（poolNavGroup：`oniaas_network`）

---

### 9.1 虚拟路由器

**Tab**：`虚拟网元 > 虚拟路由器`

**适用角色**：平台管理员或网络运维。**参见**：第 4 章（虚拟网元权限）。

1. **列表**：已纳管 **虚拟路由器（VR）** 实例：名称、型号、管理 IP、同步状态。
2. **同步 / Reload**：从控制面或缓存刷新 VR 列表（Toolbar **Reload**）。
3. **详情抽屉**（点击名称）：
   - **概览**：版本、状态、最近同步时间。
   - **接口 / 路由 / NAT 等**（以实际 Tab 为准）：查看或编辑配置片段。
4. **创建 / 纳管**（若有 write）：填写 VR 连接信息、凭据 → 保存 → 等待 **在线**。
5. **删除 / 解绑**：行操作（确认弹窗）。

**说明**：VR 配置与 **SDNCC** 控制面联动；Cloudmap 池内以 **实例纳管与状态查看** 为主，复杂编排见 SDN 产品线文档（本手册不展开）。

---

### 9.2 负载均衡

**Tab**：`虚拟网元 > 负载均衡器`

1. **列表**：LB 实例、VIP、后端池数量、健康状态。
2. **创建**：
   - 选择 **VR 或 LB 类型**、监听端口、算法。
   - 配置 **后端成员**（云主机 IP / 端口）。
   - 提交后等待 **Active**。
3. **编辑**：修改监听、成员、健康检查。
4. **删除**：行操作 + 确认。
5. **Reload** 刷新列表。

---

### 9.3 服务边界

| 能力                             | 位置                         | 场景                                               |
| -------------------------------- | ---------------------------- | -------------------------------------------------- |
| **Kubernetes Service / Ingress** | `容器服务`（**3.12**）       | 集群内 Pod/Service 暴露                            |
| **Kube-OVN EIP / FIP**           | `网络 > Kube-OVN`（**3.4**） | 租户 VPC 公网入口                                  |
| **VR + LB（本节）**              | `虚拟网元`                   | 南北向 **L3/L4 网元**、多 VPC 出口、硬件式 LB 语义 |
| **集群负载均衡**                 | `集群 > 平台网络 > 负载均衡` | Harvester/Kube-OVN 侧 LB CR，见 **3.4** §3.4.5     |

---

### 9.4 常见问题

| 现象              | 建议                                                 |
| ----------------- | ---------------------------------------------------- |
| VR **离线**       | 检查管理网、凭据、控制面同步任务                     |
| LB **后端不健康** | 核对成员 IP 可达、健康检查端口、安全组               |
| 列表 **空**       | 确认资源池类型含 **oniaas_network** Tab；权限 `read` |

## 9. 虚拟网元

**主入口**：`Cloudmap 资源池 > 虚拟网元`

**适用角色**：具备虚拟网元权限的平台管理员或网络运维。**参见**：第 4 章（虚拟网元权限）。

虚拟网元含 **虚拟路由器** 与 **负载均衡器** 两个侧栏项。虚拟路由器底层是一台基于网元镜像的 Cloudmap 资源池云主机，通过自带管理台编排路由/NAT 等；负载均衡器是基于 IP 地址池与云主机标签的四层负载均衡。

---

### 9.1 虚拟路由器

**入口**：`虚拟网元 > 虚拟路由器`

---

#### 9.1.1 查看虚拟路由器

![虚拟路由器列表](assets/ch03-vne/vrouter-list.png)

1. 进入 **虚拟路由器** 列表，查看：实例名称、网元类型、版本、状态、IP 地址、管理地址、节点、CPU、内存、创建时间。
2. 按 实例名称、状态、节点筛选；**刷新** 同步。
3. 行操作：**管理台**（打开网元自带 Web 管理界面）、**云主机详情**、**编辑标签**、**查看 YAML**。

**操作效果**：列表反映各虚拟路由器实例的运行状态；数据与云主机列表同源。

---

#### 9.1.2 创建虚拟路由器

![创建虚拟路由器](assets/ch03-vne/vrouter-create-modal.png)

1. 单击工具栏 **创建实例**。
2. 填写 **实例名称**（已自动生成，可改）。
3. 选择 **规格**（预设或自定义 vCPU/内存）。
4. 选择 **网元类型**、**镜像** 与 **系统盘容量**。
5. 选择 **网络**（扁平子网）。
6. 单击 **立即创建**。

**操作效果**：按所选镜像创建一台网元云主机并接入网络，状态进入 **运行中** 后可通过管理台编排。

---

#### 9.1.3 管理与运维

1. 在目标实例行操作选择 **管理台**，进入网元自带界面配置接口、静态路由、NAT、ACL 等。
2. 实例的电源、改配、备份等通过 **云主机详情** 完成（见 **7.4**、**7.5**）。

**操作效果**：路由/NAT 等网元编排在管理台内完成；平台层提供实例生命周期与资源管理。

**注意**：虚拟网元为 Cloudmap 资源池内的网元云主机，路由器/NAT 等具体配置在网元管理台内维护；与跨站点 SDN 控制面（另一产品线）不共用同一套界面。

---

### 9.2 负载均衡器

**入口**：`虚拟网元 > 负载均衡器`

---

#### 9.2.1 查看负载均衡器

![负载均衡器列表](assets/ch03-vne/slb-list.png)

1. 进入 **负载均衡器** 列表，查看：名称、项目、地址、地址分配模式、监听器摘要、创建时间。
2. 按 名称、项目、IP 分配模式筛选；**刷新** 同步。
3. 行操作 **查看 YAML / 删除**（可在多选后 **批量删除**）。

---

#### 9.2.2 创建负载均衡器

![创建负载均衡](assets/ch03-vne/slb-create-modal.png)

**前置条件**：已存在可用的 **IP 地址池**（在 `集群 > 网络管理 > 集群网络 > IP 地址池` 维护，见 **6.2.8**）。

1. 单击 **创建负载均衡**。
2. **基本信息**：填写 **名称**、选择 **项目**。
3. **IP 分配模式**：选择 **IP Pool（自动分配）**，并选择 **地址池**。
4. **监听端口配置**：添加一条或多条，填写名称、协议（TCP/UDP）、前端端口 → 后端端口。
5. **后端关联标签**：添加 **标签 Key = Value**，流量转发到带该标签的云主机。
6. 单击提交。

**操作效果**：负载均衡器从地址池获取 VIP，按监听端口将流量转发到匹配标签的云主机。

**注意**：

- 后端通过 **云主机标签** 匹配，无独立后端池成员与健康检查算法配置。
- 无可用 IP 地址池时无法创建，请先创建地址池（见 **6.2.8**）。

---

### 9.3 与其它网络能力的关系

| 能力                              | 位置                                                 | 场景                                           |
| --------------------------------- | ---------------------------------------------------- | ---------------------------------------------- |
| **虚拟路由器 / 负载均衡器**       | 本章                                                 | 网元云主机做路由/NAT；基于地址池的四层负载均衡 |
| **集群负载均衡**                  | `集群 > 网络管理 > 集群网络 > 负载均衡`（**6.2.7**） | 集群侧负载均衡（与本章负载均衡同源）           |
| **容器 服务 / Ingress / 网关**    | 容器服务（**10.4–10.6**）                            | 集群内 Pod/Service 暴露                        |
| **扁平 / VPC 的 EIP、SNAT、DNAT** | 扁平网络（**13**）、VPC 网络（**14**）               | 租户网络的公网出入口                           |

---

### 9.4 常见问题

| 现象                  | 建议                                                                    |
| --------------------- | ----------------------------------------------------------------------- |
| 虚拟路由器 **未运行** | 在云主机详情查看状态与事件，必要时重启（见 **7.4.1**）                  |
| 负载均衡 **无法创建** | 确认已存在 IP 地址池（见 **6.2.8**）                                    |
| 后端不通              | 核对云主机标签是否匹配、监听端口与云主机服务端口、安全组（见 **13.2**） |

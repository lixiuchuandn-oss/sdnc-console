### 7.3 查看云主机

**适用角色**：具备云主机读权限的租户用户或平台管理员。

查看分两层：**云主机实例** 列表用于总览、筛选与快捷操作；**详情抽屉** 用于查看单台云主机的完整信息，并作为后续变更、排障、删除前确认的入口。本节 7.3.1 说明列表，7.3.2–7.3.3 说明如何进入详情及详情结构，7.3.4–7.3.6 说明详情内的性能、备份与诊断。

---

#### 7.3.1 查看云主机列表

**入口**：`云主机 > 云主机实例`

1. 进入目标 Cloudmap 资源池，打开 **云主机**，进入 **云主机实例**。
2. 用工具栏的搜索框与筛选条件定位目标云主机（按名称、项目、状态等）。
3. 查看列表各列信息；如需调整显示列，使用工具栏的 **列展示** 勾选或隐藏列。
4. 在目标行末单击 **…** 打开行操作菜单，执行查看、访问、电源、标记或删除等操作。
5. 单击工具栏 **刷新** 重新拉取资源池中的最新状态。

![云主机实例列表](assets/ch03-vm/vm-list-overview.png)

**列表字段**：

| 列                            | 说明                                                                                        |
| ----------------------------- | ------------------------------------------------------------------------------------------- |
| **云主机名称**                | 显示名称，前缀为操作系统图标；可单击进入详情；管理员/有写权限时名称后有别名编辑（铅笔）图标 |
| **云主机 ID**                 | 平台内的唯一标识                                                                            |
| **状态**                      | 运行状态标签，详见下「状态含义」                                                            |
| **项目 / 租户 / 组织**        | 所属命名空间与归属（租户登录时不显示「租户/组织」列）                                       |
| **节点**                      | 当前所在宿主机                                                                              |
| **CPU / 内存**                | 当前规格                                                                                    |
| **GPU / 网卡直通 / USB 直通** | 已分配的直通设备（默认隐藏，可在 **列展示** 中打开）                                        |
| **热扩容**                    | 是否已开启 CPU/内存热扩容（已开启 / 未开启）                                                |
| **镜像 / 操作系统**           | 系统盘来源镜像与识别出的操作系统                                                            |
| **IP 地址 / MAC 地址**        | 主网卡地址                                                                                  |
| **存储卷**                    | 系统卷、数据卷的容量与状态摘要                                                              |
| **创建时间**                  | 云主机创建时间                                                                              |

**名称列上的标记**：

- **盾牌图标**：该云主机被标记为 **重要实例**（开启防删保护），不可直接删除。
- **「克隆」标签**：该云主机由克隆创建，悬停可见克隆来源。

**状态含义**：

- 主状态以彩色圆点 + 文字展示，常见为 **运行中、启动中、迁移中、停止中、已停止、已暂停、删除中、错误**。
- 主状态旁可能附加临时标签：**磁盘扩容中 / 磁盘待扩容**（卷扩容过程中）、**克隆进行中 / 克隆完成**（克隆卷就绪状态）。

**行操作菜单**（行末 **…**，按状态与权限显示）：

| 操作                                 | 说明与去向                                             |
| ------------------------------------ | ------------------------------------------------------ |
| **实例详情**                         | 打开详情抽屉（见 7.3.2）                               |
| **访问 VNC**                         | 打开图形控制台（云主机须非停止；终端/控制台见 7.4.2）  |
| **分配云桌面**                       | 将运行中的云主机分配给云桌面用户（管理员，需网关就绪） |
| **启动 / 停止 / 重启 / 暂停 / 恢复** | 电源操作（见 7.4.1）                                   |
| **设为重要实例 / 取消重要标记**      | 开关防删保护                                           |
| **强制停止 / 强制重启**              | 高风险操作，有确认                                     |
| **删除**                             | 删除云主机（重要实例受保护时不可删；见 7.6）           |

**操作效果**：列表反映资源池中云主机的实时运行状态、规格与所在节点；单击 **刷新** 会从资源池重新同步，而非仅读取本地缓存。增删改成功后列表会自动更新。

---

#### 7.3.2 打开云主机详情

**入口**：`云主机实例` 列表单击 **名称**（名称列为可点击链接），或行操作 **… > 实例详情**

1. 在列表中单击目标云主机名称，或在行操作菜单选择 **实例详情**。
2. 右侧滑出 **详情抽屉**。

![详情抽屉 · 详情 Tab](assets/ch03-vm-detail/vm-detail-drawer-detail-tab.png)

**操作效果**：详情抽屉是查看完整配置以及发起变更、排障、删除前确认的统一入口。无云主机读权限时名称不可点击。

---

#### 7.3.3 详情抽屉概览

详情抽屉分顶栏、工具栏与内容 Tab 三部分。

| 区域         | 内容                                                                        |
| ------------ | --------------------------------------------------------------------------- |
| **顶栏**     | 名称、ID、运行状态标签                                                      |
| **状态标签** | **配置已同步 / 变更同步中**；以及热扩容系列标签（如已启用、待重启、不可用） |
| **刷新**     | 强制重新拉取并聚合该云主机数据                                              |
| **工具栏**   | 终端、电源操作、**资源配置** 下拉、**…** 更多菜单                           |
| **Tab**      | **详情 / 性能 / 备份与快照** 切换                                           |

![更多操作菜单](assets/ch03-vm-detail/vm-detail-more-menu.png)

**工具栏入口去向**：

- **资源配置** 下拉：调整规格、磁盘管理、网卡管理、GPU 管理、USB 管理（变更操作见 7.5）。
- **…** 更多菜单：电源与生命周期（克隆、保存模板、热迁移、强制停止、删除，见 7.4）、性能调优、调度策略、CloudInit 管理、诊断工具（见 7.5、7.3.6）。

**详情 Tab** 展示项目、节点、镜像、CPU/内存、磁盘摘要、网卡、调度标签等；其中 **调度诊断** 区展示节点选择器与节点亲和规则，便于对照 **Pending** 原因。

**操作效果**：顶栏状态标签可快速判断配置是否已下发；提交变更后状态会在 **变更同步中** 与 **配置已同步** 之间切换（见 7.5）。

#### 7.3.4 查看性能监控

**入口**：`详情抽屉 > 性能`

1. 在详情抽屉切换到 **性能** Tab。
2. 在 **CPU / 内存 / 网络 / 磁盘** 之间切换图表。
3. 选择时间范围；单击顶栏 **刷新** 重新拉取曲线。

![性能 Tab](assets/ch03-vm-detail/vm-detail-tab-performance.png)

**操作效果**：展示该云主机的资源使用曲线，用于容量评估与排障。

**注意**：性能曲线依赖资源池监控组件正常运行；监控总体说明参见 **5 云监控**。

---

#### 7.3.5 查看备份与快照

**入口**：`详情抽屉 > 备份与快照`

1. 在详情抽屉切换到 **备份与快照** Tab。
2. 查看该云主机的备份与快照列表。
3. 如需新建，单击 **创建备份** 或 **创建快照**，在当前上下文直接发起（上下文已锁定本机）。

![备份与快照 Tab](assets/ch03-vm-detail/vm-detail-tab-backup.png)

**操作效果**：此处列表与 **云备份** 全局列表同源；删除前可据此确认是否已有可恢复点。

**注意**：备份目标、保留策略与恢复操作详见 **12 云备份**。

---

#### 7.3.6 诊断工具

**入口**：`详情抽屉 > … > 诊断工具`

| 子项          | 说明                                                     |
| ------------- | -------------------------------------------------------- |
| **运行诊断**  | 聚合调度、资源、事件等信息，定位 Pending、启动失败等问题 |
| **查看 YAML** | 只读查看云主机定义，供进阶排障                           |
| **实时日志**  | 若菜单提供，查看串口/控制台日志流                        |

**操作步骤**：

1. 打开云主机 **详情抽屉**，在 **…** 更多菜单中选择 **诊断工具**。
2. 选择 **运行诊断** 查看聚合结果，或选择 **查看 YAML / 实时日志** 进一步排查。

**操作效果**：运行诊断是创建失败、长期 Pending、热扩容不可用等问题的首选排查入口。

**注意**：日志采集对象与外部查询配置参见 **15 日志管理**。

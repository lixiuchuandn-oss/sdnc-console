### 7.3 查看云主机

**适用角色**：租户用户或平台管理员。

查看分两层：**云主机实例** 列表用于总览与筛选，**详情抽屉** 用于查看单台云主机的完整信息并作为后续变更、排障、删除前确认的入口。

---

#### 7.3.1 查看云主机列表

**入口**：`云主机 > 云主机实例`

1. 进入目标 Cloudmap 资源池，打开 **云主机**，进入 **云主机实例**。
2. 用名称、项目、状态等条件筛选列表。
3. 查看列表中的名称、状态、项目、节点、IP、规格等字段。
4. 单击工具栏 **刷新** 重新拉取资源池中的最新状态。

**操作效果**：列表反映资源池中云主机的实时运行状态、规格和所在节点；刷新会从资源池重新同步，而非仅读取本地缓存。

---

#### 7.3.2 打开云主机详情

**入口**：`云主机实例` 列表单击 **名称**（名称列为可点击链接）

1. 在列表中单击目标云主机名称。
2. 右侧滑出 **详情抽屉**。

![详情抽屉 · 详情 Tab](assets/ch03-vm-detail/vm-detail-drawer-detail-tab.png)

---

#### 7.3.3 详情抽屉概览

| 区域 | 内容 |
| ---- | ---- |
| **顶栏** | 名称、ID、运行状态标签 |
| **状态标签** | **配置已同步 / 变更同步中**；以及热扩容系列标签 |
| **刷新** | 强制重新拉取并聚合云主机数据 |
| **工具栏** | 终端、电源操作、**资源配置** 下拉、**…** 更多菜单 |
| **Tab** | **详情 / 性能 / 备份与快照** 切换 |

![更多操作菜单](assets/ch03-vm-detail/vm-detail-more-menu.png)

**详情 Tab** 展示项目、节点、镜像、CPU/内存、磁盘摘要、网卡、调度标签等；**调度诊断** 区展示节点选择器与节点亲和规则，便于对照 **Pending** 原因。

电源、迁移、克隆等操作见 **7.4**；修改规格、磁盘、网卡等见 **7.5**。

---

#### 7.3.4 查看性能监控

**入口**：`详情抽屉 > 性能`

1. 在详情抽屉切换到 **性能** Tab。
2. 切换 **CPU / 内存 / 网络 / 磁盘** 图表。
3. 选择时间范围；顶栏 **刷新** 重新拉取曲线。

![性能 Tab](assets/ch03-vm-detail/vm-detail-tab-performance.png)

**操作效果**：展示该云主机的资源使用曲线，用于容量评估与排障。监控总体说明参见 **5 云监控**。

---

#### 7.3.5 查看备份与快照

**入口**：`详情抽屉 > 备份与快照`

1. 在详情抽屉切换到 **备份与快照** Tab。
2. 查看该云主机的备份与快照列表。
3. 单击 **创建备份** 或 **创建快照** 可在当前上下文直接发起（上下文已锁定本机）。

![备份与快照 Tab](assets/ch03-vm-detail/vm-detail-tab-backup.png)

**操作效果**：此处列表与 **云备份** 全局列表同源；详细策略与恢复见 **12 云备份**。

---

#### 7.3.6 诊断工具

**入口**：`详情抽屉 > … > 诊断工具`

| 子项 | 说明 |
| ---- | ---- |
| **运行诊断** | 聚合调度、资源、事件等信息，定位 Pending、启动失败等问题 |
| **查看 YAML** | 只读查看云主机定义 |
| **实时日志** | 若菜单提供，查看串口/控制台日志流 |

**操作效果**：运行诊断是创建失败、长期 Pending、热扩容不可用等问题的首选排查入口；日志采集配置参见 **15 日志管理**。

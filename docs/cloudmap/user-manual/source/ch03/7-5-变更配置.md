### 7.5 变更配置

**适用角色**：具备云主机写权限的租户用户或平台管理员。

**入口**：`云主机实例 > 单击名称 > 详情抽屉`

创建后的变更都在 **详情抽屉** 中发起：调整规格、磁盘、网卡、GPU、USB 在工具栏 **资源配置** 下拉中；性能调优、调度策略、CloudInit 在 **…** 更多菜单中。

**同步与生效（通用，注意）**：

- 提交变更后，顶栏状态先显示 **变更同步中**，写入完成后变为 **配置已同步**；可单击抽屉 **刷新** 确认。
- 部分配置可在线生效（如热扩容范围内的规格调整）；部分配置须 **重启** 或 **关机再启动** 后生效（如磁盘总线、引导顺序、CPU 绑定、NUMA、大页、固件等），界面会在保存时提示。
- 同步长期停留在 **变更同步中** 时，先 **刷新**，再查看云主机事件，必要时重启（参见 **6 常见问题**）。

---

#### 7.5.1 调整规格

**入口**：`详情抽屉 > 资源配置 > 调整规格`

![调整规格子抽屉](assets/ch03-vm-detail/vm-detail-spec-config.png)

1. 打开云主机 **详情抽屉**，在 **资源配置** 下拉中选择 **调整规格**。
2. 修改 **vCPU** 或 **内存**。
3. 单击 **确定** 提交，等待顶栏变为 **配置已同步**。

**操作效果**：

- 云主机规格更新为新的 vCPU/内存。
- 已开启热扩容且当前状态支持在线变更时，部分调整可在线完成；否则页面提示待重启，重启后完全生效。
- 调整超出热扩容上限时会被阻止，须先到 **热扩容设置** 调高上限（见 7.5.2）。

**注意**：调整规格仅改 vCPU/内存数值；CPU 拓扑、NUMA、大页等高级项在 **性能调优** 中修改（见 7.5.2，字段含义见 7.2.3）。

---

#### 7.5.2 性能调优

**入口**：`详情抽屉 > … > 性能调优`

性能调优含 **性能设置** 与 **热扩容设置** 两个子项。

**性能设置**：

1. 在 **…** 更多菜单选择 **性能调优 > 性能设置**。
2. 按需修改 **CPU 拓扑、CPU 模式、CPU 绑定、CPU 隔离、NUMA 亲和、CPU/内存 QoS、大页内存** 等（各项含义见 7.2.3）。
3. 单击 **确定** 提交，等待 **配置已同步**。

**热扩容设置**：

1. 选择 **性能调优 > 热扩容设置**。
2. 开启 **热扩容**，分别设置 CPU、内存的扩容上限。
3. 单击 **确定** 提交。

**操作效果**：

- 修改写入云主机规格；CPU 绑定、NUMA、大页等通常须重启后生效。
- 首次启用热扩容后，云主机可能需重启才具备在线扩容能力；之后 **调整规格** 只能在热扩容上限内调整。
- 热扩容与 NUMA、大页 **互斥**，启用其一会清除另一方。

**注意**：热扩容不可用的常见原因包括磁盘非共享存储、挂载了阻止迁移的设备等，悬停状态标签可看具体提示。宿主机 NUMA 拓扑可在 `集群 > 计算配置 > 计算节点 > 节点详情` 中核对（参见 **6 集群**）。

---

#### 7.5.3 磁盘管理

**入口**：`详情抽屉 > 资源配置 > 磁盘管理`

![磁盘管理子抽屉](assets/ch03-vm-detail/vm-detail-disk-manage.png)

打开 **磁盘管理** 后，对每块磁盘可执行以下操作，确认后统一保存：

| 操作            | 说明                                                                |
| --------------- | ------------------------------------------------------------------- |
| **添加数据盘**  | 新建卷、挂载已有云盘或挂载 ISO 光驱（字段同创建向导，见 7.2.4）     |
| **扩容**        | 在容量框填写新的更大容量；留空表示本次不改；StorageClass 须支持扩容 |
| **解绑**        | 从云主机规格中移除该磁盘及其卷定义，**不删除集群中的云盘（PVC）**   |
| **更换系统盘**  | 通过 **更换系统盘** 切换系统盘来源（高风险，有确认）                |
| **引导顺序**    | 用 **上移 / 下移** 调整磁盘启动优先级                               |
| **弹出 CD-ROM** | ISO 引导且光驱占用时，从详情 **…** 菜单弹出                         |

**操作步骤**：

1. 打开 **磁盘管理**，对目标磁盘执行扩容、解绑、调序等操作。
2. 如需新增，单击 **添加数据盘** 并填写来源与参数。
3. 保存提交。

**操作效果**：

- 卷扩容在后台进行，列表/详情可见 **磁盘扩容中 / 磁盘待扩容** 标签。
- **磁盘总线类型、引导顺序、解绑** 等变更对运行中云主机须 **重启后生效**，保存时会提示。
- 解绑只从规格移除，集群中的云盘仍保留，可后续重新挂载（云盘与快照管理参见 **11 云存储**）。

---

#### 7.5.4 网卡管理

**入口**：`详情抽屉 > 资源配置 > 网卡管理`

1. 打开 **网卡管理**，查看已绑定网卡卡片（含网络类型、子网、运行态 IP）。
2. 单击顶部按钮 **添加网卡**，按类型选择 **扁平子网 / VPC 网络 / 直通·SR-IOV / NAD 网络**（字段同创建向导，见 7.2.5）。
3. 对已有网卡可调整 **MAC、模型**，用 **上移 / 下移** 调序，或 **解绑** 移除。
4. 保存提交。

**操作效果**：

- 网卡增删改写入云主机规格；部分变更须 **重启** 或 **关机再启动** 后生效。
- 至少须保留一块网卡，最后一块不可删除。
- 直通/SR-IOV 网卡与所在节点绑定，会限制热迁移与指定主机切换。

**注意**：子网、EIP、安全组等网络资源管理参见 **13 扁平网络**、**14 VPC 网络**。

---

#### 7.5.5 GPU 与直通设备

**入口**：`详情抽屉 > 资源配置 > GPU管理`

1. 打开 **GPU管理**，已绑定 GPU 以卡片展示（设备、节点、总线、类型）。
2. 单击顶部按钮按类型添加：**直通 GPU / SR-IOV GPU / vGPU**，从可用设备中选择。
3. 如需更换类型，先 **解绑** 已绑定 GPU，再添加其它类型。
4. 解绑为即时提交，添加在保存后生效。

**操作效果**：

- GPU 变更写入云主机规格；视设备类型，挂载/更换后可能须 **关机再启动** 生效。
- 直通 GPU 绑定物理节点，热迁移受限。

**注意**：PCI 与 SR-IOV **网卡** 直通在 **网卡管理** 配置（见 7.5.4），USB 直通在 **USB 管理** 配置（见 7.5.6）；集群级 GPU/PCI/USB 纳管视图在 `集群 > 计算资源` 查看（参见 **6 集群**）。更改 **指定主机** 前须先卸载相关直通设备。

---

#### 7.5.6 USB 设备

**入口**：`详情抽屉 > 资源配置 > USB管理`

1. 打开 **USB管理**，单击 **添加 USB 设备**。
2. 从集群已纳管且 **启用** 的设备中选择（未被其它云主机占用）。
3. 不再需要时 **解绑** 移除。

**操作效果**：USB 设备与所在节点绑定；多块 USB 须与 GPU、PCI 直通设备位于同一节点，否则保存会被拦截。

**注意**：若无可选设备，须先由运维在集群侧配置允许的 USB 直通设备。

---

#### 7.5.7 调度策略与高可用

**入口**：`详情抽屉 > … > 调度策略`

![节点选择器改配](assets/ch03-vm-detail/vm-detail-node-scheduling.png)

调度策略含四个子项：

| 子项           | 说明                                                                          |
| -------------- | ----------------------------------------------------------------------------- |
| **节点选择器** | 切换 **自动调度 / 固定主机 / 故障域**；固定主机选具体节点，故障域选已定义的域 |
| **节点亲和性** | 基于节点标签配置优先、避让等调度偏好                                          |
| **部署集**     | 让多台云主机按部署集策略同宿或分散（固定主机模式不支持）                      |
| **高可用设置** | 设置 **运行策略** 与 **驱逐策略**（节点维护/驱逐时是否热迁移）                |

**操作步骤**：

1. 打开 **详情抽屉**，在 **…** 菜单选择 **调度策略**，再选对应子项。
2. 按子项填写后单击 **确定** 提交。

**操作效果**：

- **节点选择器** 限制云主机可运行的宿主机范围；切换为自动调度后由平台择优。
- **节点亲和性 / 部署集** 影响调度优先级与多机分布。
- **高可用设置** 影响节点故障或维护时云主机的恢复与迁移行为。
- 已运行的云主机修改调度策略后，可能需迁移或下次启动才体现最终运行位置。

---

#### 7.5.8 登录凭据与 CloudInit

**入口**：`详情抽屉 > … > CloudInit 管理`

1. 打开 **CloudInit 管理**。
2. 编辑 **userData**（账号、密码、初始化命令等）或 **networkData**（网络配置）。
3. **保存** 后按提示重启生效。

**操作效果**：与创建向导 **登录与凭据**、**高级设置** 中的 Cloud-Init 为同一份定义。

**注意**：修改密码、注入 SSH 公钥等通过编辑 userData 实现；可复用的 SSH 密钥在 `云主机 > SSH 密钥` 维护（见 7.7.4）。

---

#### 7.5.9 固件设置

EFI 固件、安全启动、TPM 等若在创建时已设定，变更须通过 **诊断工具 > 查看 YAML** 或后续版本提供的入口处理（以界面为准），且变更后通常须 **关机再启动** 生效。新建云主机时配置固件参见 **7.2.7**。

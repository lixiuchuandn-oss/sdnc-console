### 7.5 变更配置

**适用角色**：具备云主机写权限的租户用户或平台管理员。

**入口**：`云主机实例 > 单击名称 > 详情抽屉`

创建后的变更都在 **详情抽屉** 中操作：规格、磁盘、网卡、GPU、USB 在 **资源配置** 下拉中，性能调优、调度策略、登录与固件在 **…** 更多菜单中。

**同步与生效（通用，注意）**：

- 提交变更后，顶栏状态先显示 **变更同步中**，写入完成后变为 **配置已同步**；可单击抽屉 **刷新** 确认。
- 部分配置（如部分热扩容）可在线生效；部分配置（CPU 绑定、NUMA、大页、固件等）须 **重启** 或 **关机再启动** 后生效，页面会提示。
- 同步长期不变时，先 **刷新**，再查看云主机事件，必要时重启（参见 **6 常见问题**）。

---

#### 7.5.1 调整规格

**入口**：`详情抽屉 > 资源配置 > 调整规格`

1. 打开云主机 **详情抽屉**。
2. 在工具栏 **资源配置** 下拉中选择 **调整规格**。
3. 修改 vCPU 或内存。
4. 单击 **确定** 提交，等待顶栏变为 **配置已同步**。

![调整规格子抽屉](assets/ch03-vm-detail/vm-detail-spec-config.png)

**操作效果**：

- 云主机规格更新为新的 vCPU/内存。
- 已开启热扩容且当前状态支持在线变更时，部分调整可在线完成；否则提示待重启。
- 调整超出热扩容上限时会被阻止，须先调整热扩容上限。

---

#### 7.5.2 性能调优

**入口**：`详情抽屉 > … > 性能调优`

1. 打开云主机 **详情抽屉**，在 **…** 更多菜单中选择 **性能调优**。
2. 选择 **性能设置**：修改 CPU 拓扑、CPU 绑定、CPU/内存 QoS、NUMA 模式或大页内存。
3. 选择 **热扩容设置**：开启热扩容并设置 CPU、内存的扩容上限。
4. 单击 **确定** 提交，等待 **配置已同步**。

**操作效果**：

- 修改写入云主机规格；CPU 绑定、NUMA、大页等通常须重启后生效。
- 首次启用热扩容后，云主机可能需重启才具备在线扩容能力；之后 **调整规格** 只能在热扩容上限内调整。
- 热扩容与 NUMA、大页互斥；热扩容进行中会阻止再次修改规格。

**注意**：热扩容不可用常见原因包括磁盘非共享存储、挂载了阻止迁移的设备等；悬停状态标签可查看具体提示。宿主机 NUMA 拓扑可在 `集群 > 计算配置 > 计算节点 > 节点详情` 中核对（参见 **6 集群**）。

---

#### 7.5.3 磁盘管理

**入口**：`详情抽屉 > 资源配置 > 磁盘管理`

![磁盘管理子抽屉](assets/ch03-vm-detail/vm-detail-disk-manage.png)

| 操作            | 说明                                                 |
| --------------- | ---------------------------------------------------- |
| **挂载 / 卸载** | 添加数据盘，或卸载非系统盘                           |
| **扩容**        | 修改卷容量（StorageClass 须支持扩容）                |
| **更换系统盘**  | 通过 **更换系统盘** 操作切换系统盘（高风险，有确认） |
| **引导顺序**    | 上移/下移调整磁盘启动优先级                          |
| **弹出 CD-ROM** | ISO 引导且光驱占用时，从 **…** 菜单弹出              |

**操作效果**：写操作成功后单击抽屉 **刷新** 或关闭重开可见 **配置已同步**。云盘、快照管理参见 **11 云存储**。

---

#### 7.5.4 网卡管理

**入口**：`详情抽屉 > 资源配置 > 网卡管理`

1. 打开 **网卡管理**。
2. **添加 / 删除 / 修改** 网卡，可调整模型（virtio/e1000 等）与 MAC。
3. 保存后等待 **配置已同步**。

**操作效果**：部分网卡变更须重启或关机后生效。子网、EIP、安全组等配置参见 **13 扁平网络**、**14 VPC 网络**。

---

#### 7.5.5 GPU 与直通设备

**入口**：`详情抽屉 > 资源配置 > GPU管理`

1. 打开 **GPU管理**，挂载或更换 GPU 设备。
2. 保存后视设备类型可能须 **关机再启动** 生效。

**操作效果**：直通 GPU 绑定物理节点，热迁移受限。PCI 与 SR-IOV 网卡直通通过 **网卡管理** 配置（参见 **7.5.4**）。集群级 GPU/PCI/USB 纳管视图在 `集群 > 计算资源` 查看（参见 **6 集群**）。

**注意**：直通设备与运行节点绑定；更改 **指定主机** 前须先卸载相关设备。

---

#### 7.5.6 USB 设备

**入口**：`详情抽屉 > 资源配置 > USB管理`

1. 打开 **USB管理**，从已纳管且启用的设备中挂载 USB。
2. 不再需要时卸载。

**操作效果**：USB 设备与所在节点绑定；多块 USB 须与 GPU、PCI 直通设备位于同一节点。

---

#### 7.5.7 调度策略与高可用

**入口**：`详情抽屉 > … > 调度策略`

![节点选择器改配](assets/ch03-vm-detail/vm-detail-node-scheduling.png)

| 子项               | 说明                                       |
| ------------------ | ------------------------------------------ |
| **节点选择器**     | 自动调度 / 固定主机 / 故障域               |
| **节点亲和性**     | 基于节点标签的调度偏好                     |
| **虚拟机间亲和性** | 多台云主机同宿或分散策略                   |
| **高可用设置**     | 运行策略与驱逐策略（节点维护时是否热迁移） |

**操作步骤**：

1. 打开 **详情抽屉**，在 **…** 菜单选择 **调度策略**。
2. 选择对应子项并配置，单击 **确定** 提交。

**操作效果**：节点选择器限制可运行的宿主机范围；亲和性影响调度优先级与多机分布；高可用设置影响节点故障/维护时的恢复行为。已创建云主机修改调度策略后，可能需迁移或重启才体现最终运行位置。

---

#### 7.5.8 登录凭据与 CloudInit

**入口**：`详情抽屉 > … > CloudInit 管理`

1. 打开 **CloudInit 管理**。
2. 编辑 **userData / networkData**。
3. **保存** 后按提示重启生效。

**操作效果**：与创建向导 **登录与凭据**、**高级设置** 中的 Cloud-Init 字段联动同一定义。SSH 密钥维护参见 **7.7.4**。

---

#### 7.5.9 固件设置

EFI、安全启动、TPM 等若在创建时已设定，变更须通过 **查看 YAML** 或后续版本提供的入口（以界面为准），且变更后通常须 **关机再启动** 生效。新建云主机时配置固件参见 **7.2.7**。

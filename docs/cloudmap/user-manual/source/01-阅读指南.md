# 1. 阅读指南

## 1.1 手册用途

本手册说明如何在 **Compute Tower** 管控台中完成 Cloudmap 超融合资源池的日常操作。若需了解产品定位、架构与能力边界，请阅读 **《Cloudmap 超融合平台技术白皮书》**（`docs/cloudmap/whitepaper/source/`）。

| 文档           | 回答的问题                         |
| -------------- | ---------------------------------- |
| 技术白皮书     | 平台能做什么、架构如何、价值是什么 |
| **本使用手册** | 菜单在哪里、逐步怎么点、有哪些限制 |

## 1.2 适用读者

| 角色           | 典型任务                                              |
| -------------- | ----------------------------------------------------- |
| **平台管理员** | 接入资源池、集群与网络配置、系统用户与 RBAC、全局监控 |
| **运维工程师** | 云主机与云盘、备份恢复、告警处理、迁移与改配          |
| **租户管理员** | 本租户项目内创建云主机、分配网络与存储                |
| **租户用户**   | 在已授权项目内使用云主机（视 RBAC 而定）              |

## 1.3 名词与约定

| 名词                | 含义                                                                   |
| ------------------- | ---------------------------------------------------------------------- |
| **Compute Tower**   | 统一管控 Web 平台（本控制台）                                          |
| **Cloudmap 资源池** | 在「多云管理」中接入的 Harvester / KubeVirt 类型云实例                 |
| **项目**            | 对应 Kubernetes **命名空间**；创建云主机时必须选择                     |
| **云主机 / 虚拟机** | 池内侧栏 **云主机** 分组下的 **云主机实例**                            |
| **刷新**            | 列表工具栏 **Reload** 图标；会从集群拉取最新状态，非浏览器 F5          |
| **写权限**          | 无对应 `:write` 时，**创建 / 删除 / 改配** 等按钮 **不显示**（非置灰） |

## 1.4 操作说明体例

正文各节按以下结构编写（部分小节合并展示）：

- **适用角色**：谁可以操作
- **入口**：`顶栏平台 > 侧栏 > Tab` 路径
- **前置条件**：须先完成的配置
- **步骤**：编号操作
- **结果**：成功后的界面表现
- **注意**：互斥、重启、权限等
- **参见**：白皮书章节号

## 1.5 范围说明

本手册 **第 3 章** 以 **Cloudmap 资源池** 侧栏 Tab 为范围（云主机、集群、网络、统一存储、云监控等）。**不含** SDNCC、CNSOC、华为/阿里等非 Cloudmap 池产品线；系统设置与租户管理见第 4、5 章。

## 1.6 版本说明

手册与白皮书源稿均在 `docs/cloudmap/` 维护。当前部署版本可在 **系统设置 > 离线升级** 查看 **当前软件版本**（来自后端 `package.json`）。

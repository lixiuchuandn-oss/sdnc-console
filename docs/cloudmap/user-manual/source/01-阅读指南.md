# 1. 阅读指南

## 1.1 用途

本手册说明如何在 **Compute Tower** 管控台中完成 Cloudmap 资源池的日常操作，包括登录、进入资源池、查看资源、创建云主机、维护网络、管理存储、配置备份和排查常见问题。

本手册重点回答三个问题：

1. 菜单在哪里。
2. 操作怎么做。
3. 操作完成后界面会出现什么效果。

## 1.2 读者

| 角色           | 典型任务                                              |
| -------------- | ----------------------------------------------------- |
| **平台管理员** | 接入资源池、集群与网络配置、系统用户与 RBAC、全局监控 |
| **运维工程师** | 云主机与云盘、备份恢复、告警处理、迁移与改配          |
| **租户管理员** | 本租户项目内创建云主机、分配网络与存储                |
| **租户用户**   | 在已授权项目内使用云主机（视 RBAC 而定）              |

## 1.3 文档体例

| 名词                | 含义                                                          |
| ------------------- | ------------------------------------------------------------- |
| **Compute Tower**   | 统一管控 Web 平台（本控制台）                                 |
| **Cloudmap 资源池** | 在「多云管理」中接入的 Harvester / KubeVirt 类型云实例        |
| **项目**            | 对应 Kubernetes **命名空间**；创建云主机时必须选择            |
| **云主机 / 虚拟机** | 池内侧栏 **云主机** 分组下的 **云主机实例**                   |
| **刷新**            | 列表工具栏 **刷新** 按钮；会从集群拉取最新状态，而非浏览器 F5 |
| **写权限**          | 控制创建、删除、改配等变更操作；原子清单见 **第 4 章**        |

正文各节按以下结构编写（部分小节合并展示）：

- **适用角色**：谁可以操作
- **入口**：`顶栏平台 > 侧栏 > Tab` 路径
- **前置条件**：须先完成的配置
- **步骤**：编号操作
- **操作效果**：成功后的界面表现
- **注意**：互斥、重启等业务约束；权限原子见 **第 4 章**，不写权限通则

## 1.4 本手册范围

本手册 **第 3 章** 以 **Cloudmap 资源池** 侧栏功能为范围（资源总览、云监控、集群、云主机、云数据库、虚拟网元、容器服务、云存储、云备份、扁平网络、VPC 网络、日志管理）。**不含** SDNCC、CNSOC、华为/阿里等非 Cloudmap 池产品线；系统设置与租户管理见第 4、5 章。

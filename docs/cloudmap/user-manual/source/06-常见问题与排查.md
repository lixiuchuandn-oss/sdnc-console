# 6. 常见问题

遇到问题时，建议先按通用方法定位，再对照下面的分类速查与典型报错处置。

**通用排障方法**：

1. **先刷新、勿只按 F5**：用页面工具栏的 **刷新**（会从对端重新拉取），而非浏览器刷新。
2. **看状态与提示**：列表状态标签、详情顶栏状态、操作后的提示信息往往已说明原因。
3. **看事件 / 运行诊断**：云主机问题进详情 **诊断工具 > 运行诊断**（见 7.3.6）；其它资源查看其事件或 YAML。
4. **核对权限与授权**：看不到菜单/按钮多为权限或授权未开通（见第 4 章、1.6）。
5. **核对对端与依赖**：资源池是否在线、网络是否可达、依赖资源（公共子网、备份目标、镜像、IP 池等）是否就绪。

---

## 6.1 登录权限

| 现象                  | 可能原因                    | 处理步骤                          |
| --------------------- | --------------------------- | --------------------------------- |
| 无法登录              | 密码错误、账号禁用          | 管理员 **用户管理** 重置密码/启用 |
| 看不见 **资源池管理** | 角色未授权多云管理          | 见 **第 4 章** 配置角色与功能授权 |
| 池内 Tab 缺失         | 角色或 License 未包含该模块 | 见 **第 4 章**、**授权管理**      |
| 租户无 **项目**       | 未分配命名空间              | **租户管理** 分配项目             |

---

## 6.2 云主机创建

| 现象             | 可能原因                        | 处理                                         |
| ---------------- | ------------------------------- | -------------------------------------------- |
| 长期 **Pending** | 资源不足、GPU/主机/故障域不匹配 | 查节点资源；改 **运行位置**；看 **运行诊断** |
| 指定主机失败     | GPU 不在该节点                  | 换节点或换 GPU（7.2.3、7.5.5）               |
| NUMA 无法保存    | 未绑核、热扩容冲突、整除约束    | 见 7.2.3 校验说明                            |
| 大页启动失败     | 节点 hugepages 不足             | **计算节点** 查容量；改 2Mi 或关大页         |
| 故障域无法下一步 | 未选域且未填标签                | 7.2.2                                        |

---

## 6.3 改配同步

| 现象                         | 处理                                                 |
| ---------------------------- | ---------------------------------------------------- |
| 顶栏 **变更同步中** 长期不变 | 抽屉 **刷新**；查 VM 事件；必要时重启 VM             |
| **热扩容待重启**             | 按 Tag 提示 **重启** 后再扩                          |
| **热扩容不可用**             | 悬停 Tag；检查磁盘是否 **RWX**、是否挂载阻止迁移设备 |
| 大页/NUMA 改后不生效         | **重启 VM**                                          |

---

## 6.4 列表缓存

1. 先点工具栏 **刷新**，勿只按 F5。
2. 增删改成功后列表应 **自动更新**；若未更新再 **刷新**。
3. 仍陈旧：检查浏览器是否离线、API 代理是否正常。

---

## 6.5 网络存储

| 现象             | 处理                                          |
| ---------------- | --------------------------------------------- |
| VM 无网          | **网卡管理** 查子网/EIP；安全组/NACL          |
| EIP 不通         | **SNAT/DNAT** 规则；公网子网                  |
| 云盘 **Pending** | StorageClass、Provisioner；**存储概览**       |
| 备份失败         | 检查 **备份目标** 配置；云主机是否 **运行中** |

---

## 6.6 远程访问

| 现象                | 处理                                             |
| ------------------- | ------------------------------------------------ |
| **打开终端** 不可用 | VM 须 **运行中**；见 **第 4 章** 控制台权限      |
| 云桌面连不上        | **云桌面网关** 测试；用户 **分配**；VM 网络/端口 |

---

## 6.7 云主机镜像

| 现象                                              | 可能原因            | 处理                                                   |
| ------------------------------------------------- | ------------------- | ------------------------------------------------------ |
| 同步报 **镜像文件过小**（约 1 MiB）               | 测试用小 ISO/空文件 | 使用 ≥1 MiB 的镜像；见 **7.7.1**                       |
| 列表 **待同步**，点同步失败 **DataVolume 已存在** | 集群残留上次导入    | 在集群清理同名 DataVolume/镜像，或换 **镜像名称** 重传 |
| 抽屉提示完成但列表无行                            | 未刷新、筛选未清空  | 点列表 **刷新**；清空名称筛选                          |
| **待同步** 时无法删上传任务                       | 产品设计            | 在 **镜像列表** 删镜像数据，见 **7.7.1**               |
| 浏览器上传中断                                    | 网络/代理超时       | 用 **上传任务** 抽屉续传；大文件用 **ImageUploader**   |

## 6.9 典型报错与处置

| 现象                               | 可能根因                                         | 处置                                                                 |
| ---------------------------------- | ------------------------------------------------ | -------------------------------------------------------------------- |
| 看不到 **可用区** 或资源池列表为空 | 未分配资源池 / 资源池未接入 / 无读权限           | 确认账号已被分配该池（第 5 章）；接入在多云管理；核对权限（第 4 章） |
| 进入资源池后页面 **空白或转圈**    | 资源池离线 / 网络不可达                          | 在多云管理查资源池状态；核对平台到集群网络连通                       |
| 创建云主机长期 **Pending**         | 资源不足 / GPU·主机·故障域不匹配                 | 看 **运行诊断**；改运行位置；核对节点余量（见 7.3.6、6.1.1）         |
| 镜像 **暂无可选**                  | 未上传或未同步至就绪                             | 上传并同步镜像（见 7.7.1）                                           |
| 网络步 **无可用子网**              | 扁平/VPC 子网未就绪或未创建                      | 创建并确认子网就绪（见 13.1 / 14.2）                                 |
| 外部 **访问不到** 云主机服务       | 缺 DNAT / 安全组未放行 / 云主机未运行            | 配 DNAT（13.5 / 14.5）；放行安全组（13.2）；确认运行中               |
| 云主机 **无法出公网**              | 缺 SNAT / EIP 未就绪                             | 配 SNAT（13.4 / 14.4）；确认 EIP 就绪、公共子网正常                  |
| 改配后顶栏长期 **变更同步中**      | 同步未完成 / 需重启                              | 抽屉 **刷新**；查事件；必要时重启云主机（见 7.5）                    |
| **热扩容不可用**                   | 磁盘非共享 / 挂了阻止迁移的设备                  | 悬停状态标签看原因；调整磁盘或设备（见 7.5.2）                       |
| **热迁移失败**                     | 挂了直通设备 / 存储不支持 / 目标节点不符         | 卸载直通设备或换目标节点（见 7.4.3）                                 |
| 备份/恢复 **失败**                 | 备份目标未配置 / 云主机状态不符 / 已有进行中任务 | 核对备份目标；等待在进行中任务完成（见 12.5）                        |
| 云盘 **Pending**                   | StorageClass/Provisioner 异常                    | 查存储概览与 StorageClass（见 6.3.1、6.3.5）                         |
| 日志 **查不到**                    | 采集对象/采集配置/接收端缺一                     | 三者齐备并测试接收端连通（见 15.1–15.3）                             |
| 监控 **指标缺失**                  | 采集任务异常                                     | 在接入管理查采集任务与目标状态（见 5.3）                             |

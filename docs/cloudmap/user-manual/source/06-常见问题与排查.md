# 五、常见问题与排查

---

## 1. 登录与权限

| 现象                  | 可能原因                    | 处理步骤                          |
| --------------------- | --------------------------- | --------------------------------- |
| 无法登录              | 密码错误、账号禁用          | 管理员 **用户管理** 重置密码/启用 |
| 看不见 **资源池管理** | 角色未授权多云管理          | 见 **第 4 章** 配置角色与功能授权 |
| 池内 Tab 缺失         | 角色或 License 未包含该模块 | 见 **第 4 章**、**授权管理**      |
| 租户无 **项目**       | 未分配命名空间              | **租户管理** 分配项目             |

---

## 2. 云主机创建与调度

| 现象             | 可能原因                        | 处理                                         |
| ---------------- | ------------------------------- | -------------------------------------------- |
| 长期 **Pending** | 资源不足、GPU/主机/故障域不匹配 | 查节点资源；改 **运行位置**；看 **运行诊断** |
| 指定主机失败     | GPU 不在该节点                  | 换节点或换 GPU（**7.7**）                    |
| NUMA 无法保存    | 未绑核、热扩容冲突、整除约束    | 见 **7.4** 校验说明                          |
| 大页启动失败     | 节点 hugepages 不足             | **计算节点** 查容量；改 2Mi 或关大页         |
| 故障域无法下一步 | 未选域且未填标签                | 见 **7.3**                                   |

---

## 3. 改配与同步

| 现象                         | 处理                                                 |
| ---------------------------- | ---------------------------------------------------- |
| 顶栏 **变更同步中** 长期不变 | 抽屉 **Reload**；查 VM 事件；必要时重启 VM           |
| **热扩容待重启**             | 按 Tag 提示 **重启** 后再扩                          |
| **热扩容不可用**             | 悬停 Tag；检查磁盘是否 **RWX**、是否挂载阻止迁移设备 |
| 大页/NUMA 改后不生效         | **重启 VM**                                          |

---

## 4. 列表与缓存

1. 先点工具栏 **Reload**，勿只 F5。
2. 增删改成功后列表应 **自动更新**；若未更新再 Reload。
3. 仍陈旧：检查浏览器是否离线、API 代理是否正常。

---

## 5. 网络与存储

| 现象             | 处理                                    |
| ---------------- | --------------------------------------- |
| VM 无网          | **网卡管理** 查子网/EIP；安全组/NACL    |
| EIP 不通         | **SNAT/DNAT** 规则；公网子网            |
| 云盘 **Pending** | StorageClass、Provisioner；**存储概览** |
| 备份失败         | **BackupTarget**；VM 是否 Running       |

---

## 6. 远程访问

| 现象                | 处理                                             |
| ------------------- | ------------------------------------------------ |
| **打开终端** 不可用 | VM 须 **运行中**；见 **第 4 章** 控制台权限      |
| 云桌面连不上        | **云桌面网关** 测试；用户 **分配**；VM 网络/端口 |

---

## 7. 云主机镜像上传与同步

| 现象                                              | 可能原因              | 处理                                                   |
| ------------------------------------------------- | --------------------- | ------------------------------------------------------ |
| 同步报 **镜像文件过小**（约 1 MiB）               | 测试用小 ISO/空文件   | 使用 ≥1 MiB 的镜像；见 **7.9**                         |
| 列表 **待同步**，点同步失败 **DataVolume 已存在** | 集群残留上次导入      | 在集群清理同名 DataVolume/镜像，或换 **镜像名称** 重传 |
| 抽屉提示完成但列表无行                            | 未 Reload、筛选未清空 | 点列表 **Reload**；清空名称筛选                        |
| **待同步** 时无法删上传任务                       | 产品设计              | 在 **镜像列表** 删镜像数据，见 **7.9**                 |
| 浏览器上传中断                                    | 网络/代理超时         | 用 **上传任务** 抽屉续传；大文件用 **ImageUploader**   |

---

## 8. 获取版本与支持

1. **当前版本**：`系统设置 > 离线升级`。
2. **能力是否支持**：查 **技术白皮书** 对应节与本手册第 3 章。
3. **缺陷/需求**：项目支持渠道（白皮书第 11 章）。

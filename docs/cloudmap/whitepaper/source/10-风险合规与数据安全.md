# 10. 风险、合规与数据安全

本章归纳平台在私有化部署中的**数据驻留、分权合规、分布式与边缘运行风险**及应对要点。具体安全能力与网元类型见 **第 4 章**；备份与 RPO/RTO 见 **3.9**、**3.16**；审计日志见 **4.3**；相关术语见 **第 8 章**。

## 10.1 数据驻留与访问控制

**实现**：业务与备份数据默认保存在客户机房或指定托管机房，不经平台默认外传。  
**能力**：多租户与 VPC 隔离（**3.4.3**、**4.4**）；边缘推理与模型数据本地存储（**3.11.5**）。  
**价值**：满足政务、金融、制造等对数据不出域、不出园区的要求。

租户间资源与网络策略隔离；管理员操作经 RBAC 约束，关键环境可采用三权分立模式（**2.1**、**4.4**）。

## 10.2 等级保护与国密

**实现**：按需部署等保相关安全网元与检查服务；支持国密算法链路与国密/商密流量检测模式。  
**能力**：安全资源池与流量编排（**4.1**、**4.2**）；国密与商密改造（**4.5**）。  
**价值**：安全能力随业务弹性扩容，测评项可在平台内对照部署。

等保模块与第三方网元为**选配**；具体达标等级取决于部署架构与管理制度，需结合测评机构要求实施。

## 10.3 分布式与边缘运行风险

| 风险类型     | 说明                     | 平台应对（引用）                                                |
| ------------ | ------------------------ | --------------------------------------------------------------- |
| 中心链路中断 | 边缘或区域与中心网络断开 | 区域节点自治运维（**3.15**）；本地业务与推理继续运行            |
| 节点硬件故障 | 磁盘、主机宕机           | 存储多副本、VM HA（**3.16**）；推理 Worker 多节点（**3.11.1**） |
| 策略不一致   | 多站点配置漂移           | 中心策略与模型目录下发（**3.15**、**3.11.5**）                  |
| 备份缺失     | 误删或勒索               | 定时备份与异地归档（**3.9**、**3.16**）                         |

边缘站点物理安全（机柜、访问控制）需客户机房制度配合；平台提供操作审计与告警，不替代物理安防。

## 10.4 审计与事件响应

**实现**：查询谁在何时对何种资源执行了何种操作；安全告警集中展示与处置。  
**能力**：全域操作日志（**4.3**）；安全态势与事件聚合（**4.3**）。  
**价值**：满足内部审计与等保对日志留存、追溯的要求。

建议客户制定告警分级与响应流程；平台提供多渠道通知（**3.14**），项目侧响应机制见 **6.2.1**。

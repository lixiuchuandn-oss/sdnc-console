### 3.3.2 全闪存储加速引擎

面向高性能数据库、核心交易、AI 推理等高 I/O 场景，自研**用户态、内核旁路、零拷贝**全闪加速引擎，充分释放闪存性能，保障低时延、高吞吐。

- **用户态 I/O 架构**：热路径下沉至用户空间，通过内核旁路、轮询模式替代传统中断，大幅降低上下文切换开销；
- **零拷贝+无锁队列**：数据通路绕过内核缓冲区，配合无锁异步 I/O，显著提升小块随机读写并发能力；
- **卷级资源隔离**：微服务化引擎按卷隔离资源，多卷并发时仍保持稳定吞吐与可预期时延；
- **介质分层适配**：NVMe/SSD 走全闪加速路径，HDD 纳入容量层构建闪混池，兼顾性能与成本。

## 3.3 统一存储服务

Cloudmap 构建分布式统一存储，将块、对象、文件三类服务融合在同一存储池，面向虚拟机、容器、数据库、AI 推理与备份归档等负载统一供给。技术要点包括按介质分级的全闪快池/闪混池/容量慢池（**3.1.2**）、用户态内核旁路零拷贝的全闪加速引擎（**3.3.2**）、写时复制快照链与快速克隆（**3.3.4**）、多副本与纠删码冗余及多级 QoS（**3.3.5**）、跨集群异步块复制与可选 RDMA 加速（**3.3.7**）。

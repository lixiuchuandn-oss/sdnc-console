## 3.14 统一运维可观测能力

Cloudmap 打通基础设施、虚拟化、容器、网络、安全、智算等各层监控数据，提供一屏总览、全链路监控、智能巡检预警与集中运维，降低多系统运维复杂度、提升故障定位效率。

- **全局资源大盘**：集群、节点、资源池、负载实时可视化，健康度、利用率一目了然；
- **全链路监控**：覆盖计算、存储、网络、安全、数据库、AI 推理等多维度指标；
- **运维监控大盘视图（已交付）**：Cloudmap 资源池 **监控** 提供 **节点概览**（物理主机 CPU/内存利用率与状态分布）、**云主机资源**及云主机详情指标面板，对齐 Grafana 既有仪表盘口径，便于池内一站式查看；
- **智能巡检预警**：内置专家规则，自动巡检、风险识别、多渠道告警；
- **日志审计统一**：全栈日志集中汇总、检索、分析，满足合规追溯；
- **数字孪生视图**：机房、网络、资源拓扑可视化，直观掌握全域运行态势；
- **运维操作闭环**：告警、定位、处理、复盘一体化，提升运维效率。

运维交付与服务保障见 **第 6 章**；推理域监控见 **3.11.4**，存储域见 **3.3.8**。算网大脑见 **3.15**；高可用见 **3.16**。

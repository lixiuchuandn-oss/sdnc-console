### 3.1.2 统一存储架构

Cloudmap 构建**分布式统一存储池**，打破本地盘、SSD、NVMe、HDD 的介质壁垒，将各节点磁盘资源聚合为统一资源池，由统一控制面集中管理调度，实现**资源池化、性能分级、服务统一**。

![Cloudmap 统一存储架构](assets/unified-storage-arch.png)

**图 3-2 Cloudmap 统一存储架构**

- **分级存储池**：按介质类型划分为**全闪快池、闪混池、容量慢池**，灵活适配高性能、均衡、大容量归档等不同业务需求，支持 NVMe/SSD/HDD 混合组合，平衡性能与成本。
- **统一服务输出**：同一存储池向上提供**块存储、对象存储、文件存储**三类核心服务，分别支撑虚拟云盘、容器持久化卷、数据库、备份归档、非结构化数据等场景，实现一套存储承载多元业务。
- **云原生深度集成**：存储能力原生对接虚拟机、容器、云数据库、云备份、AI 推理等上层负载，支持在线扩容、快照克隆、数据保护，实现存储与业务的无缝协同。

部署配置、数据面加速、QoS 与运维等交付能力见 **3.3**。

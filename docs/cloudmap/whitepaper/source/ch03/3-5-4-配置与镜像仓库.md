### 3.5.4 配置与镜像仓库

集中管理配置、密钥与镜像资源，保障**安全、合规、可复用**。

- **配置中心（ConfigMap）**：键值/文件形式统一管理应用配置，支持动态更新、批量关联；
- **密钥管理（Secret）**：安全存储密码、证书、镜像密钥，支持细粒度权限控制；
- **镜像仓库集成**：无缝对接 Harbor 等兼容仓库，支持镜像浏览、拉取、同步、权限管理；
- **本地仓库平台部署（已交付）**：支持在资源池内**向导部署本地镜像仓库**并纳管为平台仓库，与通用 Harbor/Registry 并列展示；租户 RBAC 可单独授予镜像写权限（见 **4.4**）；
- **命名空间隔离**：配置、密钥、镜像按命名空间隔离，适配多租户、多项目场景；
- **安全合规**：镜像拉取权限管控、密钥加密存储，降低泄露风险。

选配场景下可通过服务目录开通命名空间配额，并支持 Helm Chart / Operator 模板一键部署（与 **3.5.1** 工作负载衔接）。

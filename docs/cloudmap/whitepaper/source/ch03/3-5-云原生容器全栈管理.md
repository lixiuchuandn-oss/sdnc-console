## 3.5 云原生容器全栈管理

Cloudmap 深度集成 Kubernetes，与虚拟化、裸金属、网络、存储、安全能力同平台融合，覆盖容器应用从部署、运维到治理的全过程。涵盖多类型工作负载与精细化调度（**3.5.1**）、Pod 与任务运维（**3.5.2**）、服务发现与流量治理（**3.5.3**）、配置与镜像仓库（**3.5.4**）、网络策略与中断保护（**3.5.5**），并复用计算层调度机制（**3.2.1**）。

### 3.5.3 服务发现与流量治理

构建**内通外达、高可用、可观测**流量体系，支撑服务访问、对外发布与精细化治理。

- **多类型 Service**：支持 ClusterIP、NodePort 等，实现集群内服务发现与负载均衡；
- **Ingress 统一入口**：集中管理 HTTP/HTTPS 路由、域名、TLS 证书，统一对外发布；
- **新一代 Gateway API（已交付）**：支持 Gateway、HTTPRoute、GRPCRoute 等资源的列表、创建/编辑与 YAML 查看；安装与状态展示、路由规则表单与详情抽屉已对齐 Cloudmap 工具栏与 RBAC 规范（只读场景隐藏写入口）；
- **可视化拓扑**：自动生成服务调用链路拓扑，直观展示依赖关系，便于故障排查；
- **流量健康保障**：内置健康检查、故障实例自动摘除，提升服务可用性。

南北向边界能力见 **3.4.5**。

## 3.4 网络服务

Cloudmap 构建**软件定义、多层隔离、弹性灵活、全域互通**的企业级网络体系，在统一底层物理网络之上，叠加多类逻辑网络平面，覆盖租户业务、集群内部、跨站点互联等全场景流量，实现**网络即服务、策略可视化、运维一体化**，支撑虚拟机、容器、裸金属、云桌面等多元负载安全高效通信。

![Cloudmap 网络服务架构](assets/network-service-arch.png)

**图 3-9 Cloudmap 网络服务架构**

集群内部 **管理网、存储网、迁移网** 与租户 **业务网** 分网规划（详见 **3.1.3**）。以下各节说明公共子网、扁平子网、VPC、直通网络、边界服务、安全组、物理网络编排、安全流量编排与跨域互联能力。

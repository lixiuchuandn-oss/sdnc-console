## 3.4 网络服务

Cloudmap 提供软件定义网络能力，在统一物理网络之上叠加多类逻辑网络平面，覆盖租户业务、集群内部与跨站点互联流量，为虚拟机、容器、裸金属、云桌面提供网络隔离与互通。涵盖公共子网与扁平子网、VPC、负载均衡与 NAT/EIP 边界服务、安全组、SR-IOV/PCIe 直通网络（**3.4.4**）、物理网络编排、安全流量编排（**3.4.8**）与 SD-WAN 跨域互联（**3.4.9**）。

![Cloudmap 网络服务架构](assets/network-service-arch.png)

**图 3-9 Cloudmap 网络服务架构**

集群内部 **管理网、存储网、迁移网** 与租户 **业务网** 分网规划（详见 **3.1.3**）。以下各节说明公共子网、扁平子网、VPC、直通网络、边界服务、安全组、物理网络编排、安全流量编排与跨域互联能力。

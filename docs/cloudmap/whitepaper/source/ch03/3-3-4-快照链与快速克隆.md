### 3.3.4 快照链与快速克隆

基于**写时复制（COW）**技术构建分层快照链，兼顾空间效率、数据一致性与快速恢复能力。

![快照链与写时复制](assets/snapshot-chain.png)

**图 3-8 快照链与写时复制**

- **分层快照链**：快照链式叠加，仅记录增量数据，创建速度快、对在线业务 I/O 影响极小；
- **云盘/整机快照**：支持云盘快照、虚拟机整机一致性快照，分别适配卷级回滚与整机恢复场景；
- **快速克隆**：从快照秒级生成新云盘/虚拟机，克隆体与源共享未变更数据，节省存储空间；
- **灵活恢复**：支持快照回滚、基于快照创建新资源，适配误删、数据损坏、版本回退等场景。

云主机备份与定时策略见 **3.9**。

## 3. 客户资源池 · 定制开发费

| 方案 | 虚拟化底座 | 定制开发总人天 | 金额 |
|------|------------|----------------|------|
| **A（推荐）** | Harvester / KubeVirt（Cloudmap 池） | **30** | |
| **B** | VMware vSphere | **220** | |
| 选配 · 短信告警 | 不限底座 | **10** | |

**方案 B（220 人天）**：含方案 A 实施项 + VMware Provider 对接、VM 全生命周期与高级运维、物理主机/资源池视图、监控告警对接。

| 序号 | 定制项 | 方案 A | 方案 B |
|------|--------|--------|--------|

| 2 | 租户 / RBAC 现场配置与验收 | 含 | 含 |
| 3 | 虚拟化 Provider 对接 | 无需 | 含 |
| 4 | VM 全生命周期 API + 前端工作台 | 无需 | 含 |
| 5 | VM 高级运维（暂停/迁移/快照/模板） | 无需 | 含 |
| 6 | 物理主机纳管与资源池聚合视图 | 无需 | 含 |
| 7 | 监控指标与阈值告警对接 | 无需 | 含 |
| 8 | 邮件告警通道现场联调 | 含 | 含 |
| 9 | 短信告警（对接客户网关） | 选配 | 选配 |
| 10 | 部署联调、培训、验收 | 含 | 含 |

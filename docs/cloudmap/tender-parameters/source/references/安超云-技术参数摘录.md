## 一、计算服务

| 序号 | 参数项 | 技术要求 | 备注 |
|------|--------|----------|------|
| 1 | 虚拟机生命周期 | 创建、远程操作、开机、关机、重启、强制重启、修改密码、删除、关闭电源、暂停、挂起、恢复、锁定、解锁、导出等 | |
| 2 | 创建虚拟机 | 支持通过 ISO 全新创建虚拟机；支持通过镜像、模板批量创建虚拟机；支持通过 Excel 模板批量导入虚拟机 | |
| 3 | 创建策略 | 创建虚拟机时配置放置策略；选项：系统调配、指定节点、亲和组 | |
| 4 | NFS 导入/导出 | 通过 NFS 网络路径批量导入/导出虚拟机 | |
| 5 | 镜像管理 | 管理虚拟机镜像与 ISO；支持上传、导出、禁用、同步，或从虚拟机制作镜像；WStor 存储上可从镜像制作镜像；远程上传支持进度查看及暂停、恢复、取消；（SAN 或本地）Qcow2 镜像将自动读取磁盘扇区大小 | |
| 6 | 虚拟机模板 | 模板包含规格配置、系统盘与数据盘（可选）；支持从虚拟机创建模板、从模板批量部署、从模板克隆模板或将模板转换为虚拟机；创建与克隆时均可自定义修改配置 | |
| 7 | 关机释放资源 | 虚拟机关机后可选择释放 CPU、内存资源；已释放资源的虚拟机支持恢复资源 | |
| 8 | 磁盘加密 | ▲ 支持针对系统盘或数据盘加密；加密算法可选 AES 256 或 SM4 | 磁盘加密不可取消；加密虚拟机在功能与性能上有限制（详见用户手册） |
| 9 | vTPM | ▲ 支持为 Windows 11 虚拟机配置 vTPM | 引导方式须为 UEFI；配置 vTPM 的虚拟机有功能限制 |
| 10 | NUMA | 配置虚拟机 NUMA 以提升内存访问性能；支持自动或手动分配 NUMA 拓扑；支持配置 NUMA 内存分配策略 | 开启 NUMA 时，插槽数须为 NUMA 节点数的整数倍 |
| 11 | CPU QoS | 支持 CPU 上限、CPU 份额设置 | |
| 12 | CPU 指令集 | 配置选项：系统默认、主机模式、主机直通 | ARM 仅支持主机直通 |
| 13 | 内存独占 | 启用后，虚拟机立即分配内存资源 | |
| 14 | 大页内存 | 支持配置 2M 大页内存 | |
| 15 | 内存回收 | 支持以集群维度配置内存回收开关；集群与虚拟机均开启后，对闲置内存回收并释放给有需求的虚拟机 | |
| 16 | 虚拟机保护 | 物理节点内存降低时，开启内存保护的虚拟机不会被停用 | |
| 17 | BIOS 设置 | 支持 UEFI、Legacy | |
| 18 | 更改计算配置 | 支持修改 CPU、插槽数、内存、NUMA、内存回收等；开机状态可修改 CPU/内存/NUMA，重启后生效 | |
| 19 | 快照管理 | 创建、编辑、回滚、删除快照；支持基于快照创建虚拟机；支持定时快照（最小周期 15 分钟）；▲ 快照回滚效率优化至 1 分钟内 | |
| 20 | 重装操作系统 | 通过更换镜像文件更换虚拟机操作系统 | |
| 21 | 更新 VM-Tools | 支持针对已安装 VM-Tools 的虚拟机批量更新版本；更新不更改虚拟机网络配置 | |
| 22 | 更改启动顺序 | 支持配置启动顺序（硬盘优先或光驱优先） | |
| 23 | VNC 访问 | 支持配置 VNC 密码；VNC 界面可展示集群、虚拟机、主机名、IP 地址及运行状态 | |
| 24 | 虚拟机克隆 | 支持链接克隆、完整克隆；▲ 链接克隆兼具完整克隆独立性与链接克隆高效性；克隆前后虚拟机支持无网卡场景 | |
| 25 | 迁移虚拟机 | 支持开/关机状态下跨节点迁移（含挂载 USB 的虚拟机）；迁移模式：应用性能优先、迁移性能优先；支持迁移限速 | |
| 26 | 故障疏散 | 节点故障后，故障节点上的虚拟机在集群正常节点上启动；WStor 场景支持不关闭节点，自动将故障节点虚拟机在正常节点启动 | |
| 27 | 故障疏散优先级 | 配置范围 1 级–10 级，按优先级疏散 | |
| 28 | 故障检测 | 节点级与虚拟机级故障检测与自恢复：虚拟机异常自动重启；节点异常时将 VM 迁移至健康节点 | |
| 29 | 风险告警 | 创建或重启虚拟机时自动检测集群 CPU、RAM、存储使用，资源不足时风险告警 | |
| 30 | USB 外设管理 | 虚拟机可加载物理节点 USB 设备；挂载时支持选择 USB 控制器协议版本；▲ USB 设备异常中断后支持重新绑定 | |
| 31 | GPU 管理 | 支持 GPU 与 vGPU 设备管理；支持白名单设置 | ARM 不支持 |
| 32 | 直通 GPU | 采用 GPU Passthrough 将物理 GPU 提供给虚拟机 | ARM 不支持 |
| 33 | vGPU | 将物理 GPU 切割为多个 vGPU 分配给虚拟机；▲ 针对摩尔线程支持动态等分切分 | ARM 不支持 |
| 34 | GPU 动态/静态绑定 | 动态绑定时关机自动释放 GPU，再次开机尝试绑定（可能出现资源不足绑定失败） | ARM 不支持 |
| 35 | 虚拟显卡设置 | 支持 Cirrus、QXL、VGA 或 VirtIO 类型显卡 | ARM 不支持 |
| 36 | 弹性扩容 | 按预设 CPU 或内存利用率阈值，自动对虚拟机 CPU 或内存热添加 | ARM 不支持 |
| 37 | 密钥对 | 对 Linux 虚拟机使用密钥对登录 | |
| 38 | 标签管理 | 虚拟机标签管理，通过标签快速过滤 | |
| 39 | 回收站 | 虚拟机和磁盘删除后可进入回收站，支持恢复 | |
| 40 | 聚合组 | 虚拟机迁移和故障疏散仅在聚合组内部进行 | |
| 41 | 节点扩展 | 在不中断业务的情况下扩展集群节点规模 | |
| 42 | 多光驱挂载 | 支持挂载两个光盘 | |
| 43 | 虚拟机批量操作 | ▲ 支持针对虚拟机/虚拟机磁盘的批量操作，如更改计算配置、克隆、磁盘扩容 | |
| 44 | 时区配置 | 部署平台时支持进行时区配置 | |

## 二、网络服务

| 序号 | 参数项 | 技术要求 |
|------|--------|----------|
| 1 | 经典虚拟网络（VLAN） | 虚拟网络管理，支持 VLAN、子网、子网网关、DHCP IP 等管理设置；支持 IPv4 和 IPv6 类型地址配置；支持自定义 DHCP 服务器的 IP 和 MAC 地址 |
| 2 | 端口组虚拟网络 | 端口组网络管理，支持纯二层端口组虚拟网络；不限制各 vPort 的流量转发；▲ 具有管理网端口组和上联口，支持业务虚拟机直接连入管理网络 |
| 3 | 二层组播 IGMP Snooping | 在端口组网络中支持 IGMP Snooping 功能，包含 IGMP Snooping v1 和 v2 |
| 4 | SR-IOV | 单根 IO 虚拟化，将一块物理网卡虚拟出多个轻量化的 PCI-e 物理设备，从而分配给虚拟机使用；减轻物理节点 CPU 负荷，提高网络性能，降低网络时延 |
| 5 | 直通网卡 | ▲ 支持将节点上空闲的物理网卡配置为直通模式，直接挂载给虚拟机使用，减少网络虚拟化的性能损耗 |
| 6 | 多业务网 | 支持虚拟网络流量通过不同物理网卡进出云平台；▲ 管理网络逻辑上联口支持与业务网共用 |
| 7 | 安全组 | 在经典虚拟网络（VLAN）中针对虚拟机设置进站、出站安全策略；规则支持 TCP/UDP/ICMP 等多种协议 |
| 8 | 双栈网络 | IPv4 和 IPv6 双栈虚拟网络的子网；▲ 外部管理网支持 IPv6/IPv4 双栈，浏览器可通过 IPv6 网络访问产品页面 |
| 9 | 默认路由 | 支持平台对多网卡虚拟机操作系统的默认路由设置；支持在系统设置中禁用和启用此功能 |
| 10 | 网络 QoS 管理 | 创建网络 QoS 策略，将策略应用到虚拟机网卡上 |
| 11 | 允许地址 | 支持虚拟机网卡配置允许地址，即虚拟机网卡允许透传的 IP 地址 |
| 12 | vIP 管理 | 支持配置 vIP，对多个虚拟机进行关联，以实现允许地址和高可用应用 vIP 的管理设置 |
| 13 | MAC 地址管理 | ▲ 支持自定义或按映射 IP 和随机的方式生成虚拟机的 MAC 地址 |
| 14 | 网卡多队列 | 自动为虚拟机的虚拟网卡配置多队列；当虚拟机网络流量数据大、数据交换频繁时可增加网络性能；▲ 支持按网卡配置队列数；▲ 支持修改网卡队列数 |
| 15 | 中断绑核 | 在虚拟机里，通过 VM-Tools 将虚拟网卡队列的中断绑定到虚拟机 CPU 上，提升网络性能 |
| 16 | 静态 IP 注入方式配置 | 子网关闭 DHCP 的场景下，支持 Network Manager 和文件配置方式，对经典 VLAN 和端口组虚拟网络实现注入静态 IP 的配置 |
| 17 | 虚拟管理网设置 | 提供安全网络通道访问系统服务，与业务隔离，供云原生等高级组件使用 |
| 18 | 网络管理 | 展示集群内所使用的各网络平面的详细信息，包括节点、网口、速率、IP 地址、Mac 地址、MTU 值等；▲ 支持创建业务网络、备份网络、迁移网络等 |
| 19 | 网卡管理 | 展示集群内各节点上的网卡使用情况，包括聚合口、物理网卡、子接口和各自的角色用途；▲ 支持创建和管理聚合口，包括聚合模式和成员口增减 |
| 20 | 融合网卡部署 | 支持管理网与业务网（端口组和经典 VLAN 网络）复用同一物理网卡或聚合口 |

## 重点能力索引（原表橙色高亮）

| 类别 | 参数项 | 要点 |
|------|--------|------|
| 计算 | 磁盘加密 | 算法可选 AES 256 或 SM4 |
| 计算 | vTPM | 支持 Windows 11 虚拟机 |
| 计算 | 快照管理 | 回滚效率优化至 1 分钟内 |
| 计算 | 虚拟机克隆 | 链接克隆兼顾独立性与高效性 |
| 计算 | USB 外设管理 | 异常中断后可重新绑定 |
| 计算 | vGPU | 摩尔线程动态等分切分 |
| 计算 | 虚拟机批量操作 | 批量更改计算配置、克隆、磁盘扩容 |

| 网络 | 多业务网 | 管理网逻辑上联口可与业务网共用 |
| 网络 | 双栈网络 | 外部管理网 IPv4/IPv6 双栈；IPv6 访问管理页面 |
| 网络 | MAC 地址管理 | 自定义 / 按 IP 映射 / 随机生成 |
| 网络 | 网卡多队列 | 按网卡配置与修改队列数 |
| 网络 | 网络管理 | 业务网、备份网、迁移网等网络平面创建 |

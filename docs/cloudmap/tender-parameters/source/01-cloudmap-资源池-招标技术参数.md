# Cloudmap 资源池 — 招标技术参数

> **适用范围**：Cloudmap 私有云 / 融合边缘云资源池采购与验收  
> **能力范围**：资源池 **全栈 IaaS/PaaS**（虚拟机、容器、裸金属、云桌面、云数据库、虚拟网元、智算推理、存储、网络、运维监控与日志等）  
> **不含产品线**：**SDNCC** 跨域互联（IPsec/SRv6/SASE/SDN VR 编排等）、**CNSOC/AISOC** 安全运营与态势感知（SIM）— 须单独立项或另册招标  
> **编写原则**：从平台特性与交付能力描述，不暴露底层开源组件与实现细节

---

## 编写说明

### 符号约定

| 符号 | 含义 |
|------|------|
| ★ | 实质性响应条款（不满足可废标；含须可演示、可量化验收的指标） |
| ▲ | 重要技术指标（建议纳入评分） |
| ◇ | 可选模块（未采购该模块时**勿写入标底**） |

### 表述原则

| 不宜写 | 宜写 |
|--------|------|
| 具体虚拟化/容器引擎产品名 | 原生虚拟化引擎、云原生超融合控制面 |
| 具体容器编排平台名 | 云原生统一底座、统一资源编排 |
| 具体 API 框架/厂商名 | 标准 REST 管理接口、统一资源管理接口 |
| 具体分布式存储产品名 | 分布式块存储、高可用存储服务 |
| 具体 SDN/CNI 产品名 | 软件定义网络、VPC 隔离、多网卡接入 |
| 底层组件名（如 etcd、Ceph、Harvester、Kube-OVN 等）及 K8s 资源类型名 | 管理面高可用、存储设备、工作负载、网络策略等产品能力表述 |

## 一、总体要求

| 序号 | 参数项 | 技术要求 |
|------|--------|----------|
| 1.1 | ★ 平台架构 | 云原生超融合私有云平台；在统一控制面下同时提供虚拟机与容器两类计算能力；支持 x86_64、ARM64 及 **海光、鲲鹏、飞腾、龙芯** 等信创 CPU 异构节点混合部署与统一调度 |
| 1.12 | ▲ 部署形态 | 支持超融合一体化与**存算分离**两种落地形态；存算分离场景下计算节点与存储节点可独立扩展，并支持对接外部 SAN/NAS（按项目方案） |
| 1.2 | ★ 统一纳管 | 提供标准 REST 管理接口，支持上级多云管理平台并行纳管多个资源池/站点；实现跨池算力统一视图与统一运维 |
| 1.3 | ★ 多租户 | 支持项目/租户隔离；支持 CPU、内存、存储配额；租户/组织与资源池可绑定 |
| 1.4 | ★ 权限与角色 | 支持基于角色的访问控制；提供管理员、运维、租户等预置角色，并支持自定义角色；权限可分配至用户或用户组 |
| 1.5 | ★ 细粒度授权 | 支持按功能模块及操作类型（查看/管理）分别授权；未授权功能对用户不可见且不可操作；权限策略须对管理控制台与系统管理接口同时生效 |
| 1.6 | ▲ 租户分权 | 支持为租户/组织单独配置功能权限与资源配额；租户用户使用云控制台时，仅能访问所属租户授权范围内的资源与操作 |
| 1.7 | ▲ 高可用 | 管理面支持多副本部署（建议 ≥3 奇数节点）；计算节点支持 N+1 冗余；存储支持多副本或纠删码；节点故障时虚拟机可在健康节点重启，业务 RTO 达分钟级 |
| 1.13 | ▲ 控制面 HA 可视 | 集群计算节点列表须可展示**管理面高可用**分布摘要（管理节点数、就绪状态、是否满足奇数副本仲裁等），便于验收控制面冗余 |
| 1.8 | 监控运维 | 提供集群、节点、虚拟机、存储、网络监控指标；支持告警规则、通知策略、日志采集与接收端配置 |
| 1.9 | ★ 拓扑可视 | 支持机房拓扑、物理网络拓扑等资源总览可视化 |
| 1.10 | ★ 节点线性扩展 | 单资源池集群支持从 1 个物理计算节点起部署，并线性扩展至不少于 1000 个物理计算节点；扩展过程保持统一控制面与统一运维，无需更换平台架构 |
| 1.11 | ★ 多算力形态统一承载 | 同一资源池须在统一控制台分模块提供 **虚拟机、容器、裸金属（独立资源池接入）、云桌面、PaaS 云数据库、虚拟网元** 等算力与服务形态；各形态共享网络、存储、监控与权限体系，无需切换独立第三方产品完成日常运维 |

## 二、计算服务

### 2.1 虚拟机（云主机）基础能力

| 序号 | 参数项 | 技术要求 |
|------|--------|----------|
| 2.1.1 | ★ 生命周期 | 支持虚拟机创建、开机、关机、重启、删除、变配等全生命周期管理；运行状态可查询、可审计 |
| 2.1.2 | ★ 规格配置 | 支持自定义 vCPU、内存（GiB）；提供常用规格预设（如 2C/4G、4C/8G、8C/16G 等）；支持 CPU/内存 QoS（请求与上限）及来宾 CPU 拓扑（Socket/Core/Thread）配置 |
| 2.1.3 | ★ 架构适配 | 按 CPU 架构（x86_64 / ARM64）自动适配虚拟机硬件机型，并提供推荐默认配置 |
| 2.1.4 | ★ 镜像与模板 | 支持云主机镜像管理（含 ISO、磁盘镜像等格式）；支持虚拟机模板创建及基于模板快速创建实例 |
| 2.1.5 | ▲ 热扩容 | x86 平台支持 CPU、内存在线热扩容（可配置热扩容上限）；ARM 平台须明确是否支持及等效说明；启用热扩容时须锁定 CPU 拓扑，且与 **NUMA 亲和、大页内存** 互斥（界面须提示） |
| 2.1.6 | ▲ 热迁移 | 支持无直通设备的虚拟机在线迁移；绑定 GPU/PCI 直通、硬件网卡直通的虚拟机须明确限制条件及替代方案 |
| 2.1.7 | 运行策略 | 支持始终运行、故障重试、手动、停止等运行策略；支持节点维护时尽可能热迁移、强制热迁移、不迁移等驱逐策略 |
| 2.1.7a | ★ 启动固件 | 创建与变配支持 **传统 BIOS / UEFI**；UEFI 场景支持持久化变量、安全启动；支持 **TPM 2.0**（含持久化状态） |
| 2.1.7b | ★ 初始化配置 | 创建向导支持**云初始化脚本**注入（主机名、网络、密码、SSH 等）；支持初始化配置卷集中管理与挂载；未配置初始化脚本时可自动安装虚拟机代理组件 |
| 2.1.8 | ★ 运行位置 | 创建云主机时须支持三种互斥模式：**自动调度**、**指定主机**（单选计算节点并固定主机绑定）、**故障域**（选择已配置且已分配节点的故障域并写入调度约束） |
| 2.1.9 | ★ 故障域 | 集群「计算配置」支持故障域创建、编辑、删除及为计算节点分配/调整归属；故障域类型须支持机架/可用区/主机等等价分级；创建云主机选择「故障域」模式时须从已分配节点的故障域列表中选择；删除故障域前须校验是否仍被云主机调度约束引用 |
| 2.1.10 | ★ 部署集 | 集群「计算配置」支持部署集创建与管理；须支持置放策略预设：**尽量/必须分散到不同物理机**、**尽量/必须分散到不同故障域**、**跨可用区必须分散**、**尽量聚集到同一物理机**及自定义亲和/反亲和；拓扑维度须至少支持宿主机、故障域（与故障域节点标签一致）、可用区；云主机在自动调度或故障域模式下可加入部署集（创建向导或变配）；**指定主机**、**参与指标自动调度**模式下不可同时使用部署集 |
| 2.1.11 | ▲ 指标自动调度（DRS） | 集群「计算配置」支持基于指标的调度规则创建、编辑、删除；云主机在**自动调度**模式下可勾选「参与指标自动调度」；须提供 DRS 触发的虚拟机热迁移记录查询；参与指标自动调度的云主机不可同时配置部署集 |
| 2.1.12 | ▲ 高级节点亲和 | 云主机变配支持配置节点亲和/反亲和规则（进阶调度，与运行位置、部署集策略可叠加；产品须提示与主机绑定等约束的关系） |
| 2.1.12a | ▲ 虚拟机间亲和/反亲和 | 创建向导与变配支持按**其它虚拟机**配置尽量/必须**同宿**或**分散**（拓扑维度至少支持宿主机级）；与部署集策略可区分使用场景 |
| 2.1.13 | ★ CPU 模式 | 支持主机直通、主机型号匹配及自定义 CPU 型号等来宾 CPU 模式配置 |
| 2.1.14 | ★ CPU 绑核 | 支持将 vCPU **固定绑定**至物理核；启用后 CPU QoS 不再生效，界面须提示 |
| 2.1.15 | ▲ CPU 隔离 | 启用 CPU 绑核后，支持隔离虚拟化管控线程，降低对来宾 vCPU 的干扰 |
| 2.1.16 | ★ NUMA 亲和 | 创建与变配支持 **来宾 NUMA 自动映射**（按宿主机拓扑）或 **手动 NUMA 拓扑**（2–8 个节点，均分 vCPU/内存）；须与 CPU 绑核同时启用；CPU 插槽数须为 NUMA 节点数整数倍；与热扩容互斥 |
| 2.1.17 | ▲ 物理 NUMA 可视 | 计算节点详情展示宿主机 **NUMA 节点数** 及各 NUMA 节点 CPU 分布，便于核对硬件拓扑与性能调优 |
| 2.1.18 | ★ 大页内存 | 创建与变配支持 **2 MiB / 1 GiB** 大页内存；须集群节点已预留对应大页资源；1 GiB 大页须内存为整数 GiB；与热扩容互斥；变更大页通常须重启后生效 |
| 2.1.19 | ★ 内存 QoS | 支持内存请求值与上限配置，配合监控与规格约束控制内存使用 |
| 2.1.20 | ▲ 峰值保护 | 支持 CPU、内存 **峰值保护**（业务峰值时自动取消上限限制）；与 CPU/内存 QoS 协同 |
| 2.1.21 | SSH 密钥 | 支持启动时自动注入 SSH 公钥及基础初始化配置；支持密钥对集中管理 |
| 2.1.22 | 回收站 | 支持虚拟机软删除、回收站恢复与彻底删除 |
| 2.1.23 | ▲ 虚拟机克隆 | 支持基于运行中/已停止虚拟机**直接克隆**（含系统盘与数据盘）；克隆进度可查询，完成后可手动启动 |
| 2.1.24 | ▲ 镜像交付 | 镜像列表支持**控制台上传任务**与上传进度查询；支持镜像标签管理（删除/重命名） |
| 2.1.25 | 迁移记录 | 提供虚拟机热迁移历史查询（含 DRS 触发迁移、可中止进行中的迁移任务） |

### 2.4 裸金属计算

> 裸金属以 **独立资源池**接入上级多云管理平台；生命周期由裸金属控制面执行，平台提供统一北向接口与运维入口。

| 序号 | 参数项 | 技术要求 |
|------|--------|----------|
| 2.4.1 | ★ 资源池接入 | 支持将裸金属站点注册为独立资源池；提供管理地址、凭证配置与连通性测试 |
| 2.4.2 | ★ 概览仪表盘 | 提供裸金属资源池概览：机器总量、状态分布、控制器健康、近期事件等 |
| 2.4.3 | ★ 机器全生命周期 | 支持物理机列表、详情；支持发现纳管、装机部署、释放回收及电源开/关/重启 |
| 2.4.4 | ★ 网络发现 | 支持未纳管设备网络发现列表，并可从发现记录发起纳管 |
| 2.4.5 | ★ 镜像管理 | 支持操作系统镜像列表、同步与删除；部署时可选择目标镜像 |
| 2.4.6 | ★ 网络资源 | 支持子网、VLAN 等裸金属网络资源查看与管理 |
| 2.4.7 | ▲ 批量运维 | 支持向导式部署与批量电源操作；任务进度与结果可查询 |
| 2.4.8 | ★ 与虚拟化协同 | 裸金属、虚拟机、容器在同一多云管理平台分 Tab 运维；资源总览可汇总裸金属规模 |

### 2.5 云桌面服务

> 云桌面依托 **云桌面网关**（统一远程接入与协议引擎）交付；虚拟机与裸金属在业务网可达前提下，经管理员分配后可浏览器访问。

| 序号 | 参数项 | 技术要求 |
|------|--------|----------|
| 2.5.1 | ★ 网关注册 | 系统设置支持云桌面网关实例注册（服务地址、凭据）、连通性测试与启停 |
| 2.5.2 | ★ 资源池接入 | 支持按 Cloudmap 资源池、裸金属资源池分别启用/关闭云桌面能力 |
| 2.5.3 | ★ 协议支持 | 支持 SSH、RDP、VNC 等主流远程协议，浏览器免客户端访问 |
| 2.5.4 | ★ 用户与分配 | 支持云桌面用户管理；管理员将虚拟机或裸金属 **分配** 给指定用户并统一门户登录 |
| 2.5.5 | ★ 虚拟机桌面 | 云主机列表/详情支持「分配云桌面」；用户从网关门户访问已授权桌面 |
| 2.5.6 | ▲ 裸金属远程 | 已部署裸金属节点支持经云桌面网关远程运维（与装机、调优场景衔接） |
| 2.5.7 | ▲ 控制台互补 | 保留虚拟化原生 VNC/WebSSH 控制台，与云桌面网关形成互补 |
| 2.5.8 | ★ 统一密码 | 云桌面网关支持配置**云桌面用户统一密码**；管理员分配虚拟机/裸金属后，用户凭统一密码登录网关门户 |

|------|--------|----------|
| 5.1 | ★ 多池接入 | 单管理实例须接入不少于 2 个资源池；支持批量或逐个注册（含不同地域、边缘/中心等形态）；每池独立管理地址与凭证，接入前须完成连通性测试 |
| 5.2 | ★ API 接入 | 各资源池提供 HTTPS 管理接口及访问令牌认证；管理平台通过标准 REST 接口完成跨池调用 |
| 5.3 | ★ 资源同步 | 支持按池定时/手动同步虚拟机、镜像、云盘、节点、网络、存储类型等资源；同步结果在平台侧形成统一资源目录 |
| 5.4 | ★ 算力统一视图 | 跨池汇总 CPU、内存、GPU 算力总量与已用量；支持总览仪表盘与单池下钻 |
| 5.5 | ★ 统一运维入口 | 在平台内按资源池切换或跨池检索，完成虚拟机、存储、网络等资源的查看与生命周期操作，无需分别登录各池 |
| 5.6 | ★ 权限模型 | 支持按资源池、按租户/组织、按功能模块配置角色与权限；管理员可授权用户访问指定池或跨池只读/运维权限 |
| 5.7 | ▲ 租户与配额 | 支持将指定资源池分配给租户/组织，并配置 CPU、内存、存储等配额；配额用量跨池汇总展示 |
| 5.8 | ▲ Web 控制台 | 提供虚拟机远程桌面（VNC）、WebSSH、云桌面网关门户、容器日志/终端；控制台须标识资源所属资源池 |
| 5.9 | ▲ 多算力池形态 | 管理平台须分模块纳管 Cloudmap 虚拟化池、裸金属池等；跨池展示虚拟机、容器、裸金属规模汇总 |
| 5.10 | 审计 | 关键操作留痕，审计记录须包含操作人、目标资源池、资源对象及时间；支持审计日志查询、导出及外发 |

## 七、验收建议

### 7.1 计算服务（虚拟机）

1. 创建 2C/4G 虚拟机并完成开机  
2. 挂载云盘并验证读写  
3. 如有硬件：验证 GPU/PCI/USB 直通绑定  
4. 无直通设备场景下执行在线迁移  
5. 执行备份/快照及回收站恢复  
6. 演示计算节点加入集群（至少由 N 节点扩容至 N+1 节点），验证新节点纳管成功且已有业务持续运行；投标文件须说明 1–1000 节点线性扩展方案与验证依据  
7. **故障域**：创建故障域并为至少 2 个计算节点分配归属；以「故障域」模式创建云主机并验证仅调度到该域内节点  
8. **部署集**：创建「跨故障域分散」或「跨物理机分散」部署集；将 2 台及以上云主机加入同一部署集并验证落点符合置放策略  
9. **DRS（若纳入）**：配置指标调度规则，勾选云主机「参与指标自动调度」，验证触发迁移后可在迁移记录中查询  
10. **性能调优**：查看计算节点 NUMA 拓扑信息；创建或变配云主机并演示 **CPU 绑核 + NUMA 亲和** 或 **大页内存（2Mi/1Gi）** 之一；验证与热扩容互斥提示  
11. **启动与初始化**：演示 UEFI 或 TPM 配置之一；演示云初始化脚本或 SSH 密钥注入  
12. **克隆**：从已有云主机发起克隆并查询克隆进度  
13. **虚拟机间亲和**：创建向导配置与另一台云主机同宿或分散，验证调度落点  
14. **控制面 HA**：在计算节点列表查看管理面高可用分布摘要  
15. ◇ **异构迁移**：仅采购 §2.11 时验收 P2V/V2V 演示项  

### 7.1.1 容器服务

1. 创建无状态工作负载并验证就绪副本  
2. 查看容器日志与 Web 终端  
3. 创建服务暴露（含负载均衡型关联 IP 池，若环境具备）与七层路由或 API 网关路由  
4. 创建配置项/密钥并挂载至工作负载  
5. 创建网络访问策略与中断保护策略并验证生效  

### 7.1.2 裸金属

1. 注册裸金属资源池并完成连通性测试  
2. 演示机器列表、发现纳管或部署装机（至少 1 台）  
3. 执行电源开/关/重启之一并验证状态回写  
4. 查看镜像与子网/VLAN 资源列表  

### 7.1.3 云桌面

1. 注册云桌面网关并通过连通性测试  
2. 为资源池启用云桌面接入  
3. 将一台虚拟机分配给云桌面用户，经浏览器门户完成 SSH/RDP/VNC 之一访问  

### 7.1.4 PaaS 与虚拟网元

1. 创建云数据库实例（按交付模板）并验证运行正常  
2. 创建虚拟路由器类 PaaS 实例（若纳入交付）并验证网络可达  
3. ◇ 智算推理模块仅在采购时验收  

### 7.2 存储服务

1. 验证统一存储集群、故障域、存储设备状态可监控  
2. 创建存储类型并动态创建云盘；创建云盘快照并从快照恢复  
3. 创建对象存储桶并完成 S3 读写  
4. 创建 NAS 共享目录，分别通过 NFS/SMB 挂载至虚拟机或容器并验证读写  
5. 配置远程备份目标（S3 与 NAS 各 1 个），执行虚拟机备份并验证远程副本  
6. 配置定时备份（含保留份数/失败重试）并完成恢复任务  
7. 演示存储专网或 SDRS 策略查询（若环境已配置）  
8. 从云盘快照创建新卷并挂载验证  

### 7.3 网络服务

1. 创建物理网络：分别演示「全部节点统一网卡」与「按节点指定网卡」；创建链路聚合物理网络并验证成员口可在详情/拓扑中展示  
2. 在已绑定网卡或链路聚合组的物理网络下创建公共子网（含 CIDR、网关、VLAN）  
3. 创建 VPC 与子网，虚拟机挂载并分配静态 IP  
4. 配置 EIP、SNAT、DNAT 并验证连通性  
5. 创建扁平子网与安全组规则  
6. 验证多网卡与附加网络接入  
7. 创建 IP 地址池与自研 SLB 实例：配置 TCP/UDP 监听、绑定虚拟机后端，验证 VIP 流量转发  
8. 演示容器服务暴露与平台网络能力联动（见 7.1.1）  

### 7.4 多池统一纳管

1. 在管理平台注册不少于 2 个资源池并完成连通性测试  
2. 验证各池资源同步后，总览页可展示跨池算力总量与已用量  
3. 在统一控制台内切换资源池，完成虚拟机创建/查询等操作  
4. 验证按池权限授权：受限用户仅可访问授权池  
5. 验证审计日志包含目标资源池标识  

### 7.5 权限与角色

1. 配置只读角色：验证用户仅能查看授权模块，无法创建、变更或删除资源  
2. 配置管理角色：验证用户可在授权范围内完成运维操作，超出范围的操作被拒绝  
3. 租户用户登录云控制台：验证仅能访问所属租户授权的资源与功能  
4. 调整角色权限后，验证授权变更按产品约定生效  

### 7.6 运维监控与日志管理

1. 查看集群/节点监控仪表盘  
2. 创建告警规则并触发一条测试告警，验证通知策略可达  
3. 配置日志采集目标与日志输出端，验证日志可转发至外部接收端  
4. 查看机房拓扑与物理网络拓扑  
5. 查看云主机资源监控仪表盘及单台云主机详情指标面板  

### 7.7 ★ 条款验收

第一至六章所有 **★** 条目均须投标响应并现场演示；量化指标须按表中数值验收，缺项视为实质性条款未响应。**§2.8** 智算推理等 **◇** 可选模块仅在被采购时纳入验收。SDNCC 跨域互联、CNSOC/AISOC 不在本册验收范围。

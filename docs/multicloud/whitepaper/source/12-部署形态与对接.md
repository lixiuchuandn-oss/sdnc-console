# 12. 部署形态与对接

本章说明平台的部署形态、云边协同部署、纳管对接前置条件、许可与离线升级，以及选配模块的确认方式。

## 12.1 部署形态

平台面向私有化部署，规模可从单节点/三节点起步扩展至多节点资源池；与 Cloudmap 融合边缘云协同部署时，可将其资源池作为被纳管对象统一接入（见 **2.4**）。

## 12.2 云边协同部署

中心统一纳管、区域分级承载、边缘就近运行：中心下发策略、镜像、模型与权限，边缘回传监控与审计，弱网时边缘自治；算网大脑与多级边缘管理见融合边缘云白皮书（`../../cloudmap/whitepaper/`）。

## 12.3 纳管对接前置条件

接入各云需满足：有效凭证与权限、平台到对端的网络连通、对端 API/版本满足适配要求；平台提供连通性校验（`cloudConnectionTest`），校验通过后再纳管。

## 12.4 许可与离线升级

- **许可**：平台能力与版本以许可为准（对外路径见 `/api/system/license`）；
- **离线升级**：支持离线包升级（对外路径见 `/api/system/offline-upgrade/*`），适配无外网环境。

## 12.5 选配模块确认

PaaS、模型服务（MaaS）、第三方安全网元、云桌面网关、云安全中心等选配模块须在方案阶段单独确认与部署，不计入默认 IaaS 交付范围。

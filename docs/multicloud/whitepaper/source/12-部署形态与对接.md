# 12. 部署形态与对接

> 本章为大纲占位，待补全正文。聚焦平台部署、纳管对接前置与许可。

## 12.1 部署形态

私有化部署形态与规模规划；与 Cloudmap 融合边缘云的协同部署。

## 12.2 云边协同部署

中心统一纳管、区域分级承载、边缘就近运行：中心下发策略/镜像/模型/权限，边缘回传监控与审计，弱网时边缘自治；算网大脑与多级边缘管理见融合边缘云白皮书。

## 12.3 纳管对接前置条件

各云接入所需的凭证、网络连通、权限与版本要求；连通性校验。

## 12.4 许可与离线升级

平台许可（`/api/system/license`）与离线升级（`/api/system/offline-upgrade/*`）。

## 12.5 选配模块确认

PaaS/MaaS、第三方网元、云桌面网关等选配模块须在方案阶段单独确认。

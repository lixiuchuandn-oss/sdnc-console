# 14. 术语与缩略语

本章统一收录本书出现的术语与缩略语。

## 14.1 平台与产品术语

**ComputerTower**：多云管理平台的统一管控入口，提供门户、租户、权限、编排、监控与审计。
**CNMC**：多云管理产品线代号。
**资源池**：纳管资源的组织单元，也是租户授权与运维的单位。
**多云实例**：被纳管的单个云的登记单位，记录连接信息、区域与能力范围。
**适配清单**：界定某个被纳管云在平台实际可用操作的清单。

## 14.2 云与控制面术语

**Harvester / KubeVirt**：私有超融合虚拟化与虚拟机运行平台。
**MAAS**：裸金属即服务，管理物理机的发现、部署与运维。
**Rancher**：Kubernetes 集群管理平台。
**CSM**：平台接入的一类控制面。
**Xinference / Dify / MaaS**：智算推理、LLM 应用平台与模型即服务（均为选配）。

## 14.3 网络与安全术语

**VPC**：虚拟私有云网络。
**EIP / NAT**：弹性公网 IP 与网络地址转换。
**SRv6 / IPsec**：分段路由 IPv6 隧道与 IPsec 加密 VPN。
**SD-WAN**：软件定义广域网，用于跨站点加密互联。
**RBAC**：基于角色的访问控制。
**SSO**：单点登录。

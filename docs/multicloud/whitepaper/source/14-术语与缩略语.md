# 14. 术语与缩略语

> 本章为大纲占位，待补全正文。统一收录本书出现的术语与缩略语。

## 14.1 平台与产品术语

**ComputerTower**：多云管理平台统一管控入口。
**CNMC**：多云管理产品线代号。
**资源池 / 多云实例**：纳管的组织单元与登记单位。

## 14.2 云与控制面术语

**Harvester / KubeVirt**、**MAAS**、**Rancher**、**CSM** 等被纳管云与控制面。

## 14.3 网络与安全术语

**VPC**、**EIP**、**NAT**、**SRv6**、**IPsec**、**RBAC** 等术语统一口径。

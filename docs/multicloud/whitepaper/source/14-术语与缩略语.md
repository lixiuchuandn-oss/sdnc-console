# 14. 术语与缩略语

本章统一收录本书出现的术语与缩略语。

## 14.1 平台与产品术语

**ComputerTower**：多云管理平台的统一管控入口，提供门户、租户、权限、编排、监控与审计。
**CNMC**：多云管理产品线代号。
**资源池**：纳管资源的组织单元，也是租户授权与运维的单位。
**多云实例**：被纳管的单个云的登记单位，记录连接信息、区域与能力范围。
**适配清单**：界定某个被纳管云在平台实际可用操作的清单。

## 14.2 云与控制面术语

**Cloudmap 私有云**：私有化超融合形态，提供虚拟机、统一存储、统一网络与容器的一体化能力。
**Cloudmap 裸金属集群**：纳管物理机的发现、装机、部署、电源与镜像/网络。
**Cloudmap 边缘一体机**：边缘侧一体化形态，承载智算推理、LLM 应用与现场轻量业务（选配）。
**Rancher**：Kubernetes 集群管理平台。
**CSM**：平台接入的一类安全控制面。
**云桌面网关**：提供无客户端的多协议远程桌面/终端接入（见 **第 8 章**）。
**MaaS**：模型即服务（Model as a Service），提供数据标注、模型训练与推理的端到端能力（选配）。

## 14.3 网络与安全术语

**VPC**：虚拟私有云网络。
**EIP / NAT**：弹性公网 IP 与网络地址转换。
**SRv6 / IPsec**：分段路由 IPv6 隧道与 IPsec 加密 VPN。
**SD-WAN**：软件定义广域网，用于跨站点加密互联。
**RBAC**：基于角色的访问控制。
**SSO**：单点登录。

# 11. 统一运维与可观测

资源散在多云多站点时，运维最怕“看不全、查不到、对不上”。平台把各纳管资源的运维数据打通，提供跨云的资源大盘、监控告警与日志，并以后台服务保障数据一致，降低多系统运维成本。

## 11.1 资源大盘

- **全局总览**：跨云资源、健康度与利用率统一可视；
- **池/实例视图**：按资源池与多云实例下钻查看运行态势。

## 11.2 监控与告警

- **多维度指标**：覆盖计算、存储、网络、容器、智算等运行指标；
- **告警**：支持阈值与规则告警、多渠道通知；推理域指标见 **7.1**。

## 11.3 日志

运行与操作日志集中汇总、检索，便于排障；其中关键操作的审计与合规追溯统一在审计体系中管理（见 **10.5**），本章不再展开。

## 11.4 后台保障服务

平台内置若干后台服务，无需人工干预即保障数据一致与资源清理：

- **资源同步**：定时与各云对端同步资源状态（见 **3.4**）；
- **缓存同步**：周期刷新虚拟路由器等设备列表缓存；
- **回收清理**：定时清理回收站，回收过期资源。

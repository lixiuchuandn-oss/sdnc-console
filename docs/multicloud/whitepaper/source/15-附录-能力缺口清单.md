## A.2 优先级建议（供参考）

- **强合规/运营刚需（政企/政务云高频要求）**：9 服务目录与审批、13 计量计费、8 国密等保、11 企业 SSO。
- **多云核心差异化**：4 跨云迁移、5 容灾 DR、7 跨集群应用编排、6 公有云网络统一视图。
- **可视化与优化增强**：1 跨云 CMDB、12 跨云监控/AIOps、14 成本优化、10 公有云配额。
- **覆盖补齐**：2 腾讯云纳管 UI。

# 8. 远程访问与云桌面网关

对被纳管资源的基础远程访问（终端、图形控制台、容器运维）是平台内置能力，已在 **3.5** 统一说明，本章不再重复。在此之上，平台可选配**云桌面网关**，面向需要按人分配桌面、统一门户登录的场景。

## 8.1 云桌面网关

云桌面网关基于网关引擎 Guacamole，提供多协议的远程桌面与终端接入，由管理员集中分配资源：

- **多协议接入**：经网关统一接入远程桌面与终端，终端侧无需安装客户端；
- **云桌面用户**：独立于平台运维账号的一套云桌面用户体系，管理员为每个用户分配可访问的资源。

## 8.2 用户体系与权限

- **统一门户**：云桌面用户经统一门户登录，只能访问被分配的资源；
- **权限隔离**：与平台 RBAC 及审计衔接，谁登录、访问了哪台资源均可追溯（见 **第 10 章**）。

## 8.3 能力边界

云桌面网关及相关网元为**选配**，须在方案阶段单独确认与部署；当前交付范围以扁平网络与云桌面用户为主，具体以交付方案为准。

# SDN 管理 - 安全域管理 需求设计（PRD）

## 1. 概述

安全域（Security Domain）用于抽象用户在多云/多环境中的业务网络边界，例如 IDC、云上 VPC、虚拟化网络、办公网络等。安全域作为 SDN 平面的核心对象，承载以下职责：

- 统一描述一块业务网络的基础属性（网络类型、CIDR、所属租户与组织等）。
- 作为安全策略与服务链编排的基本作用域。
- 通过 SASE 网关（VR 实例）或直连方式，将业务流量引流至安全资源池。

本 PRD 定义：

- 安全域的核心模型与创建向导。
- 安全域与租户/组织、云资源池、SASE 网关之间的关系。
- “隧道引流/直连引流”的配置方式及对服务链的影响。
- 安全域详情页及其关联资源视图。

## 2. 背景与目标

- 背景：
  - 当前平台已具备 VR 实例管理、SRv6/IPsec 等能力，但缺乏一个统一的“安全网络边界”抽象来承载策略与拓扑。
  - 安全策略往往需要在“某个业务域”视角下进行，而非单个 VPC 或单台 VR。
- 目标：
  - 提供安全域作为统一抽象，绑定租户/组织及网络资源。
  - 使用清晰的向导流程，降低复杂网络场景的配置门槛。
  - 为后续级联通道、服务链编排、安全服务挂载提供稳定的上层语义。

## 3. 范围

- 前端页面：
  - 安全域列表：`/admin/sdn/security-domain`
  - 新建/编辑安全域向导：`/admin/sdn/security-domain/new`
- 后端接口：
  - 安全域 CRUD。
  - 云资源池与 VPC 列表。
  - 云端创建 VPC（可选）。
- 展示与确认：
  - 向导确认页完整展示 IPv4/IPv6 与 VR 绑定、引流方式。
  - 安全域详情页展示关联的 VPC/VR/隧道/服务链等。

## 4. 术语与关系

- SecurityDomain：安全域实体。
- Tenant/Org：租户与组织，定义安全域归属，详见《多云管理 - 租户管理》。
- VPC：云上虚拟私有网络。
- VR/SASE 网关：承载隧道与安全引流的虚拟路由器实例。
- Cloud Pool：云资源池（阿里云/华为云/Cloudmap/Harvester 等）。
- Traffic Mode（引流方式）：
  - `tunnel`：隧道引流。
  - `direct`：直连引流。

## 5. 用户与权限

- 租户管理员/网络管理员：
  - 在其授权的租户/组织范围内创建与管理安全域。
  - 管理安全域与 VPC/VR/SASE 网关的关联关系。
- 安全运维人员：
  - 查看安全域拓扑、状态与告警。
  - 在安全域中挂载安全服务与服务链。

## 6. 创建安全域向导

创建安全域采用三步向导模式，遵循原有 `安全域管理 PRD` 的基本结构，并引入租户/组织与引流方式配置。

### 6.1 Step 1：设定基础信息

- 字段：
  - 名称（必填）：安全域名称。
  - 类型（必填）：IDC/VPC/虚拟化/办公/其他。
  - 所属租户（必填）：当前上下文租户，或由用户选择。
  - 所属组织（必填）：通过“租户 → 组织”级联选择器选择 Org。
  - 说明（可选）：文本描述。
  - 标签（可选）：Key-Value 形式。

### 6.2 Step 2：设定安全域网络与引流方式

- 分支逻辑：
  - VPC 类型安全域。
  - 非 VPC 类型安全域（IDC/办公/虚拟化等）。

#### 6.2.1 VPC 类型

- 云资源池选择：
  - 仅展示当前组织可用的 Cloud 列表（基于 ResourcePoolAssignment）。
- VPC 来源：
  - 使用已有 VPC：
    - 选择云资源池后，加载该 Org 下可见的 VPC 列表。
  - 新建 VPC：
    - 字段：VPC 名称、IPv4 CIDR（必填）、是否开启 IPv6 及 IPv6 CIDR（开启时必填）。
    - 支持调用云端创建 VPC 接口；云端失败不阻断安全域创建，但需明显提示。
- VR 绑定：
  - 自动：系统根据云资源池和 VPC 上下文选择合适的 VR/VRF。
  - 绑定已有：用户从 VR 列表中选择一个或多个 VR 实例作为出口。

#### 6.2.2 非 VPC 类型

- 适用场景：
  - IDC 机房网络。
  - 办公网/扁平网络。
  - 虚拟化网络等。
- 配置项：
  - 绑定 VR（必填）：从 VR 实例列表选择一台或多台作为该安全域的边界设备。
  - IPv4 CIDR/IPv6 CIDR（可选）：建议至少填写一项，用于拓扑与策略展示。

#### 6.2.3 引流方式配置（安全域级）

- 在安全域维度统一配置安全流量引流方式，供后续服务链继承与复用：
  - 隧道引流（tunnel）：
    - 通过绑定的 SASE 网关（VR 实例）创建隧道，将安全域内业务流量引流至安全资源池。
    - 对应后续在 VR/SRv6/IPsec 模块中的隧道配置动作。
  - 直连引流（direct）：
    - 安全域所在物理网络已通过核心交换或旁路方式直连到安全资源池。
    - 系统不再自动为该安全域创建隧道，仅在策略与服务链编排层面处理流量。
- UI 约束：
  - 当选择 `tunnel` 时，需确保已绑定至少一个 VR 实例。
  - 当选择 `direct` 时，给出提示说明“不会自动创建隧道，仅进行策略编排”。

### 6.3 Step 3：确认安全域

- 确认页需分区展示：
  - 基础信息：名称、类型、租户、组织、标签。
  - 云资源与 VPC（仅 VPC 类型）：云资源池、VPC 详情、IPv4/IPv6。
  - 网络设置（非 VPC 类型）：绑定 VR、CIDR/CIDR6。
  - 引流方式：tunnel/direct。
- 用户确认后提交创建，创建成功后跳转至安全域详情页。

## 7. 字段与校验

- 基础字段：
  - `name`、`type`、`tenantId`、`orgId` 必填。
  - `description/tags` 可选。
- VPC 类型：
  - `cloudId/vpcMode` 必填。
  - 使用已有 VPC 时：`vpcId` 必填。
  - 新建 VPC 时：`newVpcName`、`newVpcCidr` 必填；开启 IPv6 时 `newVpcIpv6Cidr` 必填。
- 非 VPC 类型：
  - `vrUuid` 必填。
  - `cidr/cidr6` 可选，建议至少填一项（可在后续版本中提升为强校验）。
- 引流方式：
  - `trafficMode` 必填，取值：
    - `tunnel`：隧道引流，由 VR 实例创建至安全资源池的隧道承载。
    - `direct`：直连引流，假定底层物理网络已连通安全资源池。
  - 服务链默认继承所属安全域的 `trafficMode`，仅在特殊场景下允许覆盖（具体覆盖规则在服务链 PRD 中定义）。

## 8. 数据与接口

- 安全域实体（示意）：
  - `id`、`name`、`type`、`tenantId`、`orgId`、`description`、`tags`。
  - `trafficMode`：`tunnel`/`direct`。
  - 网络属性：
    - VPC 类型：`cloudId`、`vpcId`、`newVpcName`、`newVpcCidr`、`newVpcIpv6Cidr`。
    - 非 VPC 类型：`vrUuid`、`cidr`、`cidr6`。
- 接口：
  - 安全域 CRUD：
    - `POST /api/security-domains`：创建。
    - `GET /api/security-domains`：列表（支持按 tenantId/orgId 过滤）。
    - `GET /api/security-domains/{id}`：详情。
    - `PUT /api/security-domains/{id}`：更新。
    - `DELETE /api/security-domains/{id}`：删除。
  - 云相关接口：
    - `fetchClouds()`：获取云资源池列表。
    - `fetchCloudProviderVpcs(cloudId)`：获取指定资源池下 VPC 列表。
    - `createCloudProviderVpc(...)`：新建 VPC。

## 9. 前端页面结构与文案

- 向导页：
  - 左侧步骤条（基础信息/网络与引流/确认）。
  - 右侧内容区按步骤渲染。
  - 主按钮：“上一步/下一步/创建/取消”。
  - 使用统一中文文案与提示，错误信息简洁明确。
- 列表页：
  - 字段：名称、类型、租户、组织、引流方式、关联 VPC/VR 数量、状态（Active/Disabled 等）。
  - 筛选：按租户/组织/类型/引流方式。

## 10. 状态与性能

- 使用表单值驱动向导状态。
- VR 与云列表按需加载（懒加载、搜索）。
- 列表数据支持分页、搜索与前端截断显示。

## 11. 错误处理与回退

- 云端新建 VPC 失败：
  - 不阻断安全域创建，但需提示“当前安全域未关联云侧 VPC”。
- 表单校验失败：
  - 阻止进入下一步，聚焦到第一个错误字段。
- 网络错误：
  - 列表页显示“暂无数据/加载失败”提示，并提供重试按钮。

## 12. 非功能需求

- 安全：
  - 所有接口需校验租户/组织权限。
  - 不泄露不属于当前租户/组织的任何资源信息。
- 性能：
  - 在常规租户规模下，安全域列表与向导的首次加载时间可接受（例如 <3 秒）。

## 13. 安全域详情页

- 概览区：
  - 安全域名称、类型、租户、组织。
  - 引流方式（隧道/直连）。
  - 当前状态（启用/禁用/异常）。
- 子资源 Tabs（参考原 PRD）：
  1. 资源总览：VPC 及 VR 实例信息表格。
  2. 安全域拓扑：画板，展示 VPC/VR/安全服务/隧道等节点与关系。
  3. 级联通道：显示该安全域关联的所有 SRv6 隧道实例。
  4. 应用实例：显示安全域内的应用实例。
  5. 安全服务：显示挂载到该安全域的安全服务实例。
  6. 服务链：显示该安全域关联的所有服务链实例。
  7. SRv6 隧道：显示该安全域关联的 SRv6 隧道实例。
  8. IPsec VPN：显示该安全域关联的所有 IPsec VPN 实例。
  9. NAT：显示该安全域关联的所有 NAT 实例。
  10. 网络 ACL：显示该安全域关联的所有网络 ACL 实例。
  11. 旁路阻断：显示该安全域关联的所有旁路阻断策略实例。

## 14. 验收与测试

- 基础流程：
  - 能通过向导创建 VPC 类型和非 VPC 类型安全域。
  - 能选择与当前租户/组织匹配的云资源池与 VPC。
- IPv6 支持：
  - 向导中 IPv6 开启时能够正确填写与展示 IPv6 CIDR。
- 引流方式：
  - 能在创建和编辑安全域时设置 `trafficMode`，并在详情与列表中正确展示。
  - 服务链在默认情况下继承所属安全域 `trafficMode`。
- 权限与过滤：
  - 列表与详情按 `tenantId/orgId` 正确过滤。

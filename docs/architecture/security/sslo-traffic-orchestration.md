# SSLO 流量编排 (Traffic Orchestration) PRD

## 1. 概述 (Overview)
本产品 (SSLO) 支持服务链编排，允许按照需求将指定的五元组流量引导至不同的安全设备进行处理。

## 2. 功能架构 (Feature Architecture)
- **一级菜单**: SDNCC
- **二级菜单**: 流量编排 (Traffic Orchestration)
- **三级功能**:
    1. VSW 集群管理
    2. 安全域管理
    3. 防护对象管理
    4. 服务链管理

## 3. 详细功能设计 (Detailed Functional Design)

### 3.1 VSW 集群管理 (VSW Cluster Management)
以集群为主体进行管理，关注集群内的 VSW 服务状态及实例状态，支持跨云大平台的多集群管理。
**原理说明**: 安全资源池集群中，每台物理机都需要部署一个 VSW 实例。本模块按集群维度展示服务健康状态，并支持深入查看物理机维度的部署情况。

*   **云安全资源池管理 (Cloud Security Resource Pool Management)**:
    *   支持从 **CNMC 资源池管理** 页面添加云安全资源池。
    *   支持在 **VSW 集群管理** 页面直接添加云安全资源池。

*   **Tabs**:
    1.  **集群列表 (Cluster List)**:
        *   展示管理的所有 VSW 集群。
        *   支持集群的添加、删除、编辑等管理操作。
        *   **集群服务状态 (Service Health Status)**:
            *   **终态 (Final State)**: 集群内所有物理机都已部署 VSW，且运行正常。
            *   **亚健康 (Sub-healthy)**: 集群内所有物理机都已部署 VSW，但存在物理机宕机或部分 VSW 实例宕机。
            *   **不可用 (Unavailable)**: 集群宕机，或集群内所有 VSW 实例均宕机。
    2.  **实例列表 (Instance List)**:
        *   **筛选条件**:
            *   **集群选择**: 必须选择一个集群进行管理。
            *   **物理机选择**: 支持选择“全部物理机”或“指定物理机”。
        *   **展示逻辑**:
            *   列表应列出所选集群下**所有的物理机**。
            *   如果该物理机已部署 VSW，显示 VSW 详情。
            *   如果该物理机未部署 VSW，显示物理机信息，状态为“未部署”。
        *   **列表字段**:
            *   序号
            *   **物理机 IP/名称** (新增)
            *   VSW 名称 (未部署时为空)
            *   引流模式 (如：三层引流)
            *   引流前缀
            *   虚拟交换机工作线程数
            *   **状态**: 正常 / 异常 / 未部署
            *   操作
        *   **操作项**:
            *   **已部署**: 配置变更、定义网卡、SSL 加解密配置、恢复服务链配置、移除实例。
            *   **未部署**: 提供 **部署 VSW** 的操作入口，支持为集群内指定的物理机部署 VSW。

### 3.2 安全域管理 (Security Zone Management)
安全域是流量编排的一个集合，包含圈定的安全设备、防护对象和服务链。

*   **列表页**: 展示安全域列表，支持安全域的增删改查。
*   **详情页 (Detail Page)**:
    *   **组件**: 使用 `ResourceDetailContainer.tsx`。
    *   **上半部分**: 安全域基本详情。
    *   **下半部分 (Tabs)**:
        *   **安全设备 (Security Devices)**: 展示该安全域下的设备，支持关联/移除、状态查看。
        *   **防护对象 (Protected Objects)**: 展示该安全域关联的防护对象，支持关联/移除。
        *   **服务链 (Service Chains)**: 展示该安全域内的服务链，支持管理。

### 3.3 防护对象管理 (Protected Object Management)
用于统一管理对哪些 IP 及端口的流量进行编排。

*   **支持类型 (Types)**:
    1.  **自定义 (Custom)**: 用户自定义输入的 IP 地址或 IP 网段。
    2.  **VPC**: 选择云资源池中的 VPC。
    3.  **私网服务 (Private Service)**: 内部私有服务。
    4.  **公网域名 (Public Domain)**: 公网可访问的域名。
    *(注：截图显示类型有 自定义、VPC、私网服务、公网域名，与之前需求略有差异，以此为准)*

*   **列表页功能**:
    *   **搜索**: 支持按 **对象 IP**、**对象 ID**、**对象名称**、**对象类型** 进行模糊搜索。
    *   **字段**:
        *   Checkbox (多选框)
        *   对象名称
        *   对象类型 (自定义、VPC 等)
        *   防护范围 (IP/CIDR)
        *   服务名称(域名)
        *   所在安全域名称
        *   所在服务链 (链接可点击)
        *   流量日志 (7天) - 显示状态如 "无流量日志"，支持刷新
        *   威胁数量 (7天) - 高/中/低
        *   操作
    *   **操作项**:
        *   **编辑信息**: 修改对象名称、类型等。
        *   **删除对象**: 删除该防护对象。
        *   **批量删除**: 列表底部提供批量删除按钮。

*   **新增/编辑弹窗**:
    *   **对象名称**: 必填输入框。
    *   **对象类型**: 下拉选择 (自定义、VPC、私网服务、公网域名)。
    *   **防护端口**: 根据类型可能需要输入。

### 3.4 服务链管理 (Service Chain Management) - 核心功能
服务链定义了流量经过安全设备的顺序。

*   **顶部操作栏**:
    *   **创建服务链**: 创建新的服务链。
    *   **公网DNS配置**: 配置公网 DNS。
    *   **搜索**: 支持按 **租户名称** 进行搜索，支持刷新列表。

*   **列表页字段**:
    *   Checkbox (多选框)
    *   所属租户
    *   所属组织
    *   所属安全域
    *   服务链ID/名称
    *   服务链类型 (如：串行、旁路+串行)
    *   防护对象 (数量，如：2 项)
    *   安全服务 (网元组) (数量，如：1 项)
    *   串行状态 (如：正常)
    *   旁路状态 (如：正常、--)
    *   目标流量 (如：1.15E7pps)
    *   来源流量 (如：2.18E7pps)
    *   **服务链健康度** (如：100%)
    *   操作

*   **操作项**:
    *   **服务链详情**: 点击跳转至详情页，支持查看可视化拓扑。
    *   **更多操作**:
        *   **执行一键Bypass**: 快速旁路流量。
        *   **编辑**: 编辑服务链配置。
        *   **删除**: 删除服务链。

*   **批量操作**:
    *   **删除**: 列表底部支持批量删除选中项。

*   **详情页 (Detail Page)**:
    *   **头部信息**:
        *   返回按钮、服务链名称。
        *   状态标签 (如：串行、旁路)。
        *   所属安全域信息 (支持跳转/编辑)、**重新检测** 功能入口。
    *   **左侧指标面板**:
        *   最大带宽 (MB)。
        *   上行流量 (pps)。
        *   下行流量 (pps)。
        *   异常 Path 数量 (如：0条)。
    *   **路径状态列表 (Path Status Panel)**:
        *   位于左侧（可折叠/展开），展示该服务链下所有路径的状态。
        *   **筛选**: 支持下拉筛选 (如：全部、异常)。
        *   **列表内容**: 序号、Path 状态 (正常/异常)、异常网元数量。
    *   **可视化拓扑区域 (Topology Canvas)**:
        *   **核心节点**:
            *   **源头**: 互联网 (Internet) 图标。
            *   **终端**: 防护资产 (Protected Asset) 图标。
        *   **设备节点**:
            *   展示串行/旁路的安全设备。
            *   **信息展示**: 设备图标、设备名称 (如 waf_33)、管理 IP (如 10.21.100.216)、设备类型 (如 waf)。
        *   **连线**:
            *   以连线表示流量走向 (如：互联网 -> WAF -> 防护资产)。
            *   连线颜色表示状态 (如：绿色代表正常)。

*   **新增/编辑服务链 (Create/Edit Wizard)**:
    *   采用分步向导模式，左侧为步骤导航：**基本信息** -> **防护对象** -> **服务链设定** -> **创建**。
    *   **Step 1: 基本信息 (Basic Info)**:
        *   **服务链名称**: 输入框。
        *   **设定使用场景**:
            *   **一级分类**:流量检测/防护模式模式、应用加密改造模式
            *   **二级分类**:
                *   应用加密改造: 
                    * 商密改造 D:\Compute.Tower\frontend\src\assets\sm-gz.png
                    * 国密改造 D:\Compute.Tower\frontend\src\assets\gm-gz.png
                    * 商密应用改国密 D:\Compute.Tower\frontend\src\assets\sm-to-gm.png
                    * 国密应用改商密 D:\Compute.Tower\frontend\src\assets\gm-to-sm.png
                *   流量检测/防护: 
                    * 标准 D:\Compute.Tower\frontend\src\assets\std.png
                    * WAN 加密流量检测 D:\Compute.Tower\frontend\src\assets\wan.png
                    * LAN 商密流量检测 D:\Compute.Tower\frontend\src\assets\lan-sm.png
                    * LAN 国密流量检测 D:\Compute.Tower\frontend\src\assets\lan-gm.png
                *   
        *   **安全域示意图**: 根据选择的场景动态展示预设的流量走向图 (如：浏览器 -> 加解密模块 -> 防火墙 -> WAF -> 私网应用)。
    *   **Step 2: 防护对象 (Protected Objects)**:
        *   **选择防护对象**: 下拉搜索框 (支持按 对象IP 搜索)。
        *   **列表**: 展示已选对象，包含字段：对象名称、对象类型、标签、防护范围、服务名称(域名)。
        *   支持空状态显示 "暂无数据"。
    *   **Step 3: 服务链设定 (Service Chain Settings)**:
        *   **交互设计 (Interaction)**:
            *   **所画即所得 (WYSIWYG)**: 支持通过鼠标拖拽的方式进行服务链编排。
            *   **组件面板**: 界面侧边或顶部提供可用安全设备/网元组件库。
        *   **串行服务链**:
            *   **启用开关**: Checkbox。
            *   **可视化编排**:
                *   展示 "互联网" <-> "防护对象" 的主路径。
                *   **添加节点**: 支持从组件面板 **拖拽 (Drag & Drop)** 安全服务节点至主路径上，也可点击路径上的 "+" 号添加。
                *   **调整顺序**: 支持鼠标拖拽已添加的节点来调整服务链顺序。
                *   **状态图例**: 红色 (异常)、绿色 (正常)、黄色 (告警-部分虚机故障)。
        *   **旁路服务链 (并行)**:
            *   **启用开关**: Checkbox。
            *   **可视化编排**:
                *   展示镜像流量引流路径。
                *   **操作**: 同样支持拖拽组件至旁路区域进行配置。
    *   **底部操作栏**:
        *   **立即创建**: 提交按钮。

*   拓扑图需清晰展示流量路径和设备节点。

# 多云平台仪表盘 PRD

## 背景与目标
- 跨云资源与云企业网（CEN）聚合管理的单屏概览；统一指标、状态与快捷操作。

## 用户与角色
- `super_admin`：全局数据与操作；跨租户。
- `tenant`：本租户数据与操作（受限）。

## 布局与导航
- 顶部摘要：云资源总数、CEN总数、近24小时事件、登录用户数。
- 关键指标（多云）：提供商分布、状态分布、区域热力。
- 网络态势（CEN）：数量与状态、拓扑缩略、附件统计。
- 事件时间线：关键事件与失败操作。
- 快捷操作：创建云资源/创建CEN/管理附件/查看配额与限额。
- 全局筛选：时间范围、租户、云提供商、区域、状态、标签。

## 数据刷新与性能
- 摘要与分布图：60s 轮询；手动刷新。
- 事件：30s 轮询或推送。
- 拓扑：60s 刷新；支持重拉。
- 首屏与交互性能目标：2–5s 与 <200ms。

## 多云管理能力
- 提供商分布、区域热力、健康仪表；列表摘要与批量操作；凭据健康与告警。

## 云企业网管理能力
- CEN总览与状态分布；拓扑视图与边/节点交互；附件管理（挂载/解绑/重试）。

## 接口（参考）
- `GET /api/clouds`、`GET /api/dashboard/stats`、`GET /api/dashboard/recent-activities`。
- `GET /api/cens`、`GET /api/cens/:id/attachments`、`DELETE /api/cens/:id`、`POST /api/cens`。

## 验收标准
- 首屏包含核心卡片与分布；图表联动过滤与跳转；事件区≥10条；权限差异生效。

## 非功能
- 安全（JWT/CORS）、可用性（友好提示与重试）、国际化、可观测性（耗时/失败率埋点）。

## 风险与里程碑
- 实时性与权限受限；拓扑性能优化；限流与凭据过期降级。
- M1/M2/M3 分阶段交付。

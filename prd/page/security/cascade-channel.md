# 产品需求文档：级联通道管理 (Cascade Channel Management)

## 1. 文档概述
**项目名称**：安全管理面 - 级联通道管理
**功能目标**：提供一个统一的编排平面，通过定义“信息域”之间的互联拓扑关系，自动生成底层的 SRv6 或 IPsec VPN 隧道配置，并调用南向接口将配置下发至对应的 VR（虚拟路由器）实例，实现跨域互联。

## 2. 核心概念与逻辑
*   **级联通道 (Cascade Channel)**：逻辑上的互联容器（对应原 CEN 实例）。它是互联策略的载体。
*   **信息域 (Info Domain)**：互联的端点（Endpoint）。每个信息域关联一个具体的 VR 实例或 VPC 网络。
*   **关联关系 (Association)**：定义信息域之间“谁和谁通”。
*   **隧道策略 (Tunnel Strategy)**：定义“怎么通”。支持 SRv6（高性能/专线）和 IPsec VPN（加密/公网）。
*   **配置下发 (Provisioning)**：系统将“拓扑+策略”翻译为 VR 可执行的指令。

## 3. 用户流程 (User Flow)
1.  **创建通道**：用户创建一个“级联通道”实例（例如：“北京-上海跨域互联”）。
2.  **挂载信息域**：用户选择需要互联的若干个“信息域”加入该通道。
3.  **定义拓扑与策略**：
    *   系统默认或用户指定拓扑（如：全互联 Mesh、中心-分支 Hub-Spoke）。
    *   选择隧道技术：SRv6 或 IPsec VPN。
4.  **配置下发**：
    *   用户点击“生效/下发”。
    *   系统计算成对的隧道参数。
    *   系统调用 API 推送配置到各信息域绑定的 VR。
5.  **状态监控**：查看隧道建立状态（Up/Down）及流量监控。

## 4. 功能需求详情

### 4.1 通道实例管理 (CRUD)
*   **列表页**：展示已创建的级联通道。
    *   字段：名称、描述、包含信息域数量、互联策略（SRv6/IPsec）、状态（配置中/已下发）。
*   **新建/编辑**：
    *   输入名称、描述。
    *   **关键配置项**：
        *   `互联模式`：
            *   `Full Mesh` (全互联)：所有挂载的信息域两两互通（默认）。
            *   `Hub-Spoke` (中心-分支)：指定一个信息域为 Hub，其余为 Spoke，Spoke 间不互通。
            *   `P2P` (点对点)：仅指定两个信息域互通。
        *   `隧道类型`：`SRv6` 或 `IPsec`。

### 4.2 信息域挂载与关联
*   **挂载操作**：
    *   从“信息域列表”中选择多个加入通道。
    *   *校验*：被挂载的信息域必须已绑定有效的 VR 实例（因为最终配置要下发给 VR）。
*   **关联视图**：
    *   提供可视化拓扑图或关联矩阵，展示当前通道内哪些信息域之间建立了连接。

### 4.3 隧道配置生成与转换 (核心逻辑)
系统后台需实现以下转化逻辑（伪代码逻辑）：
*   **输入**：信息域 A (VR_A, IP_A), 信息域 B (VR_B, IP_B), 策略=IPsec。
*   **处理**：
    1.  检测 VR_A 和 VR_B 的可达性。
    2.  生成互联参数：
        *   Tunnel Source/Destination IP。
        *   IKE/IPsec Proposal (加密算法、密钥，若为 IPsec)。
        *   SRv6 SID List / Policy (若为 SRv6)。
    3.  生成路由策略：将 A 的网段路由发布给 B，反之亦然。

### 4.4 配置下发 (Provisioning)
*   **触发方式**：手动点击“应用配置”或挂载变动时自动触发（可配置）。
*   **接口调用**：
    *   调用封装好的南向接口（例如 `POST /api/vr/{vr_id}/tunnels`）。
    *   参数包体应包含：对端 VR 信息、隧道类型、路由表项。
*   **反馈机制**：
    *   界面需显示下发进度（例如：“正在配置 VR-Beijing... 成功；正在配置 VR-Shanghai... 成功”）。

## 5. 数据结构设计 (参考)

建议在后端或前端 State 中维护如下模型：

```typescript
// 级联通道实例
interface CascadeChannel {
  id: string;
  name: string;
  strategy: 'SRv6' | 'IPsec'; // 隧道类型
  topology: 'Mesh' | 'Hub-Spoke'; // 拓扑模式
  hubDomainId?: string; // 如果是 Hub-Spoke，指定 Hub
  domains: AttachedDomain[]; // 已挂载的信息域
  status: 'draft' | 'syncing' | 'active' | 'error';
}

// 挂载关系
interface AttachedDomain {
  domainId: string;
  domainName: string;
  vrId: string; // 关联的 VR 实例 ID
  vrIp: string; // VR 的公网/互联地址
  role: 'peer' | 'hub' | 'spoke';
}
```

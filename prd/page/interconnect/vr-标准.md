# VR实例标准模式产品需求文档 (PRD)

## 1. 概述
VR（Virtual Router）标准模式是一种高性能、多功能的虚拟路由设备，旨在为多云环境、异构网络提供灵活的路由与互联能力。在标准模式下，VR实例主要扮演**三层路由器**和**IPsec VPN网关**的角色，支持物理机和虚拟机部署，能够满足企业级网络互联、安全隔离及远程接入的需求。

## 2. 产品功能

### 2.1 三层路由器能力
作为核心的三层网络设备，VR标准模式提供全面的路由转发与网络服务功能。

#### 2.1.1 接口与连接
*   **物理与虚拟接口支持**：支持物理口、内存接口（VSW互联）、Tap接口（内核互联）、Vhost虚拟机接口。
*   **子接口支持**：
    *   **VLAN子接口**：支持在所有接口上创建，最大支持4094个VLAN。
    *   **VxLAN子接口**：支持VxLAN隧道终结，最大支持40k个。
*   **端口聚合**：支持静态/动态LACP，支持基于源/目的MAC、IP的负载均衡算法。

#### 2.1.2 路由协议
*   **静态路由**：支持配置静态路由条目，支持路由健康检查。
*   **动态路由**：
    *   **OSPFv2/v3**：支持开放最短路径优先协议，适用于内部网关路由。
    *   **BGP4/BGP4+**：支持边界网关协议，适用于大规模网络互联。
*   **VRF（虚拟路由转发）**：支持多达4000个VRF实例，实现路由隔离与多租户网络支持。
*   **策略路由**：支持基于源地址、五元组的策略路由，支持ECMP（等价路由）。

#### 2.1.3 网络服务
*   **DHCP服务**：支持DHCP服务器、中继，支持多段地址池、固定IP分配及状态监控。
*   **NAT（网络地址转换）**：
    *   支持源NAT（SNAT）、目的NAT（DNAT）、静态NAT。
    *   支持NAT多实例，每个实例独立配置。
    *   支持ALG（应用层网关），支持FTP、SIP等协议穿越。
*   **DNS**：支持DNS客户端与服务器功能。
*   **ARP**：支持静态ARP绑定，ARP表大小高达40960。

### 2.2 IPsec VPN网关能力
VR标准模式内置强大的IPsec VPN功能，用于构建安全加密的私有网络通道。

#### 2.2.1 部署模式
*   **网关到网关（Site-to-Site）**：连接不同分支机构或云端VPC。
*   **远程接入（Remote Access）**：支持移动用户通过VPN客户端安全接入。

#### 2.2.2 协议与认证
*   **IKE协议**：支持IKEv1/IKEv2。
*   **认证方式**：
    *   **预共享密钥（PSK）**：适用于中小型部署。
    *   **证书认证**：适用于高安全性要求场景。
*   **协商模式**：支持主模式（Main Mode）和野蛮模式（Aggressive Mode）。
*   **加密算法**：支持DES, 3DES, AES128/192/256。
*   **完整性校验**：支持MD5, SHA-1/SHA-2。
*   **DH组**：支持多种Diffie-Hellman组配置。

#### 2.2.3 高级特性
*   **VPN多实例**：支持IPsec VPN多实例部署，实现租户隔离。
*   **DPD（死亡对等体检测）**：自动检测链路状态，快速故障切换。
*   **NAT穿越（NAT-T）**：支持IPsec流量穿越NAT设备。

## 3. 技术规格 (基于V1.0)

| 规格项 | 指标说明 |
| :--- | :--- |
| **吞吐量 (FW/IPsec)** | 物理机: 5Gbps / 1Gbps (1线程)<br>虚拟机: 5Gbps / 1Gbps (1线程) |
| **并发连接数** | 千万级 |
| **IPsec隧道数** | 1000 (1线程) |
| **VRF数量** | 4000 |
| **VLAN支持** | 4094 |
| **路由表容量** | 支持大规模路由表项 (依赖内存配置) |
| **CPU架构** | Intel x86 |
| **内存要求** | 基础4G/8G，每增加1个线程需额外内存 |

## 4. 管理与维护
*   **管理方式**：支持Web GUI (HTTP/HTTPS)、CLI (SSH/Telnet)、Restful API。
*   **云化管理**：支持云平台集中纳管、配置下发与状态监控。
*   **日志与审计**：支持系统日志、安全日志、流量日志的本地存储与外发。
*   **高可用性 (HA)**：支持VRRP协议，支持主-备模式故障切换。

# Harvester 功能修复与优化计划 (2026.2.6)

## 1. 概览
本计划旨在解决 Harvester 资源池管理中的合规性问题、功能缺失及关键 Bug，确保 2.6.0 版本发布的稳定性。

## 2. 详情页面 UI 合规性 (Compliance) - (Fixed)
- **目标**：所有资源列表页必须符合 `page-detail-container.md` 和 `std-table` 规范。
- **涉及页面**：
  - `NodesSection`, `ImagesSection`, `NetworksSection`, `SshKeysSection`, `VolumesSection`, `BackupsSection`, `SnapshotsSection`, `VmsSection`。
- **修复内容**：
  - 表格列定义统一添加 `width: 80, fixed: 'right'` (Action Column)。
  - 分页配置统一移除 `showQuickJumper: true`。
  - 确保所有表格使用 `className="std-table"`。

## 3. 菜单结构调整 (Navigation) - (Fixed)
- **目标**：将 StorageClass 和 Namespace 归纳到 Cluster 菜单下。
- **修复内容**：
  - 修改 `CloudDetailHarvester.tsx` 的 Tab 定义。
  - 确保 `StorageClassesSection` 和 `NamespacesSection` 在新位置正常加载。

## 4. 缺失操作补充 (Missing Actions) - (Fixed)
- **目标**：修复部分资源页面操作无效或缺失的问题。
- **修复内容**：
  - **Backups/Snapshots**：修复了 Delete 操作无效的问题 (添加了 API 调用)。
  - **Images**：确保上传和删除功能正常。
  - **API**：在 `harvesterApi.ts` 中补全了 `deleteHarvesterBackup`, `deleteHarvesterSnapshot`, `deleteHarvesterSshKey` 等缺失接口。

## 5. 虚拟机生命周期 (VM Lifecycle) - (Fixed)

### 5.1 创建流程 (Create VM) - (Fixed)
- **修复内容**：
  - **EFI/SecureBoot**：修复了前端选项未正确映射到 `firmware.bootloader.efi` 的问题。
  - **USB Tablet**：修复了 USB Tablet 选项无效（硬编码）的问题，并将其默认值设为 `true` 以优化 VNC 体验。
  - **SSH Keys**：修复了 StepOthers 中 SSH Key 下拉框为空的问题（补充了 `fetchHarvesterSshKeys` 调用）。
  - **Network**：修复了不选 NAD 时无法创建的问题（移除了强制校验，默认使用 Pod Network）。
  - **Guest Agent**：修复了 `installGuestAgent` 选项未正确注入 Cloud-Init 脚本的问题。

### 5.2 资源变配 (Reconfigure VM) - (Fixed)
- **修复内容**：
  - **Change OS (Safe Rebuild)**：实现了原地更换系统盘逻辑 (Stop -> Create New PVC -> Swap -> Start)，替代了危险的删除重建逻辑。保留了 VM ID 和数据盘。
  - **Network Reconfiguration**：
    - 实现了 **主网卡变更** (Change Primary NIC)：支持在 NAD 和 Management Network 之间切换。
    - 实现了 **辅助网卡变更** (Change Secondary NIC)：支持动态添加/移除辅助网卡，支持自定义 MAC。
  - **UI 优化**：采用了单任务模式 (Single Task Mode)，避免配置冲突。

### 5.3 删除保护与级联删除 (Delete Protection) - (Fixed)
- **修复内容**：
  - **运行状态检查**：删除前检查 VM 是否处于 Running/Starting 状态，并显示红色警告（强制删除）。
  - **关联资源提示**：在删除确认框中列出关联的 PVC 数据卷，提示用户手动清理（Harvester 默认不自动删除数据盘 PVC）。
  - **UI 优化**：使用 `Modal.confirm` 的 `content` 渲染富文本警告信息，替代了简单的文本提示。

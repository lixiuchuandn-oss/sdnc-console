# Cloudmap harvester40 资源控制台相关问题
## 云主机模块
### 1. 删除操作
【P1 先不管】 勾选「同步删除关联镜像」时，未自动删除管理的镜像（虚拟磁盘）

### 2. 创建实例-计算资源页面
1. 勾选「启动热扩容」后创建虚机，底层实际未勾选该配置
2. 【P1 先不管】资源调度判断逻辑异常：需按照**最多扩容后的资源**计算节点是否满足调度，而非当前配置资源

### 3. 创建实例-基础资源配置
配置200C 400G资源且节点资源无法满足时，虚机状态为**待调度**，需在状态页展示「资源不足导致无法调度」等明确原因提示

### 4. 创建实例-虚机名称配置
虚机名称需支持中文、大小写及部分特殊字符；因Harvester自身接口不支持，需实现**名称转换/下转**适配逻辑
就是在我们的平台上增加别名列，进行映射即可

### 5. 创建实例-虚拟磁盘操作优化
虚拟磁盘设备类型为`cdrom`时，表格行操作展示「弹出CD-ROM」选项；**仅CD-ROM启动的虚机显示该按钮**（磁盘序列1的是CD-ROM类型），硬盘启动的虚机隐藏此操作项

### 6. 创建实例-虚拟磁盘配置异常
虚拟磁盘设备类型为`cdrom`时，选择数据盘后创建实例报错，具体错误信息：
```json
{"message":"创建实例失败","error":"{\"kind\":\"Status\",\"apiVersion\":\"v1\",\"metadata\":{},\"status\":\"Failure\",\"message\":\"admission webhook \\\"virtualmachine-validator.kubevirt.io\\\" denied the request: Bus type virtio is invalid for CD-ROM device\",\"reason\":\"Invalid\",\"details\":{\"causes\":[{\"reason\":\"FieldValueInvalid\",\"message\":\"Bus type virtio is invalid for CD-ROM device\",\"field\":\"spec.template.spec.domain.devices.disks[0].cdrom.bus\"}]},\"code\":422}\n"}
```

### 7. 创建实例-CPU高级配置（新增）
1. **CPU拓扑**：填写插槽数、每个插槽核数后，表格行展示的CPU个数未按「插槽数×每个插槽核数」计算
2. **CPU模式**：选择`Host-Passthrough`或**自定义模式**时，配置未生效
3. **CPU绑定**：勾选「启用」后，底层配置未生效，未实际绑定对应核数
4. **CPU QoS**：勾选「启用」后，底层配置未生效，未在`limit`和`request`中实现资源限制
5. **CPU隔离**：勾选「启用」后，底层配置未生效，未实现CPU隔离策略

### 8. 创建实例-内存高级配置（新增）
内存QoS配置勾选启用后，**底层未生效**，未实现内存资源的QoS限制

### 9. 创建实例-GPU分配配置（新增）
GPU分配-直通GPU场景：若目标GPU已被其他虚拟机占用，**列表中未过滤该GPU资源**，导致用户选择已占用GPU创建实例失败

## 镜像模块
### 新增镜像操作异常
1. 来源类型为「上传文件」时，未展示上传选项；仅「下载URL」来源需提供下载地址输入框
2. 存储类未提供下拉选择功能，无法选择对应存储类

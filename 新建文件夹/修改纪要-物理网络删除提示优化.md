# 物理网络删除确认提示优化（修改纪要）

- 背景：集群/物理网络列表操作行的“删除物理网络”弹窗，确认提示应显示物理网络的名称（别名），而不是资源 ID。
- 目标：提升确认信息的可读性与一致性，避免使用技术性 ID 给操作人员造成困扰。

## 修改功能
- 前端页面 Clouds/Harvester/kube-ovn 的 ProviderNetworksSection 删除确认弹窗文案：
  - 优先显示别名（来源：metadata.annotations['tower.io/alias'] 或行数据 displayAlias）。
  - 在别名缺省时回退为资源名 metadata.name。
  - 删除执行参数保持使用资源名（metadata.name）不变。

## 修改后的效果
- 删除弹窗文案由“确定要删除物理网络 <ID> 吗？”改为“确定要删除物理网络「<别名或名称>」吗？此操作不可恢复。”
- 逻辑与权限不变，仅用户可见的确认文字优化。

### 删除确认弹窗处理（handleDelete）

```ts
const handleDelete = (record: any) => {
  const raw = record?.raw || record?.rawData || record;
  const name = String(
    record?.name ||
      raw?.metadata?.name ||
      record?.metadata?.name ||
      '',
  ).trim();
  const ann = raw?.metadata?.annotations || {};
  const alias = String(record?.displayAlias || ann[TOWER_IO_ALIES_ANNOTATION] || '').trim();
  const label = alias || name;
  if (!name || name === '-') {
    message.error('删除失败：无效的物理网络名称');
    return;
  }
  Modal.confirm({
    title: '确认删除',
    content: `确定要删除物理网络「${label}」吗？此操作不可恢复。`,
    okText: '删除',
    okType: 'danger',
    cancelText: '取消',
    onOk: async () => {
      try {
        await deleteKubeOvnProviderNetwork(cloudId, name);
        message.success('删除成功');
        fetchData(true, true);
      } catch (e: any) {
        message.error(e?.message || '删除失败');
      }
    },
  });
};
```

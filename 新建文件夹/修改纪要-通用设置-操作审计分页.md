**修改概要**
- 页面：通用设置/操作审计
- 问题：审计日志未按后端分页返回进行展示，前端仅本地筛选并用当前页数据长度作为 total，导致无法正确分页
- 方案：改为后端分页（page/limit）与服务端筛选（search/action/时间范围），前端以后端返回的 total 驱动分页

**修改效果**
- 审计日志列表分页为服务端分页：切换页码/页大小会触发接口请求并返回对应数据与总数
- 支持服务端筛选：关键字、动作、日期范围均随请求参数传递并影响结果与总数
- 分页统计准确：Table 的 total 取后端返回的 total，不再使用本地过滤后的长度

**后端改动（完整实现）**
- 接口：GET /api/audit-logs
- 新增查询参数：action、startTime、endTime；分页安全化（最小1，最大200）
- 返回：items、total、page、limit、totalPages

```ts
import { Router, Response } from 'express';
import { AppDataSource } from '../config/database';
import { AuditLog } from '../entities/AuditLog';
import { authMiddleware, AuthRequest } from '../middleware/auth';
import { UserRole } from '../entities/User';
import { requirePermission } from '../permissions';

const router = Router();
const checkAuditPermission = requirePermission('system.audit:read', {
  allowSuperAdmin: true,
});

router.get('/', authMiddleware, checkAuditPermission, async (req, res) => {
  try {
    const { page = 1, limit = 20, search, action, startTime, endTime } = req.query as any;
    const safePage = Math.max(1, Number(page) || 1);
    const safeLimit = Math.max(1, Math.min(200, Number(limit) || 20));
    const skip = (safePage - 1) * safeLimit;
    const take = safeLimit;

    const repo = AppDataSource.getRepository(AuditLog);
    const query = repo.createQueryBuilder('audit_log').where('1=1');

    if (search) {
      query.andWhere('audit_log.action LIKE :search OR audit_log.username LIKE :search OR audit_log.details LIKE :search', {
        search: `%${String(search)}%`,
      });
    }

    if (action) {
      query.andWhere('audit_log.action = :action', { action: String(action) });
    }

    const startDate = startTime ? new Date(String(startTime)) : null;
    if (startDate && !Number.isNaN(startDate.getTime())) {
      query.andWhere('audit_log.createdAt >= :startTime', { startTime: startDate });
    }

    const endDate = endTime ? new Date(String(endTime)) : null;
    if (endDate && !Number.isNaN(endDate.getTime())) {
      query.andWhere('audit_log.createdAt <= :endTime', { endTime: endDate });
    }

    query.orderBy('audit_log.createdAt', 'DESC');
    query.skip(skip).take(take);

    const [items, total] = await query.getManyAndCount();

    res.json({
      items,
      total,
      page: safePage,
      limit: safeLimit,
      totalPages: Math.ceil(total / safeLimit),
    });
  } catch (error) {
    res.status(500).json({ message: 'Internal server error' });
  }
});

export const auditLogRoutes = router;
```

**接口约定**
- 入参（query）：
  - page: number
  - limit: number
  - search: string（可选）
  - action: string（可选，前端以空格替换为下划线传递，如 "START VM" → "START_VM"）
  - startTime/endTime: ISO 字符串（可选）
- 返回（JSON）：
  - items: AuditLog[]
  - total: number
  - page: number
  - limit: number
  - totalPages: number

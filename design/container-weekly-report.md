# 多云管理平台-容器模块产品规划汇报

> 汇报日期: 2026-03-28
> 项目: Compute Tower 容器功能模块

---

## 一、整体规划

### 分期进度

| 分期 | 功能范围 | 状态 |
|------|----------|------|
| 一期（基础版） | 各核心组件的列表查询、详情查看、基础操作 | 🟢 已完成 |
| 二期（增强版） | 各核心组件的创建/编辑功能、YAML编辑、Pod终端交互 | 🟢 已完成 |
| 三期（高级功能） | 高级调度策略、NetworkPolicy、交互优化、名称优化、服务拓扑、租户视角、可观测性 | 🟡 进行中 |

---

## 二、之前已完成能力回顾

### 一期（基础版）

| 模块 | 功能 |
|------|------|
| 工作负载 | Deployment/StatefulSet/DaemonSet 列表、扩缩容、重启、删除 |
| Pod | 列表、详情、日志、删除 |
| 任务 | Job/CronJob 列表、删除 |
| 服务发现 | Service/Ingress 列表 |
| 配置管理 | ConfigMap/Secret 列表 |
| 镜像仓库 | 凭证列表 |

### 二期（增强版）

| 模块 | 功能 |
|------|------|
| 工作负载 | 创建/编辑 (表单+YAML) |
| Pod | WebSocket 终端 (xterm.js) |
| 任务 | Job/CronJob 创建、暂停恢复、手动触发、重试 |
| Service | 创建/编辑/YAML编辑、关联Pod查看 |
| Ingress | 创建/编辑/YAML编辑 |
| Gateway API | Gateway/HTTPRoute/GRPCRoute 创建 |
| 配置管理 | ConfigMap/Secret 创建/编辑 |
| 镜像仓库 | 凭证创建、仓库浏览器、镜像浏览 |

## 四、风险及依赖项

| 风险点 | 建议 |
|--------|------|
| Gateway API 环境未安装 CRD | 功能已开发，后续需要环境准备，再进行验证 |
| 租户视角涉及与应用场景深度结合，以及对现有改动较大 | 调研友商产品，可能考虑租户独立界面，不和管理员混用 |
| 代码合并风险，基于旧版仓库基础上开发，可能涉及代码冲突 | 将现有前后端容器涉及到的文件打包，尝试合并 |
| 日志采集和检索| 依赖日审平台容器化改造|
